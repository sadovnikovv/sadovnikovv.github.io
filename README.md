# Claude Code для инженера

Практическое пособие: Claude Code, OmniRoute, DeepSeek, основы ИИ и агенты —
с инженерными главами про схемы, платы, контроллеры и CAD.

**Книга на сайте:** <https://sadovnikovv.github.io/>

## Что лежит в репозитории

| Путь | Что это | Кто меняет |
|---|---|---|
| `Sasha_II_TUT/Книга-Claude-Code.html` | **Источник истины**: вся книга одним автономным HTML-файлом (работает офлайн) | автор |
| `Sasha_II_TUT/ru-materials/` | Скачанные материалы: документация Claude Code и OmniRoute, гайды сообщества, основы ИИ, открытые книги | только обновляется загрузкой |
| `Sasha_II_TUT/claude-code-handbook-ru/` | Справочник Handbook на русском (только локально, на сайт не попадает) | не меняется |
| `Sasha_II_TUT/build_epub.py` | HTML → EPUB 3 (`python build_epub.py`) | редко |
| `site-src/` | Генератор статического сайта (этот README, см. ниже) | по необходимости |
| `site/` | **Собранный сайт** — то, что публикует GitHub Pages | никогда вручную |
| `.github/workflows/pages.yml` | Сборка и публикация при push в `main` | редко |

## Как обновить сайт

1. Поправить текст в `Sasha_II_TUT/Книга-Claude-Code.html` (главы — это `<h2>`;
   порядок глав — порядок в файле).
2. Локально проверить:

   ```bash
   python site-src/build_site.py          # собрать site/
   python site-src/check_site.py          # битые ссылки и якоря
   ```

   Открыть `site/index.html` в браузере.

3. Если менялся EPUB — пересобрать: `python Sasha_II_TUT/build_epub.py`.
4. Закоммитить и отправить в `main`:

   ```bash
   git add -A
   git commit -m "Обновление книги"
   git push
   ```

   GitHub Actions заново соберёт `site/` из источника и опубликует — расхождений
   не будет, даже если забыть пересобрать локально.

## Подробности

### Как устроен сайт

- **Страницы глав** (`site/pages/<id>.html`) содержат только каркас: шапку,
  подвал и подсказку из `{title, url}` всех глав. Текст подгружает
  `site/assets/app.js` запросом `../book.html` и вставляет нужную главу
  по `data-book-src`/`#якорю`. Это позволяет держать один источник текста и
  мгновенные переходы: браузер кеширует `book.html` между страницами.
- **`site/book.html`** — вся книга на одной странице (встроенные тема, шрифт,
  поиск и оглавление из оригинальной книги).
- **`site/materials/`** — `ru-materials` в виде HTML-страниц с оглавлением;
  сырой HTML из чужих Markdown экранируется (XSS-безопасно).
- **`site/download/`** — EPUB. Крупные PDF (больше 3 МБ) не копируются —
  страница материалов ссылается на файл в репозитории.
- Шрифты (Noto Sans / Serif / Sans Mono, кириллица, OFL) лежат локально в
  `site-src/vendor/fonts/` — сайт не обращается к Google Fonts.

### Ограничения

- Источник книги — в подпапке `Sasha_II_TUT/`. Если перенести книгу в корень,
  `build_site.py` найдёт её автоматически по шаблону `*-Claude-Code.html`.
- Главы с личными данными (`deepseek-billing`, `migration`, `new-pc` —
  выписка по балансу и выгрузка переписки) на сайте заменены заглушкой,
  список — константа `PRIVATE` в `site-src/build_site.py`. Личная папка
  `_selenium_out/` на сайт не копируется.
- В книге используются «вы» и личные примеры автора — при публикации это
  видно всем читателям; контактов (почта, телефон) в книге нет.

## Курсы Anthropic Academy (глава 33)

Часть данных книги взята с курсов academy.claude.com: структура курсов, темы уроков, задания и
проверочные вопросы. Тексты уроков пересказаны по-русски. Пересказы хранятся в
`site-src/academy/ru/<slug>.json` (один курс - один файл), задания и тест собираются в главу
`site-src/academy_build.py` и встраиваются в сайт. Ответы на задания и результаты самопроверки
хранятся в localStorage браузера; ничего никуда не отправляется.

```bash
python site-src/academy_fetch.py   # (по необходимости) закэшировать страницы курсов в site-src/academy/raw
python site-src/academy_ru.py check  # все ли уроки курсов пересказаны
python site-src/build_site.py        # пересобрать сайт: глава 33 обновится
```

Кэш `site-src/academy/raw/` (английские оригиналы) в репозиторий не входит.

## Практикум (глава 34)

Глава «Практикум: агент в браузере» собрана из скриптов, написанных автором: сценарии
сбора и разбора объявлений с доски объявлений, обезличенные для публикации.

- `site-src/academy/practice_ru.json` - текст, задания и самопроверка;
- `site-src/academy/practice/code.json` - только код программ (без профилей, кэшей и данных);
- `site-src/practice_build.py` - сборка главы; `site-src/academy/gen-code.py` - однократная
  подготовка очищенного кода из исходной папки (в репозиторий она не входит).

В коде нет телефонов, почт, имён, адресов и ссылок на профили. Профиль браузера и кэш
в репозиторий не попадают никогда. Задания и самопроверка сохраняют ответы в браузере.
