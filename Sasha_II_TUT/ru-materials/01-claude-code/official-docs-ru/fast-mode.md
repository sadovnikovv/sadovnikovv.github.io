# Ускорьте ответы с помощью быстрого режима

> Получайте более быстрые ответы Opus и Fable в Claude Code, включая и отключая быстрый режим с помощью `/fast`.

> [!NOTE]
>
> Быстрый режим для Claude Fable 5.2 и Claude Opus 5.5 доступен. Быстрый режим для Claude Opus 5 и Claude Opus 4.8 находится в [research preview](#research-preview).

Быстрый режим — это высокоскоростная конфигурация для поддерживаемых моделей, которая делает модель до 2,5 раза быстрее при более высокой стоимости за токен. Включайте его с помощью `/fast`, когда вам нужна скорость для интерактивной работы, такой как быстрая итерация или живая отладка, и отключайте, когда стоимость важнее, чем задержка.

Быстрый режим использует ту же модель с другой конфигурацией API, которая приоритизирует скорость над экономичностью, поэтому качество и возможности остаются прежними. В Anthropic API быстрый режим поддерживается на Fable 5.2, Opus 5.5, Opus 5 и Opus 4.8, но не на Sonnet, Haiku или других моделях. О моделях на Agent Platform от Google Cloud см. раздел [Использование быстрого режима на Agent Platform](#use-fast-mode-on-agent-platform).

> [!WARNING]
>
> Быстрый режим для Opus 4.8 был объявлен устаревшим 30 октября 2026 года и будет удален 30 ноября 2026 года. Если после этой даты вы по-прежнему используете Opus 4.8 с включенным быстрым режимом, API будет отклонять ваши запросы. До этой даты переключитесь на Opus 5.5 или отключите быстрый режим в своей сессии:
>
> * **Чтобы сохранить быстрый режим**: используйте [`/model`](https://code.claude.com/docs/ru/model-config#setting-your-model), чтобы переключиться на [Opus 5.5](https://code.claude.com/docs/ru/model-config.md#model-aliases); для этого требуется Claude Code v2.1.280 или новее. После переключения быстрый режим остается включенным. Если новая сессия по-прежнему запускается на Opus 4.8, см. раздел [Новая сессия запускается на другой модели, чем вы выбрали](https://code.claude.com/docs/ru/model-config.md#a-new-session-starts-on-a-different-model-than-you-picked).
> * **Чтобы остаться на Opus 4.8 со стандартной скоростью**: выполните [`/fast off`](https://code.claude.com/docs/ru/commands)

Opus 4.7 не поддерживает быстрый режим, поэтому переключение на него отключает быстрый режим. Быстрый режим для Opus 4.7 был объявлен устаревшим 25 июня 2026 года и удален 24 июля 2026 года.

Что нужно знать:

* Используйте `/fast` для включения быстрого режима в Claude Code CLI. Расширение [VS Code](https://code.claude.com/docs/ru/vs-code.md) предлагает команду **Toggle fast mode** при выборе модели, которая поддерживает быстрый режим. В Anthropic API Claude Code сохраняет этот переключатель в вашей настройке [`fastMode`](#toggle-fast-mode).
* Цены Anthropic на быстрый режим составляют \$16/\$80 за MTok входа/выхода на Fable 5.2, \$8/\$40 на Opus 5.5 и \$10/\$50 на Opus 5 и Opus 4.8.
* Доступно пользователям Claude Code на планах подписки (Pro/Max/Ultra/Team/Enterprise), на Claude Console и на Agent Platform от Google Cloud [с условиями](#use-fast-mode-on-agent-platform). Организациям Team и Enterprise требуется, чтобы Owner сначала это включил, а организациям Console требуется сначала получить предоставленный доступ, чтобы использовать его с Opus 5 или Opus 4.8. Оба варианта описаны в разделе [Требования](#requirements).
* Для пользователей Claude Code на планах подписки (Pro/Max/Ultra/Team/Enterprise) быстрый режим доступен только через кредиты использования и не включен в ограничения частоты запросов подписки.

## Включение быстрого режима

На Agent Platform `/fast` и настройка `fastMode` работают иначе, поэтому вместо этого следуйте разделу [Использование быстрого режима на Agent Platform](#use-fast-mode-on-agent-platform).

В CLI включайте быстрый режим одним из следующих способов:

* Запустите `/fast`, нажмите Space для включения или отключения, затем нажмите Enter для подтверждения
* На модели, которая поддерживает быстрый режим, установите `"fastMode": true` в вашем [файле пользовательских настроек](https://code.claude.com/docs/ru/settings.md). Если вы установите его на любой другой модели, вы останетесь на этой модели с отключенным быстрым режимом. На Fable 5.2 эта настройка сама по себе не действует, пока вы не запустите `/fast` во время использования Fable 5.2.

По умолчанию в Anthropic API быстрый режим, который вы включаете в интерактивной сессии, сохраняется между сессиями на поддерживаемой модели. На Fable 5.2 он сохраняется, только если вы [включили его во время использования Fable 5.2](#switch-models-while-fast-mode-is-on). Вы можете настроить быстрый режим на сброс в каждой сессии. Подробности см. в разделе [обязательное согласие за сессию](#require-per-session-opt-in).

Вне [облачного сеанса](#use-fast-mode-in-cloud-sessions), в [неинтерактивном режиме](https://code.claude.com/docs/ru/headless.md) с флагом `-p` команда `/fast` работает только в сеансе, запущенном с быстрым режимом в его значении [`--settings`](https://code.claude.com/docs/ru/cli-reference#cli-flags), например `claude -p --settings '{"fastMode": true}'`; переключение затем применяется только к этому сеансу и не сохраняется как ваше значение по умолчанию. Форма `-p` требует Claude Code v2.1.205 или более поздней версии. В остальных случаях в неинтерактивном режиме команда сообщает, что быстрый режим недоступен.

Вы можете запустить `/fast` во время работы Claude, и Claude Code переключает быстрый режим без ожидания завершения хода. Claude Code завершает текущий ход с его исходной скоростью, поэтому изменение скорости вступает в силу со следующего хода. Если ваша текущая модель не поддерживает быстрый режим, его включение также переключает вашу модель, и Claude Code использует новую модель со следующего запроса в этом ходе.

Для лучшей экономичности включайте быстрый режим в начале сеанса, а не переключайтесь в середине разговора. Подробности см. в разделе [понимание компромисса стоимости](#understand-the-cost-tradeoff).

Когда вы включаете быстрый режим с помощью `/fast`:

* В Anthropic API, если ваша текущая модель не поддерживает быстрый режим, Claude Code переключается на Opus
* Быстрый режим на Fable 5.2 требует Claude Code v2.1.321 или более поздней версии
* Вы увидите сообщение подтверждения: "Fast mode ON"
* Рядом с приглашением появляется небольшой значок `↯` во время активного быстрого режима
* Запустите `/fast` снова в любое время, чтобы проверить, включен или отключен быстрый режим

В Anthropic API Opus 5.5 является моделью по умолчанию для быстрого режима в Claude Code v2.1.280 и позже. До версии v2.1.280 быстрый режим по умолчанию использовал Opus 5, начиная с версии v2.1.219.

Когда вы отключаете быстрый режим с помощью `/fast` снова, вы остаетесь на текущей модели. Чтобы переключиться на другую модель, используйте `/model`.

### Переключение моделей во время активного быстрого режима

Быстрый режим следует вашим переключениям моделей:

* **Переключение в сторону**: когда вы переключаетесь на модель, которая не поддерживает быстрый режим, Claude Code отключает быстрый режим. Это включает Opus 4.7; до версии v2.1.221 быстрый режим оставался включенным после переключения на Opus 4.7 и API отклонял запросы.
* **Переключение обратно**: быстрый режим снова включается на поддерживаемой модели Opus, когда ваше сохраненное предпочтение включено. С [обязательным согласием за сессию](#require-per-session-opt-in) вместо этого запустите `/fast`.
* **Переключение на Fable 5.2**: быстрый режим отключается, если только вы не включили его во время использования Fable 5.2. Чтобы включить его, запустите `/fast` на Fable 5.2. Если вы не настроили [обязательное согласие за сессию](#require-per-session-opt-in), этот выбор сохраняется между сессиями в Anthropic API, пока вы не отключите быстрый режим или не включите его с другой моделью.

Всякий раз, когда переключение модели включает или отключает быстрый режим, Claude Code показывает подтверждение `Fast mode ON` или `Fast mode OFF`, и значок `↯` появляется во время активного быстрого режима. Это применяется независимо от того, переключаетесь ли вы с помощью `/model`, с помощью [`/config model=<model>`](https://code.claude.com/docs/ru/settings) или с устройства, подключенного через [Remote Control](https://code.claude.com/docs/ru/remote-control.md).

### Использование быстрого режима в облачных сеансах

Быстрый режим работает в [облачных сессиях](https://code.claude.com/docs/ru/claude-code-on-the-web.md), когда он доступен в вашей учетной записи, независимо от того, работает ли сессия на инфраструктуре, управляемой Anthropic, или на [самостоятельно размещенном runner](https://code.claude.com/docs/ru/self-hosted-environments) в Anthropic API. Требует Claude Code v2.1.271 или более поздней версии в окружении сессии.

Введите `/fast on` в сеансе, чтобы включить быстрый режим. Он остается включенным только для этого сеанса и не сохраняется как ваше значение по умолчанию. [Требования](#requirements) применяются и в облачных сеансах.

В браузере на [claude.ai/code](https://claude.ai/code) вы также можете включать и отключать быстрый режим из меню модели в поле сообщения. Меню показывает переключатель, когда ваш план включает быстрый режим и выбранная модель его поддерживает.

## Понимание компромисса стоимости

Быстрый режим имеет более высокую цену за токен, чем стандартная скорость. Вот тарифы Anthropic:

| Модель | Входные данные (MTok) | Выходные данные (MTok) |
| - | - | - |
| Fable 5.2 | \$16 | \$80 |
| Opus 5.5 | \$8 | \$40 |
| Opus 5 | \$10 | \$50 |
| Opus 4.8 | \$10 | \$50 |

Цены на быстрый режим одинаковы по всему контекстному окну из 1M токенов. Для сравнения со стандартной ставкой см. [справочник по ценам Claude](https://platform.claude.com/docs/ru/about-claude/pricing).

Когда вы впервые включаете быстрый режим в диалоге, вы платите полную цену быстрого режима за некэшированные входные токены для всего контекста диалога. Чем дальше вы продвинулись в диалоге, тем дороже это обходится, поэтому плата минимальна, если включить быстрый режим в самом начале. Быстрый режим и стандартная скорость используют [отдельные кэши](https://code.claude.com/docs/ru/prompt-caching.md#turning-on-fast-mode), поэтому при каждом последующем переключении часть диалога или весь диалог снова считывается без кэша.

### Посмотрите, где появляются расходы быстрого режима

Вы видите расходы быстрого режима в разном месте в зависимости от того, как вы вошли, поэтому сначала запустите [`/status`](https://code.claude.com/docs/ru/commands) для проверки. Если это показывает строку `Login method` такую как `Claude Max account`, вы вошли с подпиской Claude. Если вместо этого это показывает строку `API key`, ваши запросы выставляются в счёт организации Claude Console.

* **Pro, Max и Ultra**: вы платите за быстрый режим из своих кредитов использования. Перейдите на [**Settings > Usage**](https://claude.ai/settings/usage) на claude.ai, где раздел **Usage credits** показывает, сколько вы потратили в кредитах использования в этом месяце. Эта цифра включает быстрый режим, но не разбивает его отдельно.
* **Team и Enterprise**: ваша организация платит за использование быстрого режима из своих кредитов использования. Чтобы увидеть свои расходы в кредитах использования, запустите [`/usage`](https://code.claude.com/docs/ru/costs#check-your-usage-credits-spend). Для того, где ваша организация видит эти расходы, см. [Claude для Teams и Enterprise](https://code.claude.com/docs/ru/costs.md#claude-for-teams-and-enterprise).
* **Claude Console**: ваша организация платит за быстрый режим вместе с остальным использованием API. На страницах Console [Usage](https://platform.claude.com/usage) и [Cost](https://platform.claude.com/cost) выберите **Speed** в меню **Group by** для отделения быстрого режима от использования стандартной скорости. Вы видите эту опцию только когда выбранный диапазон дат включает использование быстрого режима.

## Решение о том, когда использовать быстрый режим

Быстрый режим лучше всего подходит для интерактивной работы, где задержка ответа важнее стоимости:

* Быстрая итерация изменений кода
* Сеансы живой отладки
* Работа, чувствительная ко времени, с жесткими сроками

Стандартный режим лучше для:

* Долгих автономных задач, где скорость менее важна
* Пакетной обработки или конвейеров CI/CD
* Рабочих нагрузок, чувствительных к стоимости

### Быстрый режим в сравнении с уровнем усилий

Быстрый режим и уровень усилий оба влияют на скорость ответа, но по-разному:

| Параметр | Эффект |
| - | - |
| **Быстрый режим** | Одинаковое качество модели, меньшая задержка, более высокая стоимость |
| **Более низкий уровень усилий** | Меньше времени на размышление, более быстрые ответы, потенциально более низкое качество на сложных задачах |

Вы можете комбинировать оба: используйте быстрый режим с более низким [уровнем усилий](https://code.claude.com/docs/ru/model-config.md#adjust-effort-level) для максимальной скорости на простых задачах.

## Требования

Быстрый режим требует всех следующих условий:

* **Поддерживаемый провайдер**: быстрый режим доступен через Anthropic Console API, для планов подписки Claude с использованием кредитов использования, а также на Google Cloud's Agent Platform [с определёнными условиями](#use-fast-mode-on-agent-platform). Он недоступен на Amazon Bedrock, Microsoft Foundry или Claude Platform на AWS, где `/fast` сообщает "Fast mode is not available on this provider". Организации Console также должны иметь [предоставленный доступ к быстрому режиму](#enable-fast-mode-for-your-organization), чтобы использовать его с Opus 5 или Opus 4.8.
* **Кредиты использования включены для планов подписки**: на плане Pro, Max, Ultra, Team или Enterprise в вашей учётной записи должны быть включены [кредиты использования](https://code.claude.com/docs/ru/costs.md#add-usage-credits-to-your-subscription), что позволяет оплату сверх включённого в ваш план использования. До их включения `/fast` сообщает "Fast mode requires usage credits". Чтобы включить их, выполните шаг для вашего плана:
  * На Pro, Max и Ultra включите их в разделе **Usage credits** на странице [**Settings > Usage**](https://claude.ai/settings/usage) на claude.ai или запустите `/usage-credits`, чтобы открыть эту страницу.
  * На Team и Enterprise участник с доступом к биллингу включает их для организации в [**Organization settings > Usage**](https://claude.ai/admin-settings/usage), а участник без такого доступа запускает `/usage-credits`, чтобы отправить запрос администраторам организации.

> [!NOTE]
>
> Использование быстрого режима берет кредиты непосредственно из кредитов использования, даже если у вас остается использование в вашем плане.

* **Платная организация Console**: учетные записи Claude Console не используют кредиты использования, и ваша организация платит за быстрый режим за токен вместе с остальным использованием API. На бесплатном плане Evaluation Console `/fast` показывает "Fast mode unavailable during evaluation. Please purchase credits." Чтобы это исправить, приобретите кредиты в [параметрах выставления счетов Console](https://platform.claude.com/settings/billing).

  Быстрый режим с Fable 5.2 или Opus 5.5 также зависит от [уровня использования](https://platform.claude.com/docs/en/api/rate-limits) вашей организации.
* **Включение владельцем для Team и Enterprise**: быстрый режим отключен по умолчанию для организаций Team и Enterprise. Владелец должен явно [включить быстрый режим](#enable-fast-mode-for-your-organization) перед тем, как пользователи смогут получить к нему доступ.

> [!NOTE]
>
> Четыре параметра организации могут заблокировать включение быстрого режима с помощью `/fast`:
>
> * **Быстрый режим не включен**: если быстрый режим не был включен для вашей организации, включение быстрого режима с помощью `/fast` показывает "Fast mode has been disabled by your organization."
> * **Быстрый режим отключен управляемыми параметрами**: если ваша организация развертывает [управляемые параметры](https://code.claude.com/docs/ru/managed-settings.md), которые устанавливают [`fastMode: false`](https://code.claude.com/docs/ru/settings-reference#fastmode), включение быстрого режима с помощью `/fast` показывает то же сообщение "Fast mode has been disabled by your organization".
> * **Требуется явное согласие для каждого сеанса**: управляемые параметры, которые устанавливают [`fastModePerSessionOptIn: true`](#require-per-session-opt-in), отклоняют `/fast on` с тем же сообщением везде, кроме интерактивного сеанса терминала.
> * **Модель быстрого режима не разрешена**: если список разрешённых моделей [`availableModels`](https://code.claude.com/docs/ru/model-config#restrict-model-selection) вашей организации исключает модель, на которую переключает `/fast`, включение отклоняется с "is not in your organization's allowed models". В сессии, уже работающей на разрешенной модели, поддерживающей быстрый режим, `/fast` вместо этого включает быстрый режим на вашей текущей модели без переключения моделей.

### Включение быстрого режима для вашей организации

Место, где вы включаете быстрый режим, зависит от того, какой продукт использует ваша организация:

* **Console** (клиенты API): администратор включает его в [Claude Code preferences](https://platform.claude.com/claude-code/preferences)
* **Claude AI** (Team и Enterprise): Owner включает его в [**Organization settings > Claude Code**](https://claude.ai/admin-settings/claude-code)

Организациям Console, которые используют Claude Opus 5 или Claude Opus 4.8, также нужен предоставленный доступ, как описано в [быстром режиме на Claude API](https://platform.claude.com/docs/en/build-with-claude/fast-mode). Без этого доступа запросы быстрого режима к этим моделям упираются в [ограничение частоты запросов быстрого режима](#handle-rate-limits) и возвращаются к стандартной скорости, пока доступ не будет предоставлен.

Другой вариант полного отключения быстрого режима — установить `CLAUDE_CODE_DISABLE_FAST_MODE=1`. См. [Переменные окружения](https://code.claude.com/docs/ru/env-vars.md).

### Использование быстрого режима на Agent Platform

На [Google Cloud's Agent Platform](https://code.claude.com/docs/ru/google-vertex-ai.md) вы можете включить быстрый режим для Fable 5.2 с помощью `/fast` в интерактивной сессии или с помощью флагов запуска в [неинтерактивном режиме](https://code.claude.com/docs/ru/headless.md). Требуется Claude Code v2.1.322 или новее.

Для быстрого режима [регион](https://code.claude.com/docs/ru/google-vertex-ai.md#region-configuration) для Fable 5.2 должен быть `global`, `us` или `eu`. В другом регионе `/fast` сообщает `Fast mode needs Vertex region global, us or eu`, а `claude -p` работает на стандартной скорости. Задайте регион в своей оболочке перед запуском Claude Code, например `global`:

```bash theme={null}
export VERTEX_REGION_CLAUDE_FABLE_5_2=global
```

Затем включите быстрый режим:

* **В интерактивной сессии**: выполните `/fast`. Команда переключает вас на Fable 5.2 с модели Opus или другой модели без быстрого режима на Agent Platform. Быстрый режим не сохраняется как ваш режим по умолчанию.
* **В неинтерактивном режиме**: передайте Fable 5.2 в [`--model`](https://code.claude.com/docs/ru/cli-reference#cli-flags) и быстрый режим в [`--settings`](https://code.claude.com/docs/ru/cli-reference#cli-flags), например `claude -p "Summarize this project" --model claude-fable-5-2 --settings '{"fastMode": true}'`

На Agent Platform `"fastMode": true` в ваших пользовательских, проектных, локальных или управляемых настройках не действует.

Если Agent Platform отклоняет быстрый режим, Claude Code возвращается к стандартной скорости. В этом случае интерактивная сессия показывает одно из следующих сообщений в терминале:

* `Using standard speed on Fable 5.2 · fast mode wasn't available`: выполните `/fast on`, чтобы снова попробовать быстрый режим
* `Fast mode paused: your cloud provider refused a fast request · trying again in 30m`: Agent Platform ответила на запрос быстрого режима ошибкой 403 или 404. Чтобы попробовать раньше, выполните `/fast on`. Требуется Claude Code v2.1.323 или новее.

### Использование быстрого режима за прокси и шлюзами LLM

Перед предложением быстрого режима на Anthropic API Claude Code проверяет доступность быстрого режима вашей организации с помощью запроса непосредственно к `api.anthropic.com`. Проверка не следует [`ANTHROPIC_BASE_URL`](https://code.claude.com/docs/ru/llm-gateway-connect#set-the-base-url-and-credential), поэтому в сети, которая маршрутизирует трафик Claude через [шлюз LLM](https://code.claude.com/docs/ru/llm-gateway) и блокирует прямой исходящий трафик к `api.anthropic.com`, проверка не удается, даже если запросы вывода работают.

Проверка использует настроенный [HTTP прокси](https://code.claude.com/docs/ru/network-config.md#proxy-configuration), поэтому сетевая блокировка приводит к неудаче проверки только там, где `api.anthropic.com` недостижим даже через прокси. Если в вашей организации быстрый режим включен, а `/fast` сообщает обратное, найдите показанное сообщение среди следующих случаев.

#### Fast mode unavailable due to network connectivity issues

Проверка доступности завершилась неудачей, например потому что ваша сеть блокирует `api.anthropic.com`, и запросы выполняются на стандартной скорости. Проверка, которая была успешной в прошлом, продолжает работать на основе своего кэшированного результата, поэтому заблокированная проверка в основном влияет на новые установки.

Чтобы восстановить быстрый режим, добавьте прямой исходящий трафик к `api.anthropic.com` в список разрешённых или установите `CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS=1`, что заставляет считать неудачную проверку успешной и при этом по-прежнему учитывает ответ "disabled by your organization".

#### Fast mode is currently unavailable

При работе через шлюз проверьте наличие следующих конфигураций, в которых Claude Code не отправляет проверку доступности и не имеет кэшированной ранее успешной проверки:

* Вы указываете в `ANTHROPIC_BASE_URL` свой шлюз и задаете в [`ANTHROPIC_API_KEY`](https://code.claude.com/docs/ru/llm-gateway-connect#set-the-base-url-and-credential) ключ, выданный шлюзом, который не соответствует формату API-ключа Anthropic.
* Вы устанавливаете [`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`](https://code.claude.com/docs/ru/env-vars), поэтому Claude Code пропускает проверку.

Чтобы восстановить быстрый режим в любой из этих конфигураций, установите `CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS=1`.

#### Fast mode has been disabled by your organization

При работе через шлюз вы можете увидеть это сообщение, даже если в вашей организации быстрый режим включен, в любой из следующих конфигураций:

* Вы аутентифицируетесь только с помощью [`ANTHROPIC_AUTH_TOKEN`](https://code.claude.com/docs/ru/llm-gateway-connect#set-the-base-url-and-credential), без входа в claude.ai, без API-ключа и без кэшированной успешной проверки. В этом случае Claude Code считает быстрый режим отключенным вашей организацией, не отправляя запрос.
* Прокси перехватывает проверку и отвечает собственной страницей, например прокси с TLS-инспекцией возвращает страницу блокировки с HTTP 200. Claude Code воспринимает эту страницу как ответ о том, что в вашей организации быстрый режим отключен.

В обоих случаях установите `CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK=1`, что полностью пропускает проверку, а не `CLAUDE_CODE_SKIP_FAST_MODE_NETWORK_ERRORS`, которая ни к одному из этих случаев не применяется.

> [!NOTE]
>
> Переменные пропуска изменяют только проверку на стороне клиента. Когда в вашей организации быстрый режим отключен, API отклоняет запросы быстрого режима независимо от того, установлены ли они. В этом случае Claude Code повторяет запрос на стандартной скорости, отключает быстрый режим, а `/fast` сообщает, что ваша организация отключила быстрый режим.

### Требование явного согласия для каждого сеанса

По умолчанию на Anthropic API быстрый режим, который пользователь включает в интерактивной сессии, сохраняется между сессиями на поддерживаемой модели. На Fable 5.2 быстрый режим сохраняется, только если пользователь [включил его во время использования Fable 5.2](#switch-models-while-fast-mode-is-on).

Чтобы каждая сессия начиналась с отключенным быстрым режимом, установите `fastModePerSessionOptIn` в значение `true` в любом [файле настроек](https://code.claude.com/docs/ru/settings.md#where-settings-live). Тогда пользователи включают его с помощью `/fast` в каждой сессии. Владельцы на планах [Team](https://claude.com/pricing?utm_source=claude_code\&utm_medium=docs\&utm_content=fast_mode_teams#team-&-enterprise) или [Enterprise](https://anthropic.com/contact-sales?utm_source=claude_code\&utm_medium=docs\&utm_content=fast_mode_enterprise) могут развернуть его на уровне организации через [настройки, управляемые сервером](https://code.claude.com/docs/ru/server-managed-settings.md).

```json theme={null}
{
  "fastModePerSessionOptIn": true
}
```

Это полезно для контроля затрат в организациях, где пользователи запускают несколько одновременных сеансов. Предпочтение быстрого режима пользователя все еще сохраняется, поэтому удаление этого параметра восстанавливает поведение по умолчанию с сохранением.

Когда управляемые параметры устанавливают ключ, `/fast on` работает только в интерактивном сеансе терминала. Везде еще, включая [неинтерактивный режим](https://code.claude.com/docs/ru/headless.md), [расширение VS Code](https://code.claude.com/docs/ru/vs-code.md) и [облачные сеансы](#use-fast-mode-in-cloud-sessions), это отклоняется с сообщением, что ваша организация отключила быстрый режим.

## Обработка лимитов скорости

Быстрый режим имеет отдельные ограничения частоты запросов, отличные от стандартной скорости; для организаций Console они описаны на странице [ограничений частоты запросов](https://platform.claude.com/docs/en/api/rate-limits) Claude Platform. Когда вы достигаете лимита запросов быстрого режима:

1. Быстрый режим автоматически переключается на стандартную скорость
2. Значок `↯` становится серым, указывая на охлаждение
3. Вы продолжаете работать со стандартной скоростью и ценами
4. Когда охлаждение истекает, быстрый режим автоматически повторно включается

Чтобы вместо этого отключить быстрый режим вручную, запустите `/fast` снова.

Если вы исчерпаете кредиты использования во время сеанса, Claude Code повторно пытается выполнить каждый отклоненный запрос быстрого режима со стандартной скоростью и ценами, поэтому вы продолжаете работать, и охлаждение отсутствует. То, как вы видите отклонение, зависит от типа сеанса:

* В интерактивной сессии Claude Code показывает уведомление "Fast mode disabled · Out of usage credits" и отключает быстрый режим. Ваше сохраненное предпочтение быстрого режима не изменяется; запустите `/fast`, чтобы снова включить быстрый режим.
* В [неинтерактивном режиме](https://code.claude.com/docs/ru/headless.md) с `--output-format stream-json` и через Agent SDK Claude Code выдает тот же текст в потоке сообщений как `system` сообщение с подтипом `notification`. Сообщение приходит один раз за ход, пока у вас закончились кредиты использования. Быстрый режим остается включенным.

## Исследовательское превью

Быстрый режим для Claude Opus 5 и Claude Opus 4.8 — это функция исследовательского превью. Это означает:

* Функция может измениться на основе отзывов
* Доступность и цены могут измениться
* Базовая конфигурация API может развиваться

Сообщайте о проблемах или отзывах через ваши обычные каналы поддержки Anthropic.
