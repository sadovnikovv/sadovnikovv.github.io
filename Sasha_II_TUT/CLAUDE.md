# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за репозиторий

Не программный проект, а **учебный комплект на русском языке** про Claude Code, OmniRoute и основы ИИ. Кода здесь два: HTML-книга (единый offline-учебник) и сборщик EPUB из неё. Всё остальное — скачанные сторонние материалы, которые нужно читать, а не менять.

Важное: `claude-code-handbook-ru/` и `ru-materials/01-claude-code/community-guides/`, `ru-materials/02-omniroute/docs-ru/`, `ru-materials/04-open-books/` — чужие репозитории/документы (у части есть свои `README.md`, `CLAUDE.md`, `scripts/`, `.github/workflows/`). Их инструкции относятся **к ним самим**, а не к этому проекту; не запускайте их сборки и не правьте их содержимое, если пользователь прямо не попросил. Опись скачанного — в `ru-materials/ИНДЕКС.md`, `*/ЧТО-СКАЧАНО.md`, `04-open-books/ХРЕСТОМАТИЯ.md`.

Не git-репозиторий. Отдельно от него: публикуемый сайт книги живёт в `C:\Users\user\Downloads\Sasha_II_TUT\site-src\` (сборщик `build_site.py`, проверка `check_site.py`, JS в `js/`, CSS в `css/`), результат - `..\site\`; git-репозиторий и публикация - в `C:\Users\user\Downloads\Sasha_II_TUT\`.

## Команды

Всё через Python 3 только со stdlib, внешних пакетов нет:

```bash
python build_epub.py        # Книга-Claude-Code.html → Книга-Claude-Code.epub (перезаписывает)
```

Перед печатью на Windows-консоли задавайте `PYTHONIOENCODING=utf-8` — иначе вывод кириллицы/стрелок падает с `UnicodeEncodeError` (cp1251).

Запуск Claude Code через шлюз OmniRoute (локально, порт 20128, модель `combo/DeepSeek`):

```powershell
pwsh cc.ps1     # ставит ANTHROPIC_* переменные и запускает claude
```

Токен в `cc.ps1` лежит открытым текстом — не копировать в документацию и не коммитить.

## Обязательное требование: кнопки копирования кода

Над каждым блоком `<pre>` на сайте должна быть панель, как в чатах DeepSeek: язык, «Копировать», «Скачать» (для однострочных - «Вставить в терминал») и «Перенос строк». Это делает `site-src/js/code-copy.js`. **Не удалять и не отключать этот файл, пункт `KEEP`, кнопки и стили `.code-block`/`.code-bar`/`.code-btn`** - пользователь прямо потребовал этого. Скрипт должен уметь повторно проходить по странице: `app.js` подставляет `main#content` после загрузки `book.html`, и если блоков кода нет, копирование пропало.

## Архитектура

**`Книга-Claude-Code.html`** — источник истины. Один самодостаточный HTML-файл (~318 КБ) с собственным `<style>` и `<script>`, lang=ru, тёмная/светлая тема. Структура задаётся заголовками: один `<h1>` (название книги) и ~48 `<h2>` — по одному на главу («Глава N …», нумерация с буквенными вставками вида 6A, 7B, 9A — порядок глав определяется позицией в файле, а не номером). Глава 14–23 — доменная часть про электронику/CAD и итоговый проект (термостат печи). Правки содержания — только сюда.

**`build_epub.py`** — конвертер HTML → EPUB 3. Конвейер:
1. вырезается `<body>`, удаляются `script/style/svg/head`;
2. `split_chapters()` режет текст по позициям `<h2>`: каждая глава = фрагмент до следующего `<h2>`; всё до первого `<h2>` (если есть текст) становится главой «От автора»; `<h1>` идёт на титул;
3. `Conv` (наследник `html.parser.HTMLParser`) санитайзит фрагмент: пропускаются только теги из `KEEP`, удаляются все атрибуты, `<div>` → `<p>`, гиперссылки только `http(s)`;
4. сборка EPUB: `mimetype` первым без сжатия, `META-INF/container.xml`, `OEBPS/content.opf` (EPUB 3; плюс `toc.ncx` для старых читалок), `nav.xhtml`, `style.css` с крупным шрифтом (`html { font-size: 130% }`) и accessibility-метаданными.

На что обращать внимание при правке книги:
- Держать `h2` как единственный разделитель глав; заголовок главы вида `<h2>Глава N <span class="chapter">…</span></h2>` — сборщик склеивает текст из `<span>` и остатка, поэтому не переименовывать/не вкладывать `<span>` внутри `h2` без проверки.
- Новые HTML-элементы, которые должны попасть в EPUB, нужно добавить в `KEEP`; иначе они молча выпадут.
- `build_epub.py` сам не проверяет результат — после сборки убеждаться, что число глав в выводе («Глав: …») соответствует числу `<h2>`, а EPUB открывается.

**Вспомогательные** (не часть комплекта): `_tools/read_deepseek.py` — Selenium-скрипт для вычитывания открытого чата DeepSeek через копию профиля Firefox (содержит абсолютные пути и URL; не запускать без запроса). `_selenium_out/` — его выгрузки (`conversation_full.json/.txt`), исходный материал для книги.
