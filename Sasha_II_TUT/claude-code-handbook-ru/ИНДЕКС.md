# Claude Code Handbook на русском

Полное практическое руководство по Claude Code на русском языке.

- Источник: https://github.com/sfrangulov/claude-code-handbook-ru
- Лицензия: CC0-1.0 (общественное достояние — можно свободно читать, копировать и распространять)
- Актуально на: 16 ноября 2026 (коммит в репозитории-источнике)

## Что в папке

| Файл | Что это |
|---|---|
| `README.md` | Основная книга: quickstart, harness, Skills, субагенты, оркестрация, методологии, Evals, Plugins, Hooks, Mods, MCP, шаблоны `CLAUDE.md`, строки состояния, мониторинг расходов |
| `llms-full.txt` | Весь текст одним файлом — удобно целиком передать ИИ-агенту в контекст |
| `docs/tips-ru.md` | Большой сборник практических советов |
| `docs/skill-families-ru.md` | Сравнение семейств скиллов: какой набор под какие задачи |
| `cheatsheet/cheatsheet.pdf` | Шпаргалка на один лист A4: горячие клавиши, слэш-команды, MCP, память, скиллы, агенты, флаги CLI |
| `LICENSE` | Текст лицензии CC0-1.0 |

## Как читать

- `README.md` и `docs/*.md` — любой Markdown-редактор. В VS Code: `Ctrl+Shift+V` (предпросмотр).
- `cheatsheet/cheatsheet.pdf` — любой PDF-просмотрщик, можно распечатать на A4.
- Начать лучше с разделов «С чего начать» и «Quickstart за 10 минут» в `README.md`.
