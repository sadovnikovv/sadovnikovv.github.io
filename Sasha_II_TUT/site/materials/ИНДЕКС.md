# Учебные материалы на русском: Claude Code + OmniRoute + основы ИИ

*Собрано 18.11.2026. Всё скачано локально, ссылки проверены в день сборки.*

Этот комплект **дополняет** ранее скачанную книгу `../claude-code-handbook-ru/` и закрывает три темы:

1. **Claude Code** — официальная документация на русском (205 страниц) и 9 community-гайдов.
2. **OmniRoute** — официальная русская документация (15 файлов) и практический разбор связки с Claude Code.
3. **ИИ для чайников** — собственный ликбез, бесплатные курсы, статьи и книги.

> **Читать как книгу:** откройте [`../Книга-Claude-Code.html`](../Книга-Claude-Code.html) — единое offline-пособие (редакция 2.0) с историей нейросетей, устройством трансформера, ландшафтом моделей, агентами, практикумом и библиотекой. Оно собирает все материалы в последовательный курс.
>
> **Открытая хрестоматия:** [`04-open-books/ХРЕСТОМАТИЯ.md`](04-open-books/ХРЕСТОМАТИЯ.md) — легально скачанные открытые книги и статьи arXiv для чтения без интернета.

## Что именно добавилось

### Claude Code

- **Официальная русская документация** — 205 страниц: quickstart, настройка, память, skills, субагенты, hooks, MCP, плагины, Agent SDK, стоимость, безопасность. Это первоисточник, а не пересказ.
- **`claude-code-pro-course`** (MIT) — 12 модулей, 8 лабораторных, starter kit и библиотека промптов.
- **`claude-code-konspekt`** — конспект четырёх курсов Anthropic Academy: 77 правил и 34 промпта.
- **`claude-howto-ru`** (MIT) — визуальные уроки со схемами.
- **`edgelab-claude-md`** — как писать `CLAUDE.md`, чтобы агент работал предсказуемо.
- **`claude-starter-kit`** — 8 готовых команд на русском.
- **`claude-skill-help-ru`** — скилл `/help-ru` со всеми командами.
- **`awesome-ai-devtools-ru`** (CC0) — каталог на 281 инструмент.
- **`state-of-ai`** — компактный гайд по агентной разработке.

### OmniRoute

- **15 файлов официальной русской документации**: quickstart, провайдеры, бесплатные тарифы, авто-комбо, настройка Claude Code, пользовательское руководство, стоимость, диагностика, MCP.
- **Практический разбор `cc.txt`**: что делает каждая переменная, как проверить связку, почему возникают 401/404/model not found, как безопасно хранить токен.

### Основы ИИ

- **`ИИ-для-чайников.md`** — собственный ликбез: ИИ vs ML vs нейросети vs LLM, токены, контекст, галлюцинации, промпты, агенты, RAG, безопасность, словарь.
- **`Курсы-книги-статьи.md`** — 8 бесплатных курсов Stepik, 13 статей Хабра, 7 книг, маршрут на неделю.

### Углублённый курс (в HTML-книге)

- **История нейросетей** — от формального нейрона 1943 года до трансформеров и reasoning-моделей.
- **Анатомия трансформера** — токены, эмбеддинги, attention, Q/K/V, MLP, логиты, sampling, KV-кэш, MoE.
- **Веса и биты** — параметры, обучение, форматы FP32/FP16/BF16/INT8/INT4, квантование, память.
- **Ландшафт моделей 2026** — семейства, бенчмарки, DeepSeek V4 и `flash-none`, уровни `none/low/high/max`.
- **Локальные модели** — Ollama, LM Studio, llama.cpp, vLLM, железо, качество, гибридная схема.
- **Токены и сжатие** — prompt caching, контекстная инженерия, экономия, мифы и лайфхаки.
- **Железо** — CPU/GPU/NPU, тензорные ядра, GEMM, prefill/decode, память, инференс-стек.
- **Агенты** — зачем нужны, паттерны, MCP, 18 популярных проектов GitHub со звёздами и лицензиями.
- **Оптимизация** — подборка статей Хабра и Пикабу с практическими выводами.
- **Вопросы и ответы** — 50 коротких ответов, закрывающих базовые пробелы.
- **Оплата DeepSeek из РФ** — способы пополнения, расчёт в рублях по вашей выгрузке, настройка ключа.
- **Перенос на новый компьютер** — журнал установки на Windows 10 1909: Chocolatey, npm, политика PowerShell, ошибки winget и OmniRoute.
- **Новый ПК: инструкция с нуля** — пошаговый маршрут: Chocolatey → Node.js → npm → Claude Code → OmniRoute → провайдер/комбо/ключ → `cc.ps1`.
- **Память, обучение и скиллы** — что сохраняется о пользователе, как работает компрессия, как вернуться в сессию, перенастроить и превратить опыт в `SKILL.md`.

### Открытая хрестоматия

- **`04-open-books/`** — легально скачанные открытые книги (Little Book of Deep Learning, Mathematics for Machine Learning, Dive into Deep Learning) и 10 статей arXiv, включая Attention Is All You Need, DeepSeek-V3, DeepSeek-R1, LoRA, FlashAttention, vLLM.

## Важные оговорки

1. **Переводы OmniRoute машинные.** Смысл передан, но формулировки местами корявые. Для точных деталей сверяйтесь с английским оригиналом.
2. **Официальная документация Claude Code переведена не на 100%.** Отдельные заголовки и термины остались на английском.
3. **Часть community-репозиториев без лицензии.** Для личного обучения — можно; для публикации — нужно разрешение автора.
4. **Скачанный код не запускался.** Плагины, скиллы и скрипты из репозиториев проверяйте перед установкой.
5. **В `cc.txt` лежит токен открытым текстом.** Не передавайте файл третьим лицам; при утечке перевыпустите ключ в панели OmniRoute.
6. **Бесплатные курсы и тарифы меняются.** Список курсов Stepik проверен 18.11.2026; доступность бесплатных провайдеров OmniRoute — смотрите `FREE-TIERS-GUIDE.md` и панель.
