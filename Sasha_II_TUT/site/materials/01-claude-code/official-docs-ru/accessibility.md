# Использование Claude Code с программой чтения с экрана

> Настройте Claude Code для программ чтения с экрана, таких как VoiceOver и NVDA, а также параметры для увеличения экрана, уменьшения движения и тем, удобных для дальтоников.

Claude Code имеет режим программы чтения с экрана, который заменяет его визуальный интерфейс терминала простым линейным текстом. Вместо прямоугольников, анимаций прогресса и перерисовок на месте Claude Code выводит помеченные строки, которые программа чтения с экрана, такая как VoiceOver или NVDA, читает по порядку. Вы можете вести полный диалог, одобрять разрешения инструментов и просматривать выходные данные от начала до конца.

Режим программы чтения с экрана является дополнительным. Если вы используете увеличитель экрана, уменьшение движения или тему, удобную для дальтоников, вместо программы чтения с экрана, установите `CLAUDE_CODE_ACCESSIBILITY`, `prefersReducedMotion` или `theme` из таблицы [Параметры доступности](#accessibility-settings). Режим программы чтения с экрана адаптирует только интерфейс терминала, поэтому вам не нужен он в панели чата расширения VS Code. В Claude Code v2.1.236 или более поздней версии расширение [объявляет активность диалога вашей программе чтения с экрана](https://code.claude.com/docs/ru/vs-code.md#use-a-screen-reader) там без каких-либо параметров.

## Включение режима программы чтения с экрана

Выберите метод, который соответствует тому, как часто вы используете программу чтения с экрана:

* Для одной сессии: запустите `claude --ax-screen-reader`.
* Для сессий, запущенных из одной оболочки: установите переменную окружения `CLAUDE_AX_SCREEN_READER` на `1`. В Bash или Zsh запустите `export CLAUDE_AX_SCREEN_READER=1`. В PowerShell запустите `$env:CLAUDE_AX_SCREEN_READER = "1"`. Добавьте эту строку в профиль оболочки, чтобы сохранить её для будущих оболочек.
* Для каждой сессии на машине: добавьте `"axScreenReader": true` в ваш пользовательский [файл настроек](https://code.claude.com/docs/ru/settings.md). Настройка применяется в любом терминале, включая интегрированный терминал VS Code.

Если вы комбинируете методы, Claude Code отдаёт приоритет флагу [`--ax-screen-reader`](https://code.claude.com/docs/ru/cli-reference#cli-flags) над переменной окружения [`CLAUDE_AX_SCREEN_READER`](https://code.claude.com/docs/ru/env-vars#variables), а переменной — над настройкой [`axScreenReader`](https://code.claude.com/docs/ru/settings-reference#axscreenreader).

Если вы используете Claude Code через SSH, установите переменную окружения или настройку на удаленной машине, где работает Claude Code.

Первая строка, которую выводит Claude Code, подтверждает режим: `[Screen Reader Mode: on via flag]`, `[Screen Reader Mode: on via env]` или `[Screen Reader Mode: on via settings]`.

### Настройки проекта не могут включить режим программы чтения с экрана

Строка при запуске `Screen reader mode is off: project settings can't turn it on` означает, что проект запросил режим программы чтения с экрана, но ничто другое его не включает. Claude Code игнорирует как ключ `axScreenReader`, так и значение `CLAUDE_AX_SCREEN_READER` в разделе `env` в файлах проекта `.claude/settings.json` и `.claude/settings.local.json`, каким бы ни было их значение.

* **Чтобы включить режим**: запустите Claude Code с `--ax-screen-reader`, установите `CLAUDE_AX_SCREEN_READER` на `1` в вашей оболочке или добавьте `"axScreenReader": true` в ваш пользовательский [файл настроек](https://code.claude.com/docs/ru/settings.md) и перезапустите Claude Code. Изменять файлы проекта не нужно. После включения режима при запуске вместо этого появится [строка подтверждения](#turn-on-screen-reader-mode).
* **Если вы не используете программу чтения с экрана**: ничего делать не нужно. Чтобы эта строка больше не появлялась, добавьте `"axScreenReader": false` в ваш пользовательский файл настроек или удалите ключ `axScreenReader` и переменную `CLAUDE_AX_SCREEN_READER` из файлов настроек проекта.

## Отключение режима программы чтения с экрана

Отмените любой метод, который включил режим: запустите без флага, удалите переменную окружения или задайте для `axScreenReader` значение `false` в файле пользовательских настроек. Если вы установите `CLAUDE_AX_SCREEN_READER` на `0`, Claude Code сохраняет режим отключенным даже когда параметр имеет значение `true`.

## Параметры доступности

Таблица перечисляет каждый параметр доступности, устанавливаете ли вы его как флаг, переменную окружения или параметр, и что он изменяет.

| Параметр | Тип | Что он изменяет |
| :- | :- | :- |
| [`--ax-screen-reader`](https://code.claude.com/docs/ru/cli-reference#cli-flags) | Флаг | Режим программы чтения с экрана для одного сеанса. |
| [`CLAUDE_AX_SCREEN_READER`](https://code.claude.com/docs/ru/env-vars#variables) | Переменная окружения | Режим программы чтения с экрана для сеансов, запущенных из оболочки, где вы его установили. |
| [`axScreenReader`](https://code.claude.com/docs/ru/settings-reference#axscreenreader) | Параметр | Режим программы чтения с экрана для каждого сеанса, когда `true`. |
| [`CLAUDE_AX_STARTUP_QUIET_MS`](https://code.claude.com/docs/ru/env-vars#variables) | Переменная окружения | Как долго Claude Code ждёт после строки подтверждения перед тем, как нарисовать первую подсказку в режиме программы чтения с экрана. Требует Claude Code v2.1.217 или более поздней версии. |
| [`CLAUDE_AX_PREPARK_MS`](https://code.claude.com/docs/ru/env-vars#variables) | Переменная окружения | Если задана, сколько миллисекунд Claude Code удерживает курсор терминала в начале текущей строки перед тем, как написать новую или изменённую строку в режиме программы чтения с экрана. Требует Claude Code v2.1.233 или более поздней версии. |
| [`CLAUDE_CODE_ACCESSIBILITY`](https://code.claude.com/docs/ru/env-vars#variables) | Переменная окружения | Курсор терминала, который остаётся видимым для увеличителей экрана, таких как macOS Zoom, когда вы установите его на `1`. Курсор следует за кареткой ввода и, в Claude Code v2.1.218 или более поздней версии, за выделённой строкой в меню и панелях, таких как `/config` и `/plugin`. |
| [`prefersReducedMotion`](https://code.claude.com/docs/ru/settings-reference#prefersreducedmotion) | Параметр | Уменьшенные или отсутствующие спиннеры, мерцание и другие анимации, когда `true`. |
| [`theme`](https://code.claude.com/docs/ru/settings-reference#theme) | Параметр | Цвета интерфейса, включая удобные для дальтоников темы `dark-daltonized` и `light-daltonized`. Вы также можете выбрать одну с помощью [`/theme`](https://code.claude.com/docs/ru/commands#all-commands). |
| [`preferredNotifChannel`](https://code.claude.com/docs/ru/settings-reference#preferrednotifchannel) | Параметр | С значением `"terminal_bell"`, звонок терминала вне режима программы чтения с экрана, когда Claude ждёт вас. |

## Что слышит ваша программа чтения с экрана

В режиме программы чтения с экрана Claude Code выводит плоский текст:

* Нет символов рисования прямоугольников для интерфейса
* Нет подсказок только по цвету
* Нет перерисовок содержимого, которое не изменилось. Спиннеры прогресса отображаются как статический текст
* Таблицы в ответах Claude читаются как предложения `Header: value` вместо сетки с символами рисования прямоугольников
* Diff читаются как обычный текст, построчно, где `+` и `-` обозначают добавленные и удалённые строки, поэтому вы можете прослушать предлагаемое изменение в запросе подтверждения редактирования файла, прежде чем ответить на него

Claude Code оставляет всё, что он выводит, в буфере прокрутки вашего терминала, поэтому вы можете перечитать более ранние ходы с помощью команд просмотра вашей программы чтения с экрана или поиска вашего терминала. Claude Code игнорирует настройку [`tui`](https://code.claude.com/docs/ru/settings-reference#tui) в режиме программы чтения с экрана. Кроме присоединённых фоновых сессий, перечисленных в разделе [Известные ограничения](#known-limitations), он выводит прокручиваемый текст вместо [полноэкранного отображения](https://code.claude.com/docs/ru/fullscreen.md).

После того как Claude Code выводит [строку подтверждения](#turn-on-screen-reader-mode) при запуске, он ждёт 3 секунды, прежде чем отрисовать промпт, чтобы ваша программа чтения с экрана могла дочитать строку. Нажмите любую клавишу, чтобы завершить ожидание. Чтобы изменить длительность ожидания, задайте [`CLAUDE_AX_STARTUP_QUIET_MS`](https://code.claude.com/docs/ru/env-vars#variables).

Каждое сообщение в транскрипте начинается с метки, которую объявляет ваша программа чтения с экрана и которая называет, что это: ваши сообщения, ответы и размышления Claude, активность инструментов, ошибки и предупреждения, а также промпты. Метки также доступны для поиска, поэтому вы можете переходить между разделами транскрипта, выполняя поиск в буфере прокрутки вашего терминала:

| Метка | Значение |
| :- | :- |
| `you:` | Ваши сообщения |
| `claude:` | Ответы Claude |
| `thinking:` | Размышления Claude |
| `tool:` | Активность инструмента, такая как редактирование файла или запуск команды |
| `tool error:` | Инструмент, завершившийся с ошибкой |
| `error:` | Ошибка в диалоге, такая как неудачный запрос API |
| `warning:` | Предупреждение от Claude Code, такое как переключение на резервную модель |
| `Permission Required:` | Запрос разрешения, ожидающий вашего ответа |
| `Cost:` | Сводка стоимости сессии при выходе Claude Code, если ваша учётная запись [показывает затраты](https://code.claude.com/docs/ru/costs.md) |

Claude Code удерживает курсор терминала на каретке ввода, поэтому команда чтения текущей строки вашей программы чтения с экрана читает промпт, который вы редактируете. Когда вы вводите текст в конце строки ввода или нажимаете `Backspace` там, Claude Code выводит только символы, которые изменились. Ваша программа чтения с экрана повторяет только эти символы.

Когда вы удаляете слово или строку с помощью одного из [сочетаний клавиш редактирования текста](https://code.claude.com/docs/ru/interactive-mode.md#text-editing), Claude Code объявляет удалённый текст:

* Удаление слов с помощью `Ctrl+W` или `Alt+D`, или с помощью `Option+Delete` на macOS или `Ctrl+Backspace` на Windows
* Удаление до начала строки с помощью `Ctrl+U` или `Cmd+Backspace`
* Удаление до конца строки с помощью `Ctrl+K`

Когда вы переключаете [режимы разрешений](https://code.claude.com/docs/ru/permission-modes.md) с помощью `Shift+Tab`, Claude Code объявляет режим разрешений, на котором вы остановились, например `[plan mode on]` или `[accept edits on]`. Claude Code выводит объявление один раз и не повторяет его при последующих перерисовках.

### Чтение более раннего вывода без потери позиции

Если ваша программа чтения с экрана перескакивает обратно к промпту, пока вы читаете более ранний вывод, значит, она следует за курсором терминала. Claude Code перемещает курсор терминала обратно к промпту каждый раз, когда выводит новый текст.

Чтобы сохранить позицию во время чтения, отключите в программе чтения с экрана следование за курсором терминала. В NVDA нажмите `NVDA+6`, чтобы курсор просмотра перестал следовать за курсором терминала. Нажмите `NVDA+6` ещё раз, чтобы снова включить следование.

### Переход между ходами

Claude Code выводит маркеры интеграции оболочки OSC 133 на границах ходов, поэтому клавиша перехода к предыдущему промпту в вашем терминале перемещает между ходами без чтения всего транскрипта:

* iTerm2: Cmd+Shift+Up
* Терминал VS Code: Ctrl+Up на Windows, Cmd+Up на macOS
* Windows Terminal: нет клавиши по умолчанию; привяжите действие `scrollToMark` в его настройках
* Kitty и Ghostty: найдите в документации терминала его клавишу перехода к промпту

macOS Terminal не реагирует на маркеры, а Claude Code не выводит их в WezTerm. В этих терминалах вместо этого выполните поиск в буфере прокрутки по метке `you:`.

## Ответ на меню и подсказки

В режиме программы чтения с экрана меню, которыми вы обычно навигируете с помощью клавиш со стрелками, включая подсказки разрешения, становятся нумерованными списками. Claude Code объявляет каждый параметр как нумерованную строку, затем подсказку `Select with numbers`, которая называет допустимый диапазон. Введите номер нужного параметра и нажмите Enter.

* Нажмите Escape, чтобы отменить меню, чья подсказка заканчивается на `or Escape to cancel`.
* Если вы введёте номер, которого нет в списке, Claude Code объявляет допустимый диапазон и позволяет вам попробовать снова.

Селектор [`/effort`](https://code.claude.com/docs/ru/model-config#adjust-effort-level), который является ползунком вне режима программы чтения с экрана, становится тем же видом нумерованного списка.

Подсказки да-или-нет запрашивают введённый ответ вместо меню с двумя параметрами. Ответьте `y` или `n` и нажмите Enter. `yes` и `no` также работают.

## Услышьте, когда Claude Code нуждается в вас

В режиме программы чтения с экрана Claude Code звонит в звонок терминала, когда ему нужно ваше внимание, поэтому вам не нужно постоянно проверять стенограмму. Звонок звонит, когда:

* Claude завершает ответ
* Подсказка или диалог нуждается в вашем ответе, такой как подсказка разрешения
* Инструмент, который работал дольше 5 секунд, завершается

Звонок - это стандартный сигнал тревоги вашего терминала. Чтобы отключить его, измените параметр звонка в приложении вашего терминала. Вне режима программы чтения с экрана установите [`preferredNotifChannel`](https://code.claude.com/docs/ru/settings-reference#preferrednotifchannel) на `"terminal_bell"`, чтобы получить [аналогичный звонок](https://code.claude.com/docs/ru/terminal-config.md#get-a-terminal-bell-or-notification), когда Claude ждёт вас.

## Известные ограничения

Некоторые поведения не адаптированы для режима программы чтения с экрана:

* Режим программы чтения с экрана не включается автоматически при запуске программы чтения с экрана.
* Claude Code не объявляет изменение режима разрешений, сделанное с помощью команды, например вход в [режим планирования](https://code.claude.com/docs/ru/permission-modes.md#analyze-before-you-edit-with-plan-mode) с помощью `/plan`.
* Присоединение к [фоновому сеансу](https://code.claude.com/docs/ru/agent-view.md) с помощью `claude attach` или из представления агента входит в альтернативный экран терминала, который не имеет собственного буфера прокрутки. Это [то же поведение, что и для других присоединённых сеансов](https://code.claude.com/docs/ru/fullscreen.md). Чтобы выйти, нажмите Left Arrow на пустой подсказке или Ctrl+Z, если диалог имеет фокус.
* Claude Code объявляет затраты в сводке, которую он выводит при выходе, а не за ход.
* Режим программы чтения с экрана не изменяет [неинтерактивный режим](https://code.claude.com/docs/ru/headless.md) с флагом `-p`. Неинтерактивный режим уже выводит простой текст и остаётся альтернативой для написания скриптов.

## Сообщить о проблеме

Если что-то не работает с вашей программой чтения с экрана, увеличителем или терминалом, откройте проблему на [трекере проблем Claude Code](https://github.com/anthropics/claude-code/issues) и упомяните вашу вспомогательную технологию в заголовке. Включите вашу операционную систему, приложение терминала и имя и версию вспомогательной технологии в отчёт.
