Нулевое хранение данных #

Узнайте о нулевом хранении данных (ZDR) для Claude Code, доступном для квалифицированных учетных записей на Claude for Enterprise, включая область действия, отключенные функции и способы запроса активации.

Нулевое хранение данных (ZDR) для Claude Code доступно для квалифицированных учетных записей на Claude for Enterprise. Когда ZDR включен, промпты и ответы модели, созданные во время сессий Claude Code, обрабатываются в реальном времени и не сохраняются Anthropic после возврата ответа, за исключением случаев, когда это необходимо для соответствия закону или борьбы со злоупотреблениями.

[!NOTE]

ZDR не включен в стандартный план Claude for Enterprise и не может быть включен из настроек администратора. Он доступен для квалифицированных учетных записей и требует отдельной активации от Anthropic. Если ваша организация требует ZDR, свяжитесь с отделом продаж или с вашей командой учетных записей Anthropic, чтобы подтвердить соответствие требованиям.

Организации Claude for Enterprise, в которых включён HIPAA, могут распространить действие соглашения о деловом партнёрстве (Business Associate Agreement, BAA) на Claude Code CLI и вкладку Code в Claude Desktop без ZDR после того, как конфигурация HIPAA будет применена к Claude Code (локальный режим) и Cowork (локальный режим). См. Настройка Claude Code (локальный режим) для организации, готовой к HIPAA. Организациям без конфигурации HIPAA по-прежнему требуется ZDR, чтобы на Claude Code распространялось соглашение BAA. Список подходящих сервисов (Eligible Services) см. в руководстве по внедрению.

ZDR на Claude for Enterprise дает корпоративным клиентам возможность использовать Claude Code с нулевым хранением данных и получать доступ к административным возможностям:

  • Контроль затрат на пользователя
  • Панель управления Analytics
  • Настройки, управляемые сервером
  • Журналы аудита

ZDR для Claude Code на Claude for Enterprise применяется только к прямой платформе Anthropic. Для развёртываний Claude на Amazon Bedrock, Google Cloud's Agent Platform или Microsoft Foundry обратитесь к политикам хранения данных этих платформ.

Область применения ZDR #

ZDR охватывает вывод Claude Code на Claude for Enterprise.

[!WARNING]

ZDR включается на основе организации. Каждая новая организация требует отдельной активации ZDR вашей командой учета Anthropic. ZDR не применяется автоматически к новым организациям, созданным в рамках одного и того же аккаунта. Свяжитесь с вашей командой учета, чтобы включить ZDR для любых новых организаций.

Маршрутизация трафика Claude Code в вашу организацию ZDR #

ZDR применяется к запросам, которые аутентифицируются в организации с включенным ZDR. Если разработчик входит в Claude Code с личным аккаунтом или с API ключом из другой организации, эти сеансы не охватываются. Чтобы требовать, чтобы входы разработчиков в claude.ai принадлежали вашей организации ZDR, разверните управляемые параметры forceLoginMethod и forceLoginOrgUUID; см. Ограничение входа на вашу организацию, которая также объясняет, как эти ключи обрабатывают входы в Claude Console.

Что охватывает ZDR #

ZDR охватывает вызовы вывода модели, сделанные через Claude Code на Claude for Enterprise. Когда вы используете Claude Code в своем терминале, отправляемые вами запросы и ответы, которые генерирует Claude, не сохраняются Anthropic. Это применяется ко всем моделям, доступным вашей организации ZDR. Некоторые модели требуют хранения данных по умолчанию; см. Доступность моделей в рамках ZDR.

Что не охватывает ZDR #

ZDR не распространяется на следующее, даже для организаций с включенным ZDR. Если в строке не указано иное, эти функции следуют стандартным политикам хранения данных:

| Функция | Детали | | - | - | | Chat на claude.ai | Чат-беседы через веб-интерфейс Claude for Enterprise не охватываются ZDR. | | Cowork | Сеансы Cowork не охватываются ZDR. | | Артефакты | Артефакты в диалогах чата и сессиях Cowork не охватываются ZDR и хранятся до удаления, если только ваша организация не установила для них срок хранения. Артефакты недоступны в Claude Code с ZDR. | | Claude in Chrome | Браузерное расширение Claude in Chrome не охватывается ZDR. Оно недоступно в Claude Code с ZDR, но участники по-прежнему могут использовать его вне Claude Code, если ваша организация это разрешает. | | Claude Code Analytics | Не сохраняет запросы или ответы модели, но собирает метаданные производительности, такие как адреса электронной почты аккаунтов и статистику использования. Метрики вклада недоступны для организаций ZDR; панель управления аналитикой показывает только метрики использования. | | Управление пользователями и местами | Административные данные, такие как адреса электронной почты аккаунтов и назначения мест, сохраняются в соответствии со стандартными политиками. | | Интеграции третьих сторон | Данные, обработанные инструментами третьих сторон, MCP servers или другими внешними интеграциями, не охватываются ZDR. Независимо проверьте практики обработки данных этих сервисов. |

Функции, отключенные под ZDR #

Когда ZDR включен для организации Claude Code на Claude for Enterprise, определенные функции, которые требуют сохранения запросов или завершений, автоматически отключаются на уровне бэкенда:

| Функция | Причина | | - | - | | Cloud sessions, включая те, которые запущены из приложения Desktop | Требует серверного хранилища данных сеанса, включая историю беседы с запросами и завершениями. | | Единый интерфейс Chat и Cowork | Требует облачных сессий. | | Claude Tag | Сохраняет память канала и стенограммы сеансов. | | Артефакты в Claude Code | Требует сохранения опубликованного содержимого страницы на инфраструктуре, управляемой Anthropic. | | Claude Docs | Требует сохранения содержимого документов на инфраструктуре, управляемой Anthropic. | | Отправка отзыва (/feedback, /bug, /share) | Отправка отзыва отправляет данные беседы в Anthropic. | | Remote Control | Сохраняет стенограмму сеанса на серверах Anthropic для синхронизации беседы между устройствами. |

Эти функции блокируются на бэкенде независимо от отображения на стороне клиента. Если вы видите отключенную функцию в терминале Claude Code при запуске, попытка использовать ее возвращает ошибку, указывающую на то, что политики организации не позволяют это действие.

Будущие функции также могут быть отключены, если они требуют сохранения запросов или завершений.

Доступность моделей под ZDR #

Claude Fable 5.2, Fable 5.1 и Fable 5 — это Covered Models, которые требуют сохранения данных по умолчанию, и то, может ли организация или рабочее пространство ZDR использовать их, регулируется политиками Covered Models, а не Claude Code. Если ваша организация не может их использовать, модели либо отсутствуют в средстве выбора /model, либо отображаются как отключенные, и сервер отклоняет запросы для них независимо от конфигурации клиента.

Другие модели остаются доступными под ZDR. Модели Fable не являются моделями по умолчанию, а псевдоним best разрешается в Opus.

Хранение данных при нарушении политики #

Даже с включенным ZDR, Anthropic может сохранять данные, если это требуется по закону или для решения нарушений политики использования. Если сеанс отмечен как нарушение политики, Anthropic может сохранить связанные входные и выходные данные на срок до 2 лет, в соответствии со стандартной политикой ZDR Anthropic.

Запрос ZDR #

Чтобы запросить ZDR для Claude Code на Claude for Enterprise, свяжитесь с отделом продаж или с вашей командой учета Anthropic. Ваша команда учета отправит запрос внутри компании, и Anthropic проверит и включит ZDR в вашей организации после подтверждения соответствия требованиям. Все действия по активации регистрируются в журнале аудита.

Если вы в настоящее время используете ZDR для Claude Code через ключи API с оплатой по мере использования, вы можете перейти на Claude for Enterprise, чтобы получить доступ к административным функциям, сохраняя ZDR для Claude Code. Свяжитесь с вашей командой учета, чтобы координировать миграцию.
