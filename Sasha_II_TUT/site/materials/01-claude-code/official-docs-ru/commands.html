Команды #

Полный справочник команд, доступных в Claude Code, включая встроенные команды и встроенные skills.

Команды управляют Claude Code внутри сеанса. Они предоставляют быстрый способ переключения моделей, управления разрешениями, очистки контекста, запуска рабочего процесса и многого другого.

Введите / для просмотра доступных вам команд или введите / с последующими буквами для фильтрации. Как меню команд соответствует тому, что вы вводите охватывает выделение, опечатки и несколько команд, которые Claude Code скрывает из меню до тех пор, пока вы не введете их полное имя.

Команда распознается только в начале вашего сообщения. Текст, следующий за именем команды, становится её аргументами. В промпте терминала вы можете начать одно сообщение с нескольких скиллов: ввод /skill-a /skill-b do XYZ загружает оба скилла и передает завершающий текст каждому из них в качестве аргументов. Можно объединить в цепочку до шести скиллов.

Если вы отправите команду, пока Claude отвечает, Claude Code ставит её в очередь и запускает после завершения текущего хода. Claude Code запускает некоторые команды немедленно без прерывания ответа, такие как /status, /tasks и /usage. В полноэкранном режиме отображения Claude Code также открывает диалоговые команды, такие как /theme и /help, немедленно. До версии 2.1.234 Claude Code ставил эти диалоги в очередь до завершения хода.

Команды в типичном рабочем процессе #

Большинство команд полезны на определённом этапе сеанса, от настройки проекта до развёртывания изменений.

Первый сеанс в репозитории. Запустите /init для создания стартового файла CLAUDE.md, затем /memory для его уточнения. Используйте /mcp для настройки любых серверов, которые нужны проекту, попросите Claude создать любых подагентов, которые вам нужны, и запустите /permissions для установки правил одобрения.

Во время задачи. /plan переключает в режим планирования перед крупным изменением. /model и /effort регулируют, какую модель вы используете и сколько рассуждений она применяет. Когда разговор становится длинным, /context показывает, что заполняет окно, а /compact суммирует его, чтобы освободить место. Используйте /btw для побочного вопроса, который не должен добавляться в историю разговора.

Запустите работу параллельно. Claude делегирует побочные задачи подагентам, а /tasks выводит список фоновой работы текущего сеанса, включая завершённых подагентов. /background отделяет весь сеанс, чтобы он продолжал работать как фоновый агент и освобождает ваш терминал. Для крупного изменения, охватывающего всю кодовую базу, /batch разбивает его на независимые единицы и запускает каждую в своём worktree. Смотрите Запуск агентов параллельно, чтобы понять, как эти подходы связаны.

Перед развёртыванием. /diff показывает, что изменилось. /code-review проверяет текущий diff на ошибки корректности и может применить результаты с помощью --fix; передайте номер PR, например /code-review high 1234, чтобы вместо этого проверить pull request. /review — это псевдоним. /code-review ultra запускает многоагентную проверку в облаке. /security-review проверяет diff на уязвимости безопасности.

Между сессиями. /clear начинает заново с новой задачи, сохраняя память проекта. /resume возвращает к более ранней беседе, /branch ветвит текущую, чтобы попробовать другое направление, а /fork копирует её в новую фоновую сессию. /teleport переносит облачную сессию в этот терминал, а /remote-control позволяет продолжить эту локальную сессию с другого устройства.

Когда что-то не так. /rewind откатывает код и разговор к контрольной точке или суммирует часть разговора. /doctor запускает проверку настройки, которая диагностирует проблемы установки и конфигурации и может их исправить, /debug диагностирует проблемы во время выполнения, а /feedback сообщает об ошибке с контекстом сеанса.

Все команды #

В таблице ниже перечислены все команды, входящие в Claude Code. Большинство из них — встроенные команды, поведение которых запрограммировано в CLI. Отмечены записи двух видов:

  • Скилл: встроенный скилл. Он работает так же, как скиллы, которые вы пишете сами: это промпт, передаваемый Claude.
  • Рабочий процесс: встроенный динамический рабочий процесс, который распределяет работу между множеством субагентов и выполняется в фоновом режиме.

Чтобы добавить собственные команды, см. скиллы.

В таблице ниже <arg> обозначает обязательный аргумент, а [arg] — необязательный.

[!NOTE]

Не каждая команда отображается у каждого пользователя. Доступность зависит от вашей платформы, тарифа и окружения. Например, /desktop отображается только на macOS и Windows x64 при входе с подпиской Claude, а /upgrade не отображается на тарифах Enterprise.

Как меню команд соответствует вводимому тексту #

Claude Code фильтрует меню / по мере ввода. Каждый пункт ниже охватывает одну вещь, которую вы можете заметить при фильтрации:

  • Выделение: Claude Code выделяет только верхнее предложение, когда буквы после / совпадают с именем команды или её псевдонимом, начиная с начала имени или с слова внутри него, игнорируя разделители :, _ и -. Ввод /adddir выделяет /add-dir, а ввод /new выделяет /clear через его псевдоним. Нажмите Enter для запуска выделенного предложения. Эти правила выделения требуют Claude Code v2.1.236 или более поздней версии.
  • После опечатки: Claude Code ничего не выделяет. Близкие совпадения остаются в списке, и вы можете выбрать одно с помощью Tab или клавиш со стрелками, но Enter отправляет ваш текст в том виде, в котором он был введён, и сообщает об Unknown command.
  • Команды, которые вам недоступны: Claude Code исключает их из меню. Когда ничего не совпадает, Claude Code показывает No commands match "/name". Большинство недоступных команд возвращают Unknown command при отправке; некоторые, такие как /schedule на ключе Console API, вместо этого отвечают собственным сообщением о доступности. Некоторые команды также отвечают собственным сообщением, когда политика вашей организации их отключает.
  • Скрытые команды: Claude Code намеренно исключает несколько доступных команд, таких как /heapdump, из меню. Частичное имя никогда не выводит скрытую команду в меню: если частичное совпадение не соответствует ничему видимому, Claude Code показывает то же сообщение об отсутствии совпадения. Claude Code выводит команду в список только после того, как вы введёте её полное имя, и отправка полного имени запускает её.
