# Тестирование iOS приложений в симуляторе

> Claude Code Desktop открывает ваше приложение в панели iOS Simulator, когда Claude собирает, запускает или проверяет его.

> [!NOTE]
>
> Панель iOS Simulator находится в публичной бета-версии в Claude Code Desktop на macOS. Она доступна в планах Pro, Max, Ultra, Team и Enterprise, за исключением организаций Enterprise с включённой конфигурацией HIPAA. Она недоступна, если вы используете [стороннего провайдера](https://code.claude.com/docs/ru/third-party-integrations.md).

Панель iOS Simulator показывает ваше приложение, работающее в Apple iOS Simulator рядом с вашей беседой в Claude Code Desktop. Когда Claude собирает, устанавливает, запускает или проверяет ваше приложение в симуляторе, панель открывается автоматически и транслирует экран устройства в реальном времени. Используйте её, чтобы наблюдать, как Claude запускает и тестирует ваше приложение, или чтобы самостоятельно взаимодействовать с приложением, пока Claude продолжает работать.

Панель симулятора управляет симулятором напрямую, поэтому ей не требуется [компьютерное управление](https://code.claude.com/docs/ru/desktop.md#let-claude-use-your-computer) и она никогда не захватывает ваш экран и не скрывает другие окна. Из CLI Claude получает доступ к iOS Simulator через [компьютерное управление](https://code.claude.com/docs/ru/computer-use.md#test-a-simulator-flow), которое управляет симулятором на вашем экране так же, как вы это делали бы с помощью мыши.

## Требования

Панель симулятора использует инструменты Apple для симулятора, которые не включены в приложение для рабочего стола. Перед началом сессии убедитесь, что у вас есть:

* Claude Desktop v1.24012.0 или позже
* Mac, так как Apple iOS Simulator работает только на macOS
* [Xcode](https://developer.apple.com/xcode/) с установленной платформой iOS, которая предоставляет устройства симулятора. Если Xcode ещё не показывает симуляторы, см. [Панель симулятора говорит, что симуляторы не найдены](#the-simulator-pane-says-no-simulators-were-found)
  * Рекомендуется Xcode 26.x или Xcode 27, и панель работает с обоими. Если у вас установлено более одного Xcode, см. [Выберите, какой Xcode использует панель симулятора](#choose-which-xcode-the-simulator-pane-uses)
  * Для тестирования на iPhone Duo вам нужен Xcode 27.1 или более поздней версии. О том, что ещё вам понадобится, см. [Тестирование приложения на iPhone Duo](#test-your-app-on-an-iphone-duo).

> [!NOTE]
>
> На этой странице "устройство" относится к симулированному iPhone или iPad, одному из тех же устройств симулятора, которыми вы управляете в Xcode в разделе **Window → Devices and Simulators**, а не к физическому оборудованию.

Панель симулятора доступна только в локальных сессиях. В [облачных](https://code.claude.com/docs/ru/desktop.md#run-long-running-tasks-in-the-cloud) и [SSH](https://code.claude.com/docs/ru/desktop.md#ssh-sessions) сессиях Claude работает на машине, которая не может получить доступ к симуляторам на вашем Mac.

### Выберите, какой Xcode использует панель симулятора

Если у вас установлено более одного Xcode, например Xcode 26.x рядом с Xcode 27, панель использует тот, на который указывает `xcode-select`. Чтобы использовать другую установку, выберите её по пути.

Например, если нужный вам Xcode установлен как `/Applications/Xcode-26.4.app`, выполните это в Terminal:

```bash theme={null}
sudo xcode-select -s /Applications/Xcode-26.4.app
```

Затем закройте и снова откройте Claude Desktop, чтобы панель использовала вновь выбранный Xcode.

Чтобы проверить, какая установка выбрана, выполните `xcode-select -p`. Она выведет папку Developer выбранной установки, например `/Applications/Xcode-26.4.app/Contents/Developer`.

## Запуск вашего приложения в симуляторе

Вам не нужна команда или настройка для открытия панели симулятора. Claude открывает её, когда запускает ваше приложение в симуляторе.

**1. Откройте ваш iOS проект**

В Claude Code Desktop откройте вкладку **Code** и начните сессию с папкой проекта вашего приложения в качестве [папки проекта](https://code.claude.com/docs/ru/desktop.md#start-a-session). Любой проект, который собирает приложение для iOS Simulator, подойдёт.

**2. Попросите Claude запустить или протестировать приложение**

Сформулируйте задачу вокруг запуска или проверки приложения. Например:

```text theme={null}
Build the app and run it in the simulator to check the onboarding flow.
```

**3. Наблюдайте приложение в панели симулятора**

Когда приложение запускается в симуляторе, панель iOS Simulator открывается рядом с беседой. В первый раз, когда Claude использует устройство, приложение для рабочего стола просит вас разрешить это; см. [Предоставьте Claude доступ к устройству](#grant-claude-access-to-a-device). Claude устанавливает приложение, взаимодействует с ним и читает экран, чтобы проверить свои собственные изменения, пока вы наблюдаете.

Когда ваш промпт касается просмотра приложения, например «выглядит ли новый экран правильно?», Claude запускает симулятор перед началом работы. После того как Claude исправит ошибку или изменит экран, попросите его проверить изменение.

Панель симулятора показывает то устройство, на котором приложение фактически запустилось. Чтобы протестировать на конкретном устройстве, назовите его в своем запросе, например "запустите его на симуляторе iPhone SE", и Claude будет нацеливаться на это устройство при сборке и запуске.

Устройство, которое Claude загружает, также появляется в приложении Apple Simulator, или в Device Hub на Xcode 27. Claude может установить приложение на устройство, которое вы уже загрузили.

Вы также можете открыть панель симулятора самостоятельно. После того как к сессии подключён симулятор или Claude Code обнаруживает работу над iOS-приложением, в строке заголовка сессии появляется кнопка **iOS Simulator**. Если панель ещё не показывает устройство, нажмите **Attach simulator** или выберите конкретное устройство из меню устройств рядом с ним; выбор выключенного устройства его загружает. Если Xcode или его симуляторы отсутствуют, панель показывает шаги настройки вместо этого и отмечает их по мере завершения.

## Управляйте симулятором самостоятельно

Панель симулятора интерактивна, а не только средство просмотра. Пока Claude работает или между задачами, вы можете:

* Касаться и проводить пальцем, щёлкая и перетаскивая на экран устройства
* Нажимать кнопки оборудования с теми же сочетаниями клавиш, что и приложение Apple Simulator: **Cmd+Shift+H** для Home, **Cmd+L** для блокировки, **Cmd+Up Arrow** и **Cmd+Down Arrow** для громкости
* Повернуть устройство на четверть оборота по часовой стрелке с помощью кнопки поворота или **Cmd+Right Arrow**
* Переключаться между устройствами, которые показывает панель, из меню устройств, которое перечисляет версию ОС каждого симулятора и загружено ли оно
* Сохранить снимок экрана с помощью **Cmd+S** или запись экрана с помощью **Cmd+R**, используя кнопки захвата панели или сочетания клавиш; файлы сохраняются на ваш Desktop
* Остановить трансляцию устройства без его выключения, нажав **Detach simulator**, что вернёт панель в состояние **Attach simulator**

Если на панели отображается меню **Display**, используйте его, чтобы настроить видеопоток от симулятора. Снизьте **Frame rate** или **Resolution**, если панель перегружает ваш Mac. Обе настройки изменяют способ отображения устройства панелью, а не способ работы приложения.

Вы и Claude управляете одним и тем же устройством, поэтому ваши касания изменяют состояние приложения, которое видит Claude. Чтобы Claude проверил конкретный экран, перейдите к нему, касаясь, затем попросите. Пока Claude управляет устройством, панель показывает значок **Claude is using this device** над экраном; воздержитесь от касания до тех пор, пока значок не исчезнет, чтобы результат отражал приложение, а не ваш ввод.

### Свернуть или закрыть панель симулятора

Вы можете свернуть или закрыть панель симулятора, и в любом случае Claude по-прежнему сможет использовать устройство.

* Если вы свернёте панель, устройство останется на виду в уменьшенном размере. Чтобы свернуть панель или снова развернуть её, см. [Свернуть панель](https://code.claude.com/docs/ru/desktop.md#minimize-a-pane).
* Если вы закроете полноразмерную или свёрнутую панель, устройство останется подключённым и запущенным. Чтобы снова показать устройство, нажмите **iOS Simulator** в заголовке окна сессии.

## Как сессии управляют устройствами

Если в вашем промпте не указан симулятор, Claude использует уже запущенный, даже если его открыла другая [параллельная сессия](https://code.claude.com/docs/ru/desktop.md#work-in-parallel-with-sessions). Чтобы у каждой сессии был собственный симулятор, укажите разные симуляторы в промпте каждой сессии.

Claude Code Desktop выключает симуляторы, которые он загрузил, как только они больше не используются: когда вы закрываете приложение, когда вы архивируете сессию или через 10 минут после отключения устройства от его панели. Устройства, которые вы загружаете вне Claude Code Desktop, например в приложении Apple Simulator или в Device Hub, никогда не выключаются автоматически. Чтобы выключить подключённое устройство прямо сейчас, используйте кнопку выключения в панели.

## Предоставьте Claude доступ к устройству

Claude просит ваше согласие перед управлением устройством, в то время как сборка или запуск приложения либо открытие URL на нём следуют режиму разрешений вашей сессии. Вы или ваша организация также можете полностью отключить доступ Claude.

### Разрешить устройство в первый раз

В первый раз, когда Claude использует симулятор, приложение для рабочего стола просит вас разрешить это. Согласие охватывает управление этим устройством и снятие скриншотов с него, и вы даёте его один раз на устройство, а не один раз на сессию. Скриншоты Claude устройства отправляются в Anthropic и хранятся в соответствии с вашими обычными настройками хранения беседы, поэтому не входите в реальные учётные записи на устройстве, которое использует Claude.

После того как вы разрешите устройство, действия Claude на нём, такие как касание, ввод текста и снятие скриншотов, выполняются без запросов разрешения, но запуск приложения вы подтверждаете так, как того требует ваш [режим разрешений](#actions-that-follow-your-permission-mode). Они имеют такой же уровень доверия, как если бы вы щёлкали в панели, и они касаются только симулированного устройства, поэтому панель не требует разрешений macOS Accessibility и Screen Recording, которые требует компьютерное управление.

Если вы отклоните запрос Claude, устройство не подключается, и Desktop не загружает его. Чтобы использовать устройство самостоятельно:

1. Нажмите **Attach simulator** в панели.
2. Нажмите **Continue** на экране разрешений.
3. Нажмите **Cancel** в появившемся затем диалоговом окне.

Устройство подключается и работает для ваших собственных касаний, а доступ Claude остаётся отключённым. После этого, чтобы предоставить Claude доступ, нажмите **Let Claude use it** в панели.

### Действия, которые следуют вашему режиму разрешений

Три действия следуют [режиму разрешений](https://code.claude.com/docs/ru/permissions.md#permission-modes) вашей сессии даже после того, как вы разрешите устройство:

* Открытие URL на устройстве, например для тестирования глубокой ссылки или загрузки страницы в Safari устройства, потому что URL может переносить данные с устройства.
* Сборка приложения, потому что `xcodebuild` запускает скрипты сборки вашего проекта на вашем Mac. Проверка уже выполняемой сборки не вызывает подсказку.
* Установка и запуск приложения, потому что Claude может запустить любое указанное им приложение, а не только то, которое вы собираете.

### Отключить доступ к симулятору

Вы можете отключить доступ Claude к симулятору в настройках приложения для рабочего стола. Организации имеют два способа отключить его для всех:

* Параметр `disableMobileSimulatorTools` [управляемая настройка](https://code.claude.com/docs/ru/desktop.md#managed-settings) блокирует инструменты симулятора Claude. Панель симулятора остаётся пригодной для ваших собственных касаний, и параметр не может быть переопределён из приложения.
* Ключ политики `requireCoworkFullVmSandbox`, который запускает инструменты Claude внутри изолированной виртуальной машины вместо вашего Mac, отключает панель симулятора и инструменты симулятора Claude полностью, поэтому панель не может подключить устройство, пока он установлен.

Claude сообщит вам, когда применяется любой из них.

## Тестирование приложения на iPhone Duo

Вы можете тестировать приложение на симуляторе iPhone Duo в панели симулятора и складывать устройство в каждое из его положений: закрытое, полуоткрытое и открытое. Для тестирования на нём вам потребуется:

* Claude Desktop v4.29.0 или новее — это более новая версия, чем v1.24012.0, которая требуется для самой панели симулятора. Чтобы обновиться, откройте **Claude > Check for Updates…**, а затем перезапустите приложение.
* Xcode 27.1 или новее со средой выполнения симулятора iOS, которая включает симулятор iPhone Duo. Для Xcode 27.1 это среда выполнения iOS 27.1. Если она отсутствует, [загрузите её в настройках Components в Xcode](https://developer.apple.com/documentation/xcode/downloading-and-installing-additional-xcode-components). Если у вас установлено несколько версий Xcode, [выберите Xcode 27.1 или новее](#choose-which-xcode-the-simulator-pane-uses).

Чтобы открыть iPhone Duo в панели, укажите его в своём промпте или [переключите панель на него самостоятельно](#control-the-simulator-yourself). Если в меню устройств ещё нет iPhone Duo, выберите **Add simulator…** в конце списка устройств и выберите тип устройства iPhone Duo.

Например, чтобы Claude проверил один экран вашего приложения в каждом положении:

```text theme={null}
Run the app on the iPhone Duo simulator and check the settings screen closed, half open, and open.
```

### Складывание iPhone Duo

* **Сложите его самостоятельно**: нажмите одну из трёх кнопок положения рядом с кнопкой поворота. Наведите указатель на кнопку, чтобы увидеть её название: **Closed**, **Half open** или **Open**. Чтобы задать угол между этими положениями, наведите указатель на кнопки положения, а затем перетащите ползунок, который появится над ними.
* **Попросите Claude сложить его**: попросите одно из трёх положений или угол шарнира в полуоткрытом положении от 1 до 179 градусов.

### Ожидайте запрос на экспорт скиллов агента Xcode

Перед проверкой макета на iPhone Duo Claude может спросить, нужно ли экспортировать скиллы агента Xcode в вашу [личную папку скиллов](https://code.claude.com/docs/ru/skills.md#where-skills-live). Эти скиллы поставляются вместе с Xcode, чтобы направлять агентов для написания кода, и как только они окажутся в этой папке, Claude Code будет загружать их и в других ваших проектах. Среди них есть скилл для подготовки макета вашего приложения к iPhone Duo.

## Ограничения

Claude управляет только симулированными устройствами и не может управлять физическим iPhone или iPad. Чтобы протестировать на нём, запустите приложение на нём из Xcode самостоятельно, затем опишите то, что вы видите, или прикрепите снимок экрана к беседе, чтобы Claude мог работать с ним.

## Troubleshooting

### Панель симулятора не открывается, когда Claude запускает приложение

Claude может не распознать, что вы хотели запустить или протестировать приложение, или инструменты симулятора могут отсутствовать. Проверьте следующее:

* Явно укажите цель, например "запустите приложение в iOS Simulator и взаимодействуйте с потоком регистрации".
* Подтвердите, что Xcode и iOS симуляторы установлены и что ваша версия Xcode соответствует [требованиям](#requirements).
* Если ваша организация управляет Claude Code, [инструменты симулятора могут быть отключены политикой](#turn-off-simulator-access).
* Если вы находитесь в организации Enterprise с включённой конфигурацией HIPAA или используете [стороннего провайдера](https://code.claude.com/docs/ru/third-party-integrations.md), панель симулятора вам недоступна.
* Панель симулятора требует Claude Desktop v1.24012.0 или позже. Откройте **Claude > Check for Updates…**, затем перезагрузите приложение.

### Панель симулятора говорит, что симуляторы не найдены

Xcode установлен, но не имеет iOS симуляторов для отображения. Панель симулятора показывает шаги настройки для выполнения и отмечает их по мере завершения каждого. Чтобы установить отсутствующую часть вручную, загрузите среду выполнения iOS симулятора из настроек Xcode или запустите `xcodebuild -downloadPlatform iOS`.
