Глава 25 Переменные, файлы, настройки

Где что лежит и как это устроено. Инженеру важно знать расположение, чтобы диагностировать и делать резервные копии.

25.1. Каталоги

%USERPROFILE%\.claude\
├── settings.json          # пользовательские настройки
├── CLAUDE.md              # личная память для всех проектов
├── agents\                # личные субагенты
├── skills\                # личные skills
├── plugins\               # плагины
├── projects\              # данные сессий
└── ...

проект\
├── CLAUDE.md              # память проекта
├── CLAUDE.local.md        # личная память проекта (в .gitignore)

    ├── settings.json      # настройки проекта (можно коммитить)

    ├── agents\

    └── hooks\

25.2. Приоритет настроек

Настройки применяются слоями. Если значение задано в нескольких местах, побеждает более специфичный слой. Типичный порядок (от высшего к низшему): управляемая политика, аргументы командной строки, локальные настройки проекта, общие настройки проекта, пользовательские настройки.

25.3. Пример settings.json

{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "model": "combo/DeepSeek",
  "permissions": {
    "defaultMode": "default",
    "allow": [
      "Read",
      "Bash(git status)",
      "Bash(git diff *)",
      "Bash(pio run *)"
    ],
    "deny": [
      "Bash(rm *)",
      "Bash(Remove-Item *)",
      "Read(./.env)",
      "Read(./secrets/**)"
    ]
  }
}

JSON строгий: комментарии и висячие запятые недопустимы. Ошибка в файле приводит к сообщению Settings Error при запуске.

25.5. Где хранить ключ

Вариант без открытого ключа в файле:

[Environment]::SetEnvironmentVariable(
  "ANTHROPIC_AUTH_TOKEN",
  "sk-ВАШ_КЛЮЧ",
  "User"
)

После этого перезапустите терминал. Переменная будет доступна во всех новых сессиях. Минус: ключ хранится в профиле пользователя; на общей машине это надо учитывать.

25.6. Резервное копирование

  • Проектные настройки и CLAUDE.md - в git.
  • Личные настройки - в защищённый архив.
  • Ключи - в менеджер секретов, не в архив с исходниками.
  • Перед экспериментами - коммит или копия папки.
