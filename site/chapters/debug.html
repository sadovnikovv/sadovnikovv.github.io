17.2. Захват и декодирование

Пример работы с sigrok-cli (синтаксис зависит от драйвера и версии; проверьте sigrok-cli -L):

sigrok-cli -d <driver> --channels D0,D1 --config samplerate=1m --samples 100000 -P i2c:scl=D0:sda=D1 -o capture.txt

Попросите агента разобрать файл: найти адрес устройства, регистры, ошибки ACK, сравнить с даташитом. Если захват сохранён как изображение, приложите его - модель умеет читать изображения и PDF.

17.3. SCPI: скрипт измерения

Многие современные приборы управляются командами SCPI. Пример на Python с PyVISA (прибор должен поддерживать VISA):

import pyvisa

rm = pyvisa.ResourceManager()
scope = rm.open_resource("USB0::0x1AB1::0x04CE::DS1ZA000000000::INSTR")
scope.timeout = 5000

print(scope.query("*IDN?"))
scope.write(":CHANnel1:DISPlay ON")
scope.write(":TIMebase:MAIN:SCALe 0.001")
data = scope.query_ascii_values(":MEASure:VPP? CHANnel1")
print("Vpp:", data)

Агент может написать такой скрипт, объяснить команды и обработать выгрузку. Но проверьте: модель прибора, набор команд, единицы, пределы входа.
