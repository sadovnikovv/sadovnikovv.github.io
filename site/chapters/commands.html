Глава 24 Команды и флаги

Краткий справочник. Полные списки - в официальной документации: cli-reference.md, commands.md, interactive-mode.md.

24.1. Запуск CLI

КомандаЧто делает
claudeИнтерактивная сессия
claude "запрос"Сессия с начальным промптом
claude -p "запрос"Неинтерактивный режим, ответ в stdout
claude -cПродолжить последнюю сессию
claude -r "имя"Возобновить сессию по имени или ID
claude updateОбновить
claude doctorДиагностика установки
claude auth loginВход в аккаунт Anthropic
claude auth statusСтатус авторизации
claude mcpУправление MCP-серверами
claude pluginУправление плагинами
claude agentsПредставление фоновых агентов

24.2. Полезные флаги

ФлагНазначение
--modelВыбрать модель
--fallback-modelЦепочка резервных моделей
--effortУровень усилия: low … max
--permission-modedefault, acceptEdits, plan, auto, dontAsk, bypassPermissions
--add-dirДобавить рабочие каталоги
--allowedToolsИнструменты без запроса разрешения
--disallowedToolsЗапрещённые инструменты и правила
--mcp-configЗагрузить MCP-конфигурацию
--settingsУказать файл настроек
--max-turnsОграничить число агентских ходов
--max-budget-usdОграничить бюджет (неинтерактивный режим)
--output-formatФормат вывода: text, json, stream-json
--resume, --continueВозобновить сессию
--debugОтладочный вывод
--ideПодключиться к IDE
--nameИмя сессии
Опасно

--dangerously-skip-permissions и --permission-mode bypassPermissions отключают проверки. Только изолированная среда.
