16.2. PlatformIO: пример полного цикла

Структура проекта:

thermostat/
├── platformio.ini
├── src/
│   └── main.cpp
├── include/
├── test/
└── docs/

platformio.ini:

[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
build_flags = -Wall -Wextra

[env:native]
platform = native
test_framework = unity

Минимальная программа:

#include <Arduino.h>

constexpr uint8_t LED_PIN = 2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  digitalWrite(LED_PIN, !digitalRead(LED_PIN));
  Serial.println("tick");
  delay(1000);
}

Команды:

pio run                    # сборка
pio run -t upload          # прошивка
pio device monitor         # последовательный порт
pio test -e native         # тесты на компьютере
pio run -t clean           # очистка

Попросите агента: собрать проект, объяснить ошибки, добавить тест, проверить предупреждения. Он видит вывод команд и может итеративно исправлять.

16.3. STM32: осторожный цикл

  1. Создайте проект в STM32CubeMX: тактирование, выводы, периферия.
  2. Сгенерируйте код для CMake или Makefile.
  3. Соберите: cmake --build build.
  4. Прошейте через OpenOCD или STM32CubeProgrammer.
  5. Проверьте на стенде: питание, тактирование, выводы.

Пример прошивки через OpenOCD (файлы конфигурации зависят от платы):

openocd -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program build/firmware.elf verify reset exit"
Осторожно

Сгенерированный код инициализации нужно сверять с даташитом и платой. Ошибка в тактировании или в состоянии вывода может выглядеть как «прошивка не работает». Проверяйте часы, питание и pinout до того, как винить код.

16.5. Пример: драйвер I2C-датчика

Задача: написать драйвер датчика BME280 для ESP32 (Arduino framework).
Требования:
- I2C на SDA=21, SCL=22, 400 кГц;
- чтение температуры, давления, влажности;
- проверка presence и кодов ошибок;
- без блокирующих delay в рабочем цикле;
- тест на хосте с mock-шиной.
Выведи: заголовочный файл, реализацию, тест, пример использования.
Не выдумывай регистры: возьми их из docs/datasheets/BME280.pdf.

После ответа проверьте: адреса регистров, коэффициенты компенсации, порядок чтения, обработку ошибок. Скомпилируйте и измерьте на реальном датчике.
