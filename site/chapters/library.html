Как открывать файлы

HTML-книга открывается двойным щелчком в браузере. Файлы .md - это Markdown; браузер покажет их как обычный текст. Для удобного чтения откройте папку в VS Code и нажмите Ctrl+Shift+V (предпросмотр). Файл claude-code-konspekt/index.html - готовый HTML-конспект, открывается в браузере.
