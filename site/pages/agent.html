Глава 6 Что такое агент

Чат-бот отвечает текстом. Агент выполняет действия. Разница принципиальная: агент может изменить ваши файлы и запустить команды.

6.1. Цикл агента

Наблюдениечитает файлы, видит вывод команд
→
Планрешает, что делать
→
Действиеправит файл, запускает команду
→
Проверкасмотрит результат, повторяет

Этот цикл повторяется, пока задача не выполнена или не исчерпан лимит. Отсюда важное следствие: агент может сделать несколько шагов подряд без вашего участия. Чем шире разрешения, тем больше шагов он выполнит сам.

6.2. Из чего состоит агент

ЭлементЧто даётГде настраивается
Инструменты (tools)Чтение и запись файлов, запуск команд, поискВстроены; ограничиваются разрешениями
ПамятьПостоянные инструкции проектаCLAUDE.md, ~/.claude/CLAUDE.md
РазрешенияЧто можно без спроса, что нельзяsettings.json, режимы разрешений
SkillsУпакованные инструкции под типовую задачу.claude/skills/<имя>/SKILL.md
СубагентыОтдельные исполнители с изолированным контекстом.claude/agents/<имя>.md
HooksАвтоматические действия по событиюsettings.json
MCPПодключение внешних инструментов и данных.mcp.json, claude mcp add
ПлагиныНаборы skills, команд, агентов и hooksМаркетплейсы плагинов

6.3. Чат-бот и агент: сравнение

КритерийЧат-ботАгент (Claude Code)
Что делаетГенерирует текстЧитает, пишет, запускает, проверяет
Доступ к файламТолько то, что вставилиРабочая папка и добавленные каталоги
РискОшибочный текстОшибочный текст + испорченные файлы + выполненные команды
КонтрольМинимальныйРазрешения, режимы, ревью, git
ПользаСовет, черновикВыполненная работа

6.4. Главное правило работы с агентом

Правило

Агент получает ровно те права, которые вы ему дали. Если он может удалить файл - рано или поздно он его удалит. Если он может закоммитить - он закоммитит. Права и резервные копии важнее уговоров «будь осторожен».

Практический минимум: работа в git-репозитории, отдельная папка, режим разрешений default или plan на первых сеансах, регулярные коммиты.

6.5. Задание 4

Задание

Создайте папку sandbox, инициализируйте в ней git и запустите Claude Code. Попросите создать файл hello.txt с текстом «проверка». Посмотрите, какие действия агент выполнит и какие разрешения запросит. Затем отмените изменения через git и повторите с режимом plan - сравните поведение.
