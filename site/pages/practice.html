Глава 34 Практикум: агент в браузере, сбор данных с сайта

Практикум. Разбор рабочего конвейера: браузер с отладочным портом, постраничный сбор выдачи, открытие карточек с разбором структурированных данных страницы, классификация по правилам, отчёт и сводка. Задача примера взята из жизни: найти на доске объявлений снаряжение для водного спорта (кайты) в заданном бюджете, отделив товар от аксессуаров и услуг. Та же схема подходит для даташитов на сайте производителя, каталога компонентов или списка вакансий: меняются адрес, селекторы и правила отбора.

Что умеет такой агент #

Агент открывает браузер не через API, а так, как это делает человек: страницы грузятся, выдаются куки и сессия, прокручивается выдача, раскрываются свёрнутые описания. Для сайтов без API это единственный рабочий путь. В коде ниже используются четыре механики: отладочный порт браузера, постраничный сбор, открытие карточек и обработка данных в файлах.

  • Браузер, запущенный с флагом remote debugging, принимает команды Selenium по адресу 127.0.0.1 на порту 9223.
  • Сбор выдачи: переход на страницы, прокрутка, сбор карточек по селекторам, дедупликация по ссылке.
  • Открытие карточек: переход на объявление, ожидание, раскрытие описания, чтение видимого текста и структурированного объекта страницы.
  • Классификация по правилам: регулярные выражения на заголовки и описания, чтобы отсеять аксессуары и услуги.
  • Отчёт и сводка: CSV и Markdown с счётчиками ошибок и полнотой данных, плюс кэш для повторных запусков.

Как устроен конвейер #

Один запуск проходит семь шагов, каждый шаг - отдельный файл-модуль. Так части можно запускать и отлаживать поодиночке: сначала собрать список, потом посмотреть, что вышло, и только затем открывать карточки. Это тот же принцип «процесс, а не один огромный промпт» из главы о агентах и рабочих процессах.

  • 1. start_browser.ps1: закрыть старые окна браузера, запустить его с отладочным портом, дождаться ответа на /json/version.
  • 2. collect.py: подключиться к браузеру, пройти страницы выдачи, сохранять в JSON и CSV постранично (так можно прервать и продолжить).
  • 3. enrich.py: открыть карточки кандидатов, собрать описание, цену, дату, параметры, статус; каждая карточка дописывается в кэш.
  • 4. classify.py: разложить заголовки по «товар», «аксессуар», «услуга», «спорное».
  • 5. build_outputs.py: разобрать описания в предложения, сформировать итоговый CSV и список на ручную проверку.
  • 6. summary.py: сводка в Markdown с числами, чтобы видеть полноту сбора.
  • 7. collect_kites.py: оркестратор, который связывает шаги и передаёт каждому пути.

Меры против блокировок и ошибок #

Площадки распознают автоматический доступ. В образце применены четыре меры: естественный темп, проверка страницы на блокировку, повторная загрузка при недогрузе и постраничное сохранение. Ни одна из них не обходит защиту: при появлении капчи скрипт останавливается и сохраняет собранное.

  • Паузы: случайные интервалы в несколько секунд между действиями и страницами.
  • Прокрутка: окно прокручивается порциями по 400-900 пикселей, как при ручном чтении.
  • Проверка блокировки: поиск в тексте страницы слов о капче и ограничении доступа; снимок экрана в файл.
  • Повтор загрузки: если карточек меньше 45, страница перезагружается до трёх раз.
  • Состояние: выгрузка дописывается после каждой страницы, повторный запуск продолжает с места сбоя.

Безопасность данных #

Это главная часть главы. В коде ниже все личные поля удалены, а в образце, из которого он взят, сбор контактов не нужен: автору требовались только товар, цена, дата, описание и параметры.

  • Не поставляйте подержанные профили: соберите отдельный профиль для автоматизации, без паролей, истории и личных вкладок.
  • Не копируйте в проект cookies, localStorage и профиль браузера: из них можно воспроизвести вашу сессию.
  • Не сохраняйте телефоны, почты, ФИО, адреса и ссылки на профили; для отбора они не нужны.
  • Папку с выгрузкой и кэшем держите вне git и не отправляйте ИИ-агенту без необходимости: в описах бывают ссылки и контакты.
  • Не загружайте такие папки в облачные ИИ и не публикуйте. Если нет уверенности, что файл без личных данных, не отправляйте его целиком, а дайте агенту код и структуру.
  • Соблюдайте условия площадки и закон о персональных данных: у товарных объявлений обычно нет персональных данных, но у профилей продавцов есть. Цель - технический сбор, а не база контактов.
  • Ограничьте число запросов и объём выгрузки; не предавайте найденные списки третьим лицам.

Запуск браузера с отладочным портом #

Закрывает окна завершения (чтобы сохранилась сессия), запускает браузер с отладочным портом и ждёт, пока порт ответит. Порт - только для локальных подключений, адрес 127.0.0.1.

$BrowserExe = "C:\Program Files\Opera\opera.exe"
$Port = 9223
$StartUrl = "about:blank"

    if ($_.MainWindowHandle -ne 0) { $null = $_.CloseMainWindow() }
}
$deadline = (Get-Date).AddSeconds(20)
while ((Get-Process opera -ErrorAction SilentlyContinue) -and (Get-Date) -lt $deadline) {
    Start-Sleep -Milliseconds 500
}
Get-Process opera -ErrorAction SilentlyContinue | Stop-Process -Force
Start-Sleep -Seconds 2

Start-Process -FilePath $BrowserExe -ArgumentList @(
    "--remote-debugging-port=$Port",
    "--remote-debugging-address=127.0.0.1",
    "--restore-last-session",
$StartUrl = "about:blank"
)

$deadline = (Get-Date).AddSeconds(40)
while ((Get-Date) -lt $deadline) {
    try {
        $r = Invoke-RestMethod -Uri "http://127.0.0.1:$Port/json/version" -TimeoutSec 1
        Write-Host "[BROWSER] Debuging ready:" $r.Browser
        return
    } catch { Start-Sleep -Milliseconds 500 }
}

Сбор выдачи постранично #

Подключение к уже запущенному браузеру через debuggerAddress, сбор карточек по селекторам, паузы, прокрутка, проверка на капчу и постраничное сохранение.

import argparse
import csv
import json
import random
import re
import sys
import time
from pathlib import Path

from selenium import webdriver
from selenium.webdriver.chrome.options import Options as ChromeOptions
from selenium.webdriver.common.by import By

HERE = Path(__file__).parent
DEBUG_ADDR = "127.0.0.1:9223"

OUT_DIR = HERE
OUT_JSON = HERE / "search.json"
OUT_CSV = HERE / "search.csv"
BASE = "https://example.com/search?q=...&p={page}"

def human_sleep(a=1.5, b=3.5):
    time.sleep(random.uniform(a, b))

def connect():
    opt = ChromeOptions()
    opt.add_experimental_option("debuggerAddress", DEBUG_ADDR)
    return webdriver.Chrome(options=opt)

def collect(driver):
    items = []
    for card in driver.find_elements(By.CSS_SELECTOR, '[data-testid="listing-card"]'):
        def text(sel):
            try:
                return card.find_element(By.CSS_SELECTOR, sel).text.strip()
            except Exception:
                return ""

        title = text('[data-testid="listing-title"]')
        if not title:
            continue
        price = text('[data-testid="listing-price"]') or text('[data-testid="listing-price"]')
        try:
            url = card.find_element(By.CSS_SELECTOR, '[data-testid="listing-title"]').get_attribute("href")
        except Exception:
            url = ""
        items.append({
            "title": title,
            "price": re.sub(r"\s+", " ", price),
            "url": url.split("?")[0],
        })
    return items

def load_existing():
    if OUT_JSON.exists():
        try:
            data = json.loads(OUT_JSON.read_text(encoding="utf-8"))
            return [{k: x.get(k, "") for k in ("title", "price", "url")} for x in data]
        except json.JSONDecodeError:
            pass
    return []

def save(items):
    OUT_JSON.write_text(json.dumps(items, ensure_ascii=False, indent=2), encoding="utf-8")
    with open(OUT_CSV, "w", newline="", encoding="utf-8-sig") as f:
        w = csv.DictWriter(f, fieldnames=["title", "price", "url"])
        w.writeheader()
        w.writerows(items)

def is_blocked(driver):
    src = driver.page_source
    return "Подтвердите, что вы не робот" in src or "Доступ временно ограничен" in src or "firewall" in src.lower()

def main():
    global OUT_JSON, OUT_CSV, OUT_DIR
    ap = argparse.ArgumentParser()
    ap.add_argument("--from-page", type=int, default=1)
    ap.add_argument("--pages", type=int, default=23)
    ap.add_argument("--out", default=None, help="папка для выгрузки; создаётся при необходимости")
    ap.add_argument("--url", default=None, help="URL выдачи с фильтрами (без параметра p)")
    ap.add_argument("--json-name", default=None)
    ap.add_argument("--csv-name", default=None)
    args = ap.parse_args()

    base = BASE
    if args.url:
        base = args.url.split("&p=")[0]
        base = base.replace("&p={page}", "")
    if args.out:
        OUT_DIR = Path(args.out)
        OUT_DIR.mkdir(parents=True, exist_ok=True)
        OUT_JSON = OUT_DIR / (args.json_name or "search.json")
        OUT_CSV = OUT_DIR / (args.csv_name or "search.csv")
    sep = "&" if "?" in base else "?"
    url_tpl = base + sep + "p={page}"

    driver = connect()
    print("[BROWSER] Подключено к", driver.capabilities.get("browserVersion"))

    items = load_existing()
    seen = {x["url"] for x in items}
    print(f"[RESUME] в файле уже {len(items)} объявлений")

    status = "ok"
    for page in range(args.from_page, args.pages + 1):
        print(f"[NAV] Страница {page}")
        page_items = []
        for attempt in range(3):
            driver.get(url_tpl.format(page=page))
            human_sleep(3, 5)

            for _ in range(random.randint(3, 6)):
                driver.execute_script(f"window.scrollBy(0, {random.randint(400, 900)});")
                human_sleep(1.0, 2.5)

            if is_blocked(driver):
                driver.save_screenshot(str(OUT_DIR / f"blocked_p{page}.png"))
                status = "blocked"
                break

            page_items = collect(driver)
            if len(page_items) >= 45:
                break
            print(f"  недогруз ({len(page_items)}), перезагрузка…")
            human_sleep(4, 8)

        if status == "blocked":
            print(f"[WARN] Блокировка/капча на странице {page}. Сохраняю собранное.")
            break

        new = [x for x in page_items if x["url"] not in seen]
        for x in new:
            seen.add(x["url"])
        items.extend(new)
        save(items)
        print(f"  найдено {len(page_items)}, новых {len(new)}, всего {len(items)}")

        if not page_items:
            print("[INFO] Пустая страница — конец списка.")
            break
        human_sleep(4, 9)

    save(items)
    print(f"[DONE] status={status}, всего {len(items)} объявлений -> {OUT_JSON.name} / {OUT_CSV.name}")

if __name__ == "__main__":
    sys.exit(main())

Открытие карточек и разбор данных #

Переход по каждому кандидату, раскрытие описания, чтение структурированного объекта страницы, нормализация даты и статуса, запись в кэш по одной карточке.

import csv
import json
import random
import re
import time
from datetime import datetime, timedelta, timezone
from pathlib import Path

from selenium import webdriver
from selenium.webdriver.chrome.options import Options as ChromeOptions
from selenium.webdriver.common.by import By

HERE = Path(__file__).parent
OUT = HERE / "enriched"
CACHE = OUT / "page_cache.jsonl"
CLASSLOG_NAME = "classification.csv"
MSK = timezone(timedelta(hours=3))
MONTHS = {m: i for i, m in enumerate(
    ["января", "февраля", "марта", "апреля", "мая", "июня", "июля", "августа", "сентября", "октября", "ноября", "декабря"], 1)}

def connect():
    o = ChromeOptions()
    o.add_experimental_option("debuggerAddress", "127.0.0.1:9223")
    o.page_load_strategy = "eager"  # не ждать все ресурсы: страница иначе может зависнуть
    drv = webdriver.Chrome(options=o)
    drv.set_page_load_timeout(40)
    drv.implicitly_wait(5)
    return drv

def html_to_text(h):
    if not h:
        return ""
    t = h.replace("\r\n", "\n")
    t = re.sub(r"<br\s*/?>", "\n", t, flags=re.I)
    t = re.sub(r"</p>\s*<p[^>]*>", "\n\n", t, flags=re.I)
    t = re.sub(r"<[^>]+>", "", t)
    import html as H
    t = H.unescape(t)
    t = t.replace("\xa0", " ")

    t = t.replace("\r\n", "\n").replace("\r", "\n")
    t = re.sub(r"[\x00-\x08\x0b\x0c\x0e-\x1f\x7f  ]", "", t)
    return t.strip()

def parse_date(raw, finish_ts, fetched_at):
    if not raw:
        return None, None, None
    now = datetime.fromisoformat(fetched_at)
    s = raw.strip().lower()
    m = re.match(r"(\d{1,2})\s+([а-яё]+)\s+в\s+(\d{1,2}):(\d{2})", s)
    if m and m.group(2) in MONTHS:
        day, mon, hh, mm = int(m.group(1)), MONTHS[m.group(2)], int(m.group(3)), int(m.group(4))
        year = now.year
        try:
            dt = datetime(year, mon, day, hh, mm, tzinfo=MSK)

            if dt > now + timedelta(days=1):
                dt = dt.replace(year=year - 1)
            return raw, dt.isoformat(), "seen_text"
        except ValueError:
            pass
    m = re.match(r"(сегодня|вчера)\s+в\s+(\d{1,2}):(\d{2})", s)
    if m:
        d = now.date() - timedelta(days=1 if m.group(1) == "вчера" else 0)
        try:
            return raw, datetime(d.year, d.month, d.day, int(m.group(2)), int(m.group(3)), tzinfo=MSK).isoformat(), "relative_to_fetch"
        except ValueError:
            pass
    if finish_ts:
        try:
            return raw, datetime.fromtimestamp(finish_ts, MSK).isoformat(), "finish_time_unix"
        except (ValueError, OSError, OverflowError):
            pass
    return raw, None, None

def extract(driver, cand, fetched_at):
    url = cand["url"]
    rec = {
        "item_id": cand["item_id"], "url": url,
        "title_original": cand["title"], "price_original": cand["price"],
        "fetched_at": fetched_at, "fetch_status": None, "fetch_error": None,
        "page_title": None, "title_live": None, "price_live_raw": None, "price_live_rub": None,
        "description_raw": None, "listing_text_raw": None,
        "published_at_raw": None, "published_at_iso": None, "published_at_basis": None,
        "updated_at_raw": None,
        "seller_is_company": None, "listing_status": None,
        "params": None, "item_flags": None, "is_bot_session": None,
    }
    data = driver.execute_script("return window.__pageData || null")
    if not data:
        body = driver.find_element(By.TAG_NAME, "body").text
        rec["fetch_status"] = "unavailable"
        rec["fetch_error"] = "нет данных объявления на странице"
        rec["page_title"] = driver.title
        rec["listing_status"] = "closed" if "Объявление закрыто" in body else "unknown"
        return rec

    rec["is_bot_session"] = data["loaderData"].get("listing-page", {}).get("isBot")
    try:
        bi = data["loaderData"]["listing-page"]["listing"]
        item = bi["item"]
    except (KeyError, TypeError):
        rec["fetch_status"] = "error"
        rec["fetch_error"] = "нет listing в данных"
        return rec

    rec["page_title"] = driver.title
    rec["title_live"] = item.get("title")
    fp = item.get("formattedPrice") or {}
    rec["price_live_raw"] = fp.get("formatedString", "").replace("\xa0", " ") or None
    rec["price_live_rub"] = item.get("price")
    rec["description_raw"] = html_to_text(item.get("descriptionHtml") or item.get("description"))
    raw_date = item.get("sortFormatedDate")
    rec["published_at_raw"], rec["published_at_iso"], rec["published_at_basis"] = parse_date(
        raw_date, item.get("finishTime"), fetched_at)

    expanded = False
    for _ in range(2):
        try:
            btn = None
            for e in driver.find_elements(By.XPATH, "//*[contains(text(),'Читать полностью') or contains(text(),'Читать далее')]"):
                if e.is_displayed():
                    btn = e
            if not btn:
                break
            driver.execute_script("arguments[0].scrollIntoView({block:'center'});", btn)
            time.sleep(0.5)
            btn.click()
            expanded = True
            time.sleep(1.5)
        except Exception:
            break
    rec["description_expanded"] = expanded

    try:
        body = driver.find_element(By.TAG_NAME, "body").text
        s = body.find("Описание")
        t = body.find("Местоположение")
        dom_desc = body[s + len("Описание"):t].strip() if s != -1 and t > s else None
    except Exception:
        dom_desc = None
    if dom_desc and len(dom_desc) > len(rec["description_raw"] or ""):
        rec["description_raw"] = dom_desc

    try:
        body = driver.find_element(By.TAG_NAME, "body").text
        title_live = rec["title_live"] or rec["title_original"]
        start = body.find(title_live)
        end = body.find("Рекомендации", start)
        listing_text = body[start:end if end != -1 else len(body)].strip()
    except Exception:
        listing_text = None
    rec["listing_text_raw"] = listing_text

    s = item.get("seller") or bi.get("seller") or {}
    rec["seller_is_company"] = s.get("isCompany")

    rec["params"] = {p.get("title"): p.get("description") for p in (bi.get("paramsBlock") or {}).get("items", [])}
    rec["item_flags"] = {k: item.get(k) for k in (
        "isActive", "isClosed", "isArchived", "isDeleted", "isBlocked", "isExpired", "isFinished",
        "isInModeration", "isRejected", "statusId")}
    flags = rec["item_flags"]
    if flags["isActive"] and not (flags["isClosed"] or flags["isArchived"] or flags["isDeleted"] or flags["isBlocked"]):
        rec["listing_status"] = "active"
    elif flags["isBlocked"]:
        rec["listing_status"] = "blocked"
    elif flags["isDeleted"]:
        rec["listing_status"] = "deleted"
    elif flags["isArchived"]:
        rec["listing_status"] = "archived"
    elif flags["isClosed"] or flags["isFinished"]:
        rec["listing_status"] = "closed"
    else:
        rec["listing_status"] = "unknown"

    if rec["description_raw"] is None and not rec["title_live"]:
        rec["fetch_status"] = "partial"
    else:
        rec["fetch_status"] = "ok"
    return rec

def main():
    OUT.mkdir(exist_ok=True)
    cands = [r for r in csv.DictReader(open(OUT / CLASSLOG_NAME, encoding="utf-8-sig"))
             if r["decision"] == "yes"]
    done = set()
    if CACHE.exists():
        for line in CACHE.read_text(encoding="utf-8").splitlines():
            if line.strip():
                done.add(json.loads(line)["item_id"])
    todo = [c for c in cands if c["item_id"] not in done]
    print(f"кандидатов: {len(cands)}, уже обработано: {len(done)}, осталось: {len(todo)}")

    driver = connect()
    with open(CACHE, "a", encoding="utf-8") as f:
        for i, c in enumerate(todo, 1):
            fetched_at = datetime.now(MSK).replace(microsecond=0).isoformat()
            try:
                try:
                    driver.get(c["url"])
                except Exception:
                    driver.execute_script("window.stop();")
                time.sleep(random.uniform(2.5, 4.0))
                for _ in range(random.randint(1, 3)):
                    driver.execute_script(f"window.scrollBy(0, {random.randint(500, 900)});")
                    time.sleep(random.uniform(0.6, 1.4))
                rec = extract(driver, c, fetched_at)

    price = rec.get("price_live_rub")
    offers, etype = extract_offers(desc, title, price)

    if etype == "not_a_kite":

        acc_like = bool(re.match(

            tcanon, re.I)) or bool(re.search(r"кайт(борд|сёрф|серф|инг| спорт)|кайт\s*борд", tcanon, re.I))
        if acc_like or acc_after_kite_title(tcanon):

        if re.search(r"(surf\s*борд)\s+борд|(^|\W)борд(\W|$)", tcanon, re.I):
            return "excluded", "в заголовке доска/борд, не кайт", [], "not_a_kite"

            return "excluded", "заголовок — доска/сумка/компрессор, не кайт", [], "not_a_kite"
        if re.search(r"(кайт|купол|kite)", tcanon, re.I):
            return "unconfirmed", "заголовок про кайт, но в описании не найдена продажа кайта", [], "uncertain"
        return "excluded", "в описании нет продажи кайта/купола", [], etype
    if etype == "trainer_kite":
        size_tr = [o["size"] for o in offers if o.get("size")]
        small = size_tr and all(float(str(s).replace(",", ".")) <= 3.5 for s in size_tr)
        if small or re.search(r"(воздушн\w* змей|карманн|детск)", canon_text(title), re.I):

Оркестратор #

Связывает шаги: каждый модуль получает пути, а результат предыдущего становится входом следующего.

import argparse
import importlib.util
import os
import re
import sys
from datetime import datetime
from pathlib import Path

HERE = Path(__file__).parent

def load_mod(name):
    spec = importlib.util.spec_from_file_location(name, HERE / f"{name}.py")
    m = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(m)
    return m

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--url", required=True, help="адрес выдачи с фильтрами (без параметра страницы)")
    ap.add_argument("--slug", required=True, help="короткое имя поиска для папки выгрузки")
    ap.add_argument("--pages", type=int, default=23)
    ap.add_argument("--limit", type=int, default=60000, help="предел цены для отбора")
    args = ap.parse_args()

    ts = datetime.now().strftime("%Y-%m-%d_%H-%M")
    slug = re.sub(r"[^\w\-]+", "_", args.slug, flags=re.UNICODE).strip("_")
    out = HERE / "enriched" / f"{ts}_{slug}"
    out.mkdir(parents=True, exist_ok=True)
    print(f"[OUT] {out}", flush=True)

    # 1) сбор выдачи (повторный запуск продолжает с места остановки)
    pa = load_mod("collect")
    pa.OUT_DIR = out
    pa.OUT_JSON = out / "search.json"
    pa.OUT_CSV = out / "search.csv"
    pa.BASE = args.url.split("&p=")[0].replace("&p={page}", "")
    sys.argv = ["collect.py", "--out", str(out),
                "--json-name", "search.json", "--csv-name", "search.csv",
                "--url", args.url, "--pages", str(args.pages)]
    pa.main()

    # 2) классификация: отбираем кандидатов для открытия карточек
    cl = load_mod("classify")
    g = cl.main.__globals__
    g["OUT"] = out
    g["PRICE_LIMIT"] = args.limit
    cl.main()

    # 3) открываем карточки кандидатов, каждая дописывается в кэш
    en = load_mod("enrich")
    g = en.main.__globals__
    g["OUT"] = out
    g["CACHE"] = out / "page_cache.jsonl"
    en.main()

    # 4) итоговые файлы по кэшу и сводка
    bo = load_mod("build_report")
    g = bo.main.__globals__
    g["OUT"] = out
    g["CACHE"] = out / "page_cache.jsonl"
    g["LIMIT"] = args.limit
    bo.main()

    su = load_mod("summary")
    g = su.main.__globals__
    g["OUT"] = out
    su.main()
    print(f"[FILES] {out}", flush=True)

if __name__ == "__main__":
    main()

  • В .gitignore есть папка выгрузки, кэш и профиль.
