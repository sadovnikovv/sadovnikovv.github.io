Глава 6E Локальные модели

Локальная модель работает на вашем компьютере. Это даёт приватность и независимость, но требует железа и терпимости к качеству ниже топового облака.

6E.1. Плюсы и минусы

Нет оплаты за токеныКачество обычно ниже топовых облачных моделей

6E.3. Сколько нужно железа

МодельINT4INT8/FP16Реалистичное железо
3–4B2–3 ГБ6–8 ГБНоутбук, 8–16 ГБ ОЗУ
7–8B4–5 ГБ14–16 ГБRTX 3060 12 ГБ, 16–32 ГБ ОЗУ
13–14B7–9 ГБ26–28 ГБRTX 4070/4080 16 ГБ, 32 ГБ ОЗУ
30–32B16–20 ГБ60–64 ГБRTX 4090 24 ГБ, 64 ГБ ОЗУ
70B35–40 ГБ140 ГБ2×24 ГБ, 64–128 ГБ ОЗУ, Mac Studio

Для CPU-only скорость будет низкой; для комфортной работы нужна GPU с достаточной VRAM. Apple Silicon с объединённой памятью удобен для больших моделей, но скорость зависит от чипа.

6E.4. Какие модели запускать

  • Qwen2.5/3 Coder - код, разные размеры, хорошая мультиязычность.
  • Llama 3.1/3.3/4 - общая линейка, много готовых квантов.
  • Mistral Small - эффективные модели среднего размера.
  • Gemma 3, Phi-4 - малые модели для ноутбуков.
  • DeepSeek-R1 Distill - reasoning в локальном исполнении, но качество ниже полной R1.
  • CodeLlama, StarCoder - код, но поколение старше.

6E.5. Подключение к Claude Code через OmniRoute

Ollama предоставляет OpenAI-совместимый endpoint http://localhost:11434/v1. OmniRoute может подключить его как провайдера, а Claude Code продолжит работать через Anthropic-совместимый интерфейс OmniRoute. Схема:

Claude CodeAnthropic API
→
OmniRoutelocalhost:20128
→
Ollamalocalhost:11434
→
Локальная модельGPU / CPU
ollama pull qwen2.5-coder:7b
ollama run qwen2.5-coder:7b
ollama serve

В панели OmniRoute добавьте провайдера Ollama с адресом http://localhost:11434. Точные шаги зависят от версии; см. PROVIDERS-GUIDE.md в папке OmniRoute.

6E.6. Чего ожидать по качеству

Локальная 7–8B модель уровня 2024–2025 годов примерно соответствует старому облачному середняку: хорошо для шаблонов, простого кода, пересказа; слабее в сложных рассуждениях, длинном контексте и редких языках. 30–70B модели заметно лучше, но требуют железа. Квантование INT4 экономит память, но может ухудшить код и математику.

Стратегия

Гибрид: конфиденциальные данные и черновая рутина - локально; сложные задачи - облако. OmniRoute позволяет переключаться, не меняя Claude Code.
