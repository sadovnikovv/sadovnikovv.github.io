## 1. Официальная документация Anthropic на русском

**Папка:** `official-docs-ru/`
**Источник:** [code.claude.com/docs/ru/overview](https://code.claude.com/docs/ru/overview)
**Объём:** 205 страниц в Markdown, полное оглавление — в `official-docs-ru/ОГЛАВЛЕНИЕ.md`.

Это то, чего не было в ранее скачанной книге-справочнике: **первоисточник** от Anthropic, а не пересказ. Документация покрывает установку, настройку, память, skills, субагентов, hooks, MCP, плагины, Agent SDK, безопасность, стоимость и устранение неполадок.

Что важно знать:

- Перевод официальный, но местами неполный: отдельные заголовки остались на английском (`Troubleshooting`, `Output styles`).
- Структура повторяет английскую документацию, поэтому номера разделов и ссылки легко сверять с оригиналом.
- Страницы в Markdown удобно открывать в VS Code (`Ctrl+Shift+V`) или скармливать ИИ-агенту.

### Как выбирать

- **Нужен структурированный курс** → `claude-code-pro-course`.
- **Нужен быстрый конспект после курсов Anthropic** → `claude-code-konspekt` (откройте `index.html` в браузере).
- **Нужны схемы и визуальные объяснения** → `claude-howto-ru`.
- **Нужно навести порядок в `CLAUDE.md`** → `edgelab-claude-md`.
- **Нужны готовые команды** → `claude-starter-kit`.
- **Нужно понять, какие ещё инструменты бывают** → `awesome-ai-devtools-ru`.

## 3. О лицензиях и происхождении

- Официальная документация принадлежит Anthropic; скачана для личного чтения. При публикации ссылайтесь на первоисточник.
- Репозитории с MIT/CC0 можно свободно использовать и распространять с сохранением условий лицензии.
- У части репозиториев лицензия не указана. Формально это значит «все права сохранены»: для личного обучения пользуйтесь, но не публикуйте их содержимое у себя без разрешения автора.
- Код и скрипты из скачанных репозиториев **не запускались**. Если будете ставить плагины/скиллы, читайте их содержимое.

## 4. Как это связано с уже имеющейся книгой

В папке `../claude-code-handbook-ru/` лежит большой справочник `sfrangulov/claude-code-handbook-ru` (CC0) — практическая книга с большим количеством советов, шаблонов и каталогом инструментов.

Новый комплект дополняет её:

- **первоисточник** (официальные доки) вместо пересказа;
- **курс с лабораторными** для последовательного обучения;
- **конспект Anthropic Academy** для быстрого повторения;
- **готовые команды и скиллы** для немедленного применения;
- **связка с OmniRoute** — в соседней папке `02-omniroute`.

Оптимальный порядок: официальный `quickstart.md` → `claude-code-pro-course` → практика → `claude-code-konspekt` как справочник → `claude-howto-ru` для углубления.
