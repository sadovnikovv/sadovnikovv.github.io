Правовые и нормативные требования #

Правовые соглашения, сертификаты соответствия и информация о безопасности для Claude Code.

Правовые соглашения #

Лицензия #

Ваше использование Claude Code подчиняется:

  • Коммерческие условия обслуживания - для пользователей Team, Enterprise и Claude API
  • Условия обслуживания для потребителей - для пользователей Free, Pro, Max и Ultra

Коммерческие соглашения #

Независимо от того, используете ли вы Claude API напрямую (1P) или получаете доступ через Amazon Bedrock или Google Cloud's Agent Platform (3P), ваше существующее коммерческое соглашение будет применяться к использованию Claude Code, если мы не договорились об ином.

Могут ли клиенты предлагать Claude Code в своих продуктах? #

Если мы не договорились об ином, предустановка или запуск Claude Code в ваших продуктах или услугах (например, в размещённых песочницах или другой инфраструктуре агентов) требует согласия с нашими Коммерческими условиями обслуживания и соблюдения приведённых ниже условий:

  • Двоичный файл Claude Code не должен быть изменён. Claude Code должен быть установлен и запущен так, как опубликовано компанией Anthropic, и клиенты не могут удалять, отключать или ограничивать какой-либо встроенный метод аутентификации (включая методы, которые позволяют входить с помощью учётной записи Claude или собственного ключа API пользователя).
  • Клиенты не могут платить, перепродавать или выступать посредником при использовании Claude от имени своих конечных пользователей. Каждый конечный пользователь должен пройти аутентификацию со своим собственным ключом API Anthropic, учётными данными плана подписки Claude или учётными данными поставщика вывода 3P (Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry). Это использование выставляется в счёт конечному пользователю в соответствии с его собственным соглашением с Anthropic или, для поставщиков вывода третьих сторон, с применимым поставщиком.

Использование имени и логотипа Claude Code. Вы можете точно сказать, простым текстом, что ваш продукт имеет предустановленный Claude Code или что он запускает Claude Code. Но вы не можете использовать имена или логотипы Claude Code или Anthropic как часть названия вашего собственного продукта, функции или компании, в своём логотипе или способом, который предполагает, что Anthropic создала, одобрила или является партнёром вашего продукта. Любое другое использование имён или логотипов Anthropic регулируется нашими Рекомендациями по товарным знакам и требует нашего письменного разрешения.

Claude Code остаётся управляемым стандартными условиями Anthropic (см. разделы «Лицензия» и «Коммерческие соглашения» выше) независимо от платформы, через которую к нему осуществляется доступ.

Соответствие нормативным требованиям #

Соответствие требованиям здравоохранения (BAA) #

Если клиент заключил с Anthropic соглашение о деловом партнере (BAA), это BAA распространяется на Claude Code в двух конфигурациях, в зависимости от того, что доступно для вашей организации:

  • Конфигурация HIPAA: Claude Code CLI или вкладка Code в Claude Desktop, используемые с учетной записью Claude for Enterprise. В организации должен быть включен HIPAA, а конфигурация HIPAA должна быть применена к Claude Code (локальный режим) и Cowork (локальный режим). См. Настройка Claude Code (локальный режим) для организации, готовой к HIPAA.
  • Zero Data Retention: Claude Code с включенной Zero Data Retention (ZDR) для соответствующей организации. ZDR доступна не для всех организаций.

В конфигурации HIPAA не охватываются облачные сессии, Remote Control, Claude Code в мобильном приложении Claude, а также Claude Code, маршрутизируемый через стороннего облачного провайдера или шлюз. Полный список подходящих сервисов (Eligible Services) приведен в руководстве по внедрению.

Политика использования #

Допустимое использование #

Использование Claude Code подчиняется Политике использования Anthropic. Объявленные лимиты использования для планов Pro, Max и Ultra предполагают обычное индивидуальное использование Claude Code и Agent SDK.

Аутентификация и использование учетных данных #

Claude Code аутентифицируется на серверах Anthropic с использованием токенов OAuth или ключей API. Эти методы аутентификации служат разным целям:

  • Аутентификация OAuth предназначена исключительно для покупателей планов подписки Claude Free, Pro, Max, Ultra, Team и Enterprise и разработана для поддержки обычного использования Claude Code и других встроенных приложений Anthropic. Инструкции по входу см. в разделе Вход в вашу учётную запись Claude; информацию о том, как Claude Code выполняет аутентификацию OAuth, см. в разделе Authentication.
  • Разработчики, создающие продукты или сервисы, которые взаимодействуют с возможностями Claude, включая те, которые используют Agent SDK, должны использовать аутентификацию по API-ключу через Claude Console или поддерживаемого облачного провайдера. Anthropic не разрешает сторонним разработчикам предлагать вход Claude.ai в их собственные приложения или маршрутизировать запросы через учётные данные планов Free, Pro, Max или Ultra от имени своих пользователей. Кроме того, разработчики не могут собирать, хранить или посредничать в учётных данных Claude.ai или токенах сессии — вход в учётную запись Claude должен осуществляться через собственный поток Anthropic.

Это не ограничивает способ, которым клиенты предоставляют и управляют своими собственными ключами API или учетными данными поставщика услуг вывода третьих сторон — например, настройку ключа API в среде разработки, менеджере секретов или образе машины для использования авторизованными пользователями клиента — при условии, что полученное использование выставляется владельцу ключа в соответствии с его соглашением с Anthropic (или применимым поставщиком) и не перепродается или не посредничается, как описано выше. Это также не препятствует конечному пользователю входить в неизмененный бинарный файл Claude Code со своей собственной подпиской Claude, включая случаи, когда платформа размещает Claude Code, как описано выше.

Anthropic оставляет за собой право принимать меры для обеспечения соблюдения этих ограничений и может делать это без предварительного уведомления.

По вопросам о разрешенных методах аутентификации для вашего случая использования, пожалуйста, свяжитесь с отделом продаж.
