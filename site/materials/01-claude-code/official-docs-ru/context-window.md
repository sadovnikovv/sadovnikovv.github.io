# Изучите контекстное окно

> Интерактивная симуляция того, как контекстное окно Claude Code заполняется во время сеанса. Посмотрите, что загружается автоматически, какую стоимость имеет каждое чтение файла и когда срабатывают правила и hooks.

Контекстное окно Claude Code содержит всё, что Claude знает о вашем сеансе: ваши инструкции, файлы, которые он читает, его собственные ответы и содержимое, которое никогда не появляется в вашем терминале. Временная шкала ниже показывает полный сеанс от запуска до компактирования: что загружается перед тем, как вы что-либо введёте, что добавляет каждое чтение файла, правило и hook по мере работы Claude, и как subagent держит большие чтения вне вашего контекста. Смотрите [письменное описание](#what-the-timeline-shows) для того же содержимого в виде списка.

## Что показывает временная шкала

* **Перед тем, как вы что-либо введёте**: CLAUDE.md, автоматическая память, имена инструментов MCP и описания скиллов загружаются в контекст. [Файлы AGENTS.md](https://code.claude.com/docs/ru/memory.md#agents-md) могут загружаться вместо CLAUDE.md. Ваша собственная настройка может добавить больше здесь, например [стиль вывода](https://code.claude.com/docs/ru/output-styles.md) или текст из [`--append-system-prompt`](https://code.claude.com/docs/ru/cli-reference).
* **Во время работы Claude**: каждое чтение файла добавляется в контекст, [правила с областью действия пути](https://code.claude.com/docs/ru/memory.md#path-specific-rules) загружаются автоматически вместе с соответствующими файлами, и [hook PostToolUse](https://code.claude.com/docs/ru/hooks-guide.md) срабатывает после каждого редактирования.
* **Последующий prompt**: [subagent](https://code.claude.com/docs/ru/sub-agents.md) обрабатывает исследование в своём собственном отдельном контекстном окне, поэтому большие чтения файлов остаются вне вашего. Только резюме и небольшой трейлер метаданных возвращаются.
* **В конце сессии**: вы запускаете `/compact`, который заменяет диалог структурированным резюме. Большая часть содержимого, загружаемого при запуске, перезагружается автоматически. Что перезагружается и что сводится в резюме, смотрите в разделе [что сохраняется после сжатия контекста](#what-survives-compaction).

## Что сохраняется при сжатии контекста

Когда длительная сессия сжимается, Claude Code суммирует историю диалога, чтобы она поместилась в контекстное окно.

| Механизм | После сжатия контекста |
| :- | :- |
| Системный промпт и стиль вывода | Оба по-прежнему применяются |
| CLAUDE.md в корне проекта и правила без области действия | Повторно внедряются с диска |
| Автоматическая память | Повторно внедряется с диска |
| Описания скиллов | Перестраиваются на основе ваших текущих [скиллов](https://code.claude.com/docs/ru/skills.md) и повторно внедряются. Требуется Claude Code версии 2.1.304 или новее |
| [Снимок Git status](https://code.claude.com/docs/ru/settings-reference.md#includegitinstructions) | Если сессия началась со снимком, Claude Code читает свежий снимок из вашего репозитория |
| План, который Claude написал в [режиме планирования](https://code.claude.com/docs/ru/permission-modes.md#analyze-before-you-edit-with-plan-mode) | Повторно внедряется с диска |
| Правила с frontmatter `paths:` | Claude Code перезагружает их [по требованию](https://code.claude.com/docs/ru/memory.md#path-specific-rules) |
| Вложенные CLAUDE.md в подкаталогах | Claude Code перезагружает их [по требованию](https://code.claude.com/docs/ru/memory.md#how-claude-md-files-load) |
| Файлы, которые Claude прочитал или отредактировал | Claude Code повторно читает до пяти, начиная с самых недавно изменённых |
| Тела вызванных скиллов | Повторно внедряются, с ограничением 5000 токенов на скилл и 25 000 токенов всего; самые старые удаляются первыми |
| [Фоновые команды](https://code.claude.com/docs/ru/interactive-mode.md#background-bash-commands) и фоновые [субагенты](https://code.claude.com/docs/ru/sub-agents.md#run-subagents-in-foreground-or-background) | Продолжают работать. Claude Code напоминает Claude, какие из них всё ещё работают, чтобы он не запустил дубликат |
| Контекст, который хуки добавили ранее | Суммируется вместе с остальной частью диалога |
| [Хуки SessionStart](https://code.claude.com/docs/ru/hooks-guide.md#re-inject-context-after-compaction), которые соответствуют источнику `compact` | Claude Code запускает их и добавляет их вывод в сжатый контекст |

Сразу после сжатия контекста Claude Code повторно читает до пяти файлов, которые Claude прочитал или отредактировал в сессии, выбирая те, которые были изменены совсем недавно. Файл размером более 5000 токенов возвращается как ссылка на путь без его содержимого, отображаемая как `Referenced file` вместо `Read`.

Правила с областью действия по пути и вложенные файлы CLAUDE.md загружаются в историю сообщений, когда Claude читает, записывает или редактирует их триггерный файл, поэтому при сжатии контекста они суммируются вместе со всем остальным. Если правило должно сохраняться после сжатия контекста, удалите frontmatter `paths:` или переместите его в CLAUDE.md в корне проекта.

Тела скиллов повторно внедряются после сжатия контекста, но большие скиллы усекаются, чтобы уложиться в лимит на скилл, а самые старые вызванные скиллы удаляются после превышения общего бюджета. Усечение сохраняет начало файла, поэтому размещайте наиболее важные инструкции в начале `SKILL.md`.

## Когда ваш контекст заполняется

Claude Code автоматически сжимает контекст по мере приближения к лимиту, поэтому заполненное контекстное окно не завершает вашу сессию. Автоматический проход работает так же, как шаг `/compact` на временной шкале. Смотрите [Когда контекст заполняется](https://code.claude.com/docs/ru/how-claude-code-works.md#when-context-fills-up), чтобы узнать, что он сохраняет. О том, когда Claude Code также сжимает диалог, оставленный без активности, смотрите [сжатие контекста при простое](https://code.claude.com/docs/ru/settings-reference.md#idlecompaction).

Вы также можете действовать перед автоматическим проходом:

* **Компактируйте с фокусом**: запустите `/compact` с инструкциями, например `/compact focus on the auth bug fix`, перед началом длительной новой задачи. Резюме сохраняет то, что вы выбираете, вместо того, что автоматический проход предполагает как важное.
* **Компактируйте часть разговора**: запустите `/rewind`, выберите сообщение и выберите **Summarize from here** или **Summarize up to here**. Смотрите [Rewind and summarize](https://code.claude.com/docs/ru/checkpointing.md#rewind-and-summarize) для того, что каждый вариант сохраняет и как направить резюме.
* **Компактируйте раньше**: запустите [`/autocompact`](https://code.claude.com/docs/ru/commands#all-commands) с количеством токенов, например `/autocompact 500k`, чтобы установить, насколько полным становится контекстное окно перед автоматическим проходом. Смотрите [Set the auto-compact window](https://code.claude.com/docs/ru/model-config.md#set-the-auto-compact-window) для принятых значений и переопределений.
* **Очищайте между задачами**: запустите `/clear` при переходе на несвязанную работу. Старый разговор вытесняет файлы, которые вам нужны дальше, и стоит токены на каждом сообщении.
* **Делегируйте большие чтения**: отправьте исследование [subagent](https://code.claude.com/docs/ru/sub-agents.md), чтобы содержимое файла оставалось в его контекстном окне, а не в вашем.

Если вам нужно большее окно, а не более короткий диалог, модели Fable, Sonnet 5 и более поздние версии, Haiku 5.5, Opus 4.6 и более поздние версии, а также Sonnet 4.6 поддерживают контекстное окно в 1 миллион токенов. Смотрите [Extended context](https://code.claude.com/docs/ru/model-config.md#extended-context), чтобы узнать о доступности в зависимости от плана и о том, как выбрать вариант модели `[1m]`. Сжатие контекста работает так же и при большем лимите.

Точка, в которой запускается автоматическое компактирование, зависит от вашей модели и конфигурации. Смотрите [Default auto-compact thresholds](https://code.claude.com/docs/ru/model-config.md#default-auto-compact-thresholds) для границ по модели и [Correct the window for a gateway or custom model ID](https://code.claude.com/docs/ru/model-config.md#correct-the-window-for-a-gateway-or-custom-model-id), если Claude Code предполагает неправильное окно для вашего ID модели, например [LLM gateway](https://code.claude.com/docs/ru/llm-gateway) псевдоним.

## Проверьте свой собственный сеанс

Визуализация использует репрезентативные числа. Чтобы увидеть фактическое использование контекста в любой момент, запустите `/context` для живого разбора по категориям с предложениями по оптимизации, включая информацию о том, какие файлы CLAUDE.md и файлы автоматической памяти загружены. Запустите `/memory` для открытия и редактирования этих файлов.
