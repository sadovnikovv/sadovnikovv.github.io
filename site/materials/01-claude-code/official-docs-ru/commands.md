# Команды

> Полный справочник команд, доступных в Claude Code, включая встроенные команды и встроенные skills.

Команды управляют Claude Code внутри сеанса. Они предоставляют быстрый способ переключения моделей, управления разрешениями, очистки контекста, запуска рабочего процесса и многого другого.

Введите `/` для просмотра доступных вам команд или введите `/` с последующими буквами для фильтрации. [Как меню команд соответствует тому, что вы вводите](#how-the-command-menu-matches-what-you-type) охватывает выделение, опечатки и несколько команд, которые Claude Code скрывает из меню до тех пор, пока вы не введете их полное имя.

Команда распознается только в начале вашего сообщения. Текст, следующий за именем команды, становится её аргументами. В промпте терминала вы можете начать одно сообщение с нескольких [скиллов](https://code.claude.com/docs/ru/skills.md#stack-several-skills-in-one-message): ввод `/skill-a /skill-b do XYZ` загружает оба скилла и передает завершающий текст каждому из них в качестве аргументов. Можно объединить в цепочку до шести скиллов.

Если вы отправите команду, пока Claude отвечает, Claude Code ставит её в очередь и запускает после завершения текущего хода. Claude Code запускает некоторые команды немедленно без прерывания ответа, такие как `/status`, `/tasks` и `/usage`. В [полноэкранном режиме отображения](https://code.claude.com/docs/ru/fullscreen.md) Claude Code также открывает диалоговые команды, такие как `/theme` и `/help`, немедленно. До версии 2.1.234 Claude Code ставил эти диалоги в очередь до завершения хода.

## Команды в типичном рабочем процессе

Большинство команд полезны на определённом этапе сеанса, от настройки проекта до развёртывания изменений.

**Первый сеанс в репозитории.** Запустите `/init` для создания стартового файла `CLAUDE.md`, затем `/memory` для его уточнения. Используйте `/mcp` для настройки любых серверов, которые нужны проекту, попросите Claude создать любых [подагентов](https://code.claude.com/docs/ru/sub-agents.md), которые вам нужны, и запустите `/permissions` для установки правил одобрения.

**Во время задачи.** `/plan` переключает в режим планирования перед крупным изменением. `/model` и `/effort` регулируют, какую модель вы используете и сколько рассуждений она применяет. Когда разговор становится длинным, `/context` показывает, что заполняет окно, а `/compact` суммирует его, чтобы освободить место. Используйте `/btw` для побочного вопроса, который не должен добавляться в историю разговора.

**Запустите работу параллельно.** Claude делегирует побочные задачи [подагентам](https://code.claude.com/docs/ru/sub-agents.md), а `/tasks` выводит список фоновой работы текущего сеанса, включая завершённых подагентов. `/background` отделяет весь сеанс, чтобы он продолжал работать как [фоновый агент](https://code.claude.com/docs/ru/agent-view.md) и освобождает ваш терминал. Для крупного изменения, охватывающего всю кодовую базу, `/batch` разбивает его на независимые единицы и запускает каждую в своём [worktree](https://code.claude.com/docs/ru/worktrees.md). Смотрите [Запуск агентов параллельно](https://code.claude.com/docs/ru/agents.md), чтобы понять, как эти подходы связаны.

**Перед развёртыванием.** `/diff` показывает, что изменилось. `/code-review` проверяет текущий diff на ошибки корректности и может применить результаты с помощью `--fix`; передайте номер PR, например `/code-review high 1234`, чтобы вместо этого проверить pull request. `/review` — это псевдоним. `/code-review ultra` запускает многоагентную проверку в облаке. `/security-review` проверяет diff на уязвимости безопасности.

**Между сессиями.** `/clear` начинает заново с новой задачи, сохраняя память проекта. `/resume` возвращает к более ранней беседе, `/branch` ветвит текущую, чтобы попробовать другое направление, а `/fork` копирует её в новую [фоновую сессию](https://code.claude.com/docs/ru/agent-view.md). `/teleport` переносит облачную сессию в этот терминал, а `/remote-control` позволяет продолжить эту локальную сессию с другого устройства.

**Когда что-то не так.** `/rewind` откатывает код и разговор к контрольной точке или суммирует часть разговора. `/doctor` запускает проверку настройки, которая диагностирует проблемы установки и конфигурации и может их исправить, `/debug` диагностирует проблемы во время выполнения, а `/feedback` сообщает об ошибке с контекстом сеанса.

## Все команды

В таблице ниже перечислены все команды, входящие в Claude Code. Большинство из них — встроенные команды, поведение которых запрограммировано в CLI. Отмечены записи двух видов:

* **[Скилл](https://code.claude.com/docs/ru/skills.md#bundled-skills)**: встроенный скилл. Он работает так же, как скиллы, которые вы пишете сами: это промпт, передаваемый Claude.
* **[Рабочий процесс](https://code.claude.com/docs/ru/workflows.md#bundled-workflows)**: встроенный [динамический рабочий процесс](https://code.claude.com/docs/ru/workflows.md), который распределяет работу между множеством субагентов и выполняется в фоновом режиме.

Чтобы добавить собственные команды, см. [скиллы](https://code.claude.com/docs/ru/skills.md).

В таблице ниже `<arg>` обозначает обязательный аргумент, а `[arg]` — необязательный.

> [!NOTE]
>
> Не каждая команда отображается у каждого пользователя. Доступность зависит от вашей платформы, тарифа и окружения. Например, `/desktop` отображается только на macOS и Windows x64 при входе с подпиской Claude, а `/upgrade` не отображается на тарифах Enterprise.

| Команда | Назначение |
| :- | :- |
| `/add-dir <path>` | Добавить рабочий каталог для доступа к файлам. Введите часть пути, чтобы увидеть подходящие каталоги; нажмите `Tab`, чтобы принять один из них. Большая часть конфигурации `.claude/` [не обнаруживается](https://code.claude.com/docs/ru/permissions.md#additional-directories-grant-file-access-not-configuration) в добавленном каталоге. Большинство [сетевых путей](https://code.claude.com/docs/ru/errors.md#working-directory-is-a-network-path), таких как `\\server\share`, добавить нельзя. После успешного добавления запускаются ваши [хуки `DirectoryAdded`](https://code.claude.com/docs/ru/hooks#directoryadded). Если вы запускаете `/add-dir`, пока Claude отвечает, следующий вызов инструмента Claude сможет получить доступ к каталогу после того, как вы подтвердите добавление |
| `/advisor [model\|off]` | Включить или отключить [инструмент advisor](https://code.claude.com/docs/ru/advisor.md), который обращается ко второй модели за рекомендациями в ключевые моменты выполнения задачи. Принимает `fable`, `opus`, `sonnet` или полный ID модели. Для `fable` требуется [доступ к Fable](https://code.claude.com/docs/ru/advisor.md#choose-an-advisor-model). Без аргумента открывает окно выбора. В сессии без интерактивного терминала или через [Remote Control](https://code.claude.com/docs/ru/remote-control.md#limitations) передайте модель или `off` в качестве аргумента; без аргумента команда в этом случае выводит текущий advisor в виде текста. Для этих форм требуется Claude Code v2.1.260 или новее |
| `/agents` | Вывести напоминание о том, что можно попросить Claude создать [субагентов](https://code.claude.com/docs/ru/sub-agents.md) или управлять ими, либо напрямую редактировать `.claude/agents/` или `~/.claude/agents/`. В v2.1.197 и более ранних версиях открывает интерактивный интерфейс для создания конфигураций субагентов и управления ими |
| `/artifact-capabilities` | **[Скилл](https://code.claude.com/docs/ru/skills.md#bundled-skills).** Загрузить справочник по возможностям среды выполнения, которые может использовать опубликованный [артефакт](https://code.claude.com/docs/ru/artifacts.md), например [вызов ваших коннекторов](https://code.claude.com/docs/ru/artifacts.md#pull-live-data-with-mcp-connectors) или [предложение скачать файл](https://code.claude.com/docs/ru/artifacts.md#offer-a-file-download), включая информацию о том, какие из них доступны вашей учётной записи. Обычно Claude загружает его самостоятельно перед созданием страницы, использующей одну из них. Доступно там, где доступны [артефакты](https://code.claude.com/docs/ru/artifacts.md#availability) |
| `/artifact-diagramming` | **[Скилл](https://code.claude.com/docs/ru/skills.md#bundled-skills).** Загрузить рекомендации по созданию диаграмм, которым Claude следует в [артефактах](https://code.claude.com/docs/ru/artifacts.md): когда диаграмма полезна, что изображать и как писать встроенный SVG, остающийся читаемым в светлой и тёмной темах. Требуется Claude Code v2.1.221 или новее |
| `/artifacts` | Показать список [артефактов](https://code.claude.com/docs/ru/artifacts.md#find-an-artifact-again), которыми вы владеете или которые вам предоставлены, затем прикрепить один из них к сессии, открыть его в браузере или скопировать ссылку на него. Доступно там, где доступны [артефакты](https://code.claude.com/docs/ru/artifacts.md#availability) |
| `/auto-mode-setup` | [Составить черновик записей `autoMode.environment`](https://code.claude.com/docs/ru/auto-mode-config#generate-environment-entries) на основе вашего проекта и недавних сессий, затем просмотреть черновик и сохранить его в пользовательские настройки. На тарифе Pro, Max, Ultra или Team требуется Claude Code v2.1.228 или новее либо v2.1.233 или новее в нативной Windows. На тарифе Enterprise или с API-ключом Claude Console требуется v2.1.283 или новее. Если команда отсутствует, см. [`/auto-mode-setup` возвращает "Unknown command"](https://code.claude.com/docs/ru/auto-mode-config#auto-mode-setup-returns-unknown-command) |
| `/autocompact [auto\|<tokens>]` | Задать окно автосжатия: насколько должно заполниться контекстное окно, прежде чем Claude Code автоматически выполнит сжатие контекста. Передайте размер, например `500k`, или `auto`, чтобы вернуться к окну, настроенному для вашей модели. Claude Code сохраняет значение в пользовательских настройках и применяет его к текущей сессии. Допустимые значения и то, что их переопределяет, см. в разделе [Настройка окна автосжатия](https://code.claude.com/docs/ru/model-config.md#set-the-auto-compact-window). Без аргумента открывает диалоговое окно, показывающее текущее окно. Требуется Claude Code v2.1.221 или новее |
| `/autofix-pr [prompt]` | Запустить [облачную сессию](https://code.claude.com/docs/ru/claude-code-on-the-web.md#auto-fix-pull-requests), которая отслеживает PR текущей ветки и отправляет исправления, когда CI завершается с ошибкой или ревьюеры оставляют комментарии. Определяет открытый PR по вашей текущей ветке с помощью `gh pr view`; чтобы отслеживать другой PR, сначала переключитесь на его ветку. По умолчанию облачной сессии поручено исправлять каждую ошибку CI и каждый комментарий ревью; передайте промпт, чтобы дать ей другие инструкции, например `/autofix-pr only fix lint and type errors`. Требуется CLI `gh` и доступ к [облачным сессиям](https://code.claude.com/docs/ru/claude-code-on-the-web.md) |
| `/background [prompt]` | Отсоединить текущую сессию, чтобы она работала как [фоновый агент](https://code.claude.com/docs/ru/agent-view.md), и освободить этот терминал. Передайте промпт, чтобы отправить ещё одну инструкцию перед отсоединением. Отслеживайте сессию с помощью `claude agents`. Чтобы скопировать диалог в новую фоновую сессию, пока эта продолжает работать, используйте `/fork`. Псевдоним: `/bg` |
| `/batch <instruction>` | **[Скилл](https://code.claude.com/docs/ru/skills.md#bundled-skills).** Параллельно оркестрировать масштабные изменения в кодовой базе. Исследует кодовую базу, разбивает работу на 5–30 независимых единиц и представляет план. После одобрения запускает по одному [фоновому субагенту](https://code.claude.com/docs/ru/sub-agents.md#run-subagents-in-foreground-or-background) на каждую единицу в изолированном [worktree](https://code.claude.com/docs/ru/worktrees.md). Каждый субагент реализует свою единицу, запускает тесты и открывает PR или сообщает о том, что произошло. Требуется git-репозиторий или [хук `WorktreeCreate`](https://code.claude.com/docs/ru/worktrees#non-git-version-control), создающий worktree. Вне git-репозитория для `/batch` требуется Claude Code v2.1.281 или новее. Пример: `/batch migrate src/ from JavaScript to TypeScript` |
| `/branch [name]` | Создать ответвление текущего диалога в этой точке, чтобы попробовать другое направление, не теряя диалог в его текущем виде. Переключает вас в ветку и сохраняет оригинал, к которому можно вернуться с помощью `/resume`. Чтобы запустить копию как отдельную [фоновую сессию](https://code.claude.com/docs/ru/agent-view.md) вместо переключения в неё, используйте `/fork`; чтобы передать побочную задачу [субагенту](https://code.claude.com/docs/ru/sub-agents.md), который сообщит результат в этот диалог, используйте `/subtask` |
| `/btw [question]` | Задать [побочный вопрос](https://code.claude.com/docs/ru/interactive-mode.md#side-questions-with-%2Fbtw) о текущей сессии, не добавляя его в диалог. Если запустить `/btw` без вопроса, Claude Code покажет ваш последний побочный вопрос, чтобы вы могли просмотреть предыдущие ответы; если вы ещё не задавали вопросов, Claude Code выведет строку с описанием использования |
| `/bug [report]` | Сообщить об ошибке или поделиться своим диалогом. Вы выбираете, какую часть истории сессии включить, и подтверждаете это на экране согласия, прежде чем что-либо будет отправлено. Если вы вошли в Anthropic и используете прямое подключение к Anthropic, отчёт отправляется в Anthropic; при использовании стороннего провайдера или без учётных данных Anthropic Claude Code записывает отчёт в [локальный архив в `~/.claude/feedback-bundles/`](https://code.claude.com/docs/ru/data-usage#telemetry-services), который вы пересылаете самостоятельно. В [расширении VS Code](https://code.claude.com/docs/ru/vs-code.md#use-the-prompt-box) `/bug` вместо этого открывает собственное диалоговое окно обратной связи расширения; требуется Claude Code v2.1.229 или новее. Если вы запускаете команду, пока Claude отвечает, Claude Code сразу открывает диалоговое окно. До v2.1.232 Claude Code ставил команду в очередь до завершения хода. Псевдоним: `/share`. До v2.1.212 `/bug` и `/share` были псевдонимами `/feedback` |
| `/cd <path>` | Перенести эту сессию в новый рабочий каталог, сохранив диалог. Введите часть пути, чтобы увидеть подходящие каталоги; нажмите `Tab`, чтобы принять один из них. Что Claude Code применяет из нового каталога сразу после перехода и чем `/cd` отличается от `/add-dir`, см. в разделе [Перенос сессии в другой каталог](https://code.claude.com/docs/ru/permissions.md#move-the-session-to-another-directory) |
| `/chrome` | Настроить параметры [Claude in Chrome](https://code.claude.com/docs/ru/chrome.md) |
| `/claude-api [migrate\|upgrade\|api-version\|managed-agents-onboard\|managed-agents-secure\|prompt-audit\|cost-optimize\|latency-optimize\|build-eval\|hillclimb\|preserved-thinking-migration]` | **[Скилл](https://code.claude.com/docs/ru/skills.md#bundled-skills).** Загрузить справочные материалы по [Claude API](https://platform.claude.com/docs/en/api/overview) и [Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview) для языка вашего проекта. Также активируется автоматически, когда ваш код импортирует `anthropic` или `@anthropic-ai/sdk`. Что делает каждая подкоманда и какая версия для неё требуется, см. в разделе [Работа над проектами с Claude API](https://code.claude.com/docs/ru/skills.md#work-on-claude-api-projects) |
| `/claude-in-chrome [task]` | **[Скилл](https://code.claude.com/docs/ru/skills.md#bundled-skills).** Поручить Claude выполнить задачу в вашем браузере, например протестировать страницу, заполнить форму или прочитать логи консоли, через [Claude in Chrome](https://code.claude.com/docs/ru/chrome.md). Доступно, когда для сессии включена интеграция с Chrome, например с помощью `claude --chrome`, или когда Claude Code может предложить [установить расширение](https://code.claude.com/docs/ru/chrome.md#install-the-extension-when-claude-asks) |
| `/clear [name]` | Начать новый диалог с пустым контекстом. Передайте имя, чтобы пометить предыдущий диалог в окне выбора `/resume`. Чтобы освободить контекст, продолжая тот же диалог, используйте вместо этого `/compact`. Возобновите предыдущий диалог с помощью `/resume` или, в том же процессе Claude Code, восстановите его из [пункта предыдущей сессии в меню отката](https://code.claude.com/docs/ru/checkpointing.md#rewind-past-a-cleared-conversation). Псевдонимы: `/reset`, `/new` |
| `/code-review [low\|medium\|high\|xhigh\|max\|ultra] [--fix] [--comment] [--max-findings n\|all\|default] [pr#\|branch\|path]` | **[Скилл](https://code.claude.com/docs/ru/skills.md#bundled-skills).** Проверить текущий diff либо переданные номер PR, ветку или путь на наличие ошибок корректности. В зависимости от вашей модели и уровня effort ревью также охватывает возможности для очистки кода. Передайте `--fix`, чтобы Claude применил найденное, `--comment`, чтобы опубликовать результаты в PR на GitHub или merge request на GitLab, или `ultra`, чтобы запустить глубокое [облачное ревью](https://code.claude.com/docs/ru/ultrareview.md). Для публикации в merge request на GitLab требуется Claude Code v2.1.257 или новее. ## Как меню команд соответствует вводимому тексту

Claude Code фильтрует меню `/` по мере ввода. Каждый пункт ниже охватывает одну вещь, которую вы можете заметить при фильтрации:

* **Выделение**: Claude Code выделяет только верхнее предложение, когда буквы после `/` совпадают с именем команды или её псевдонимом, начиная с начала имени или с слова внутри него, игнорируя разделители `:`, `_` и `-`. Ввод `/adddir` выделяет `/add-dir`, а ввод `/new` выделяет `/clear` через его псевдоним. Нажмите `Enter` для запуска выделенного предложения. Эти правила выделения требуют Claude Code v2.1.236 или более поздней версии.
* **После опечатки**: Claude Code ничего не выделяет. Близкие совпадения остаются в списке, и вы можете выбрать одно с помощью `Tab` или клавиш со стрелками, но `Enter` отправляет ваш текст в том виде, в котором он был введён, и сообщает об [Unknown command](https://code.claude.com/docs/ru/errors.md#unknown-command).
* **Команды, которые вам недоступны**: Claude Code исключает их из меню. Когда ничего не совпадает, Claude Code показывает `No commands match "/name"`. Большинство недоступных команд возвращают [Unknown command](https://code.claude.com/docs/ru/errors.md#unknown-command) при отправке; некоторые, такие как [`/schedule` на ключе Console API](https://code.claude.com/docs/ru/routines#schedule-returns-unknown-command), вместо этого отвечают собственным сообщением о доступности. Некоторые команды также отвечают собственным сообщением, когда политика вашей организации их отключает.
* **Скрытые команды**: Claude Code намеренно исключает несколько доступных команд, таких как `/heapdump`, из меню. Частичное имя никогда не выводит скрытую команду в меню: если частичное совпадение не соответствует ничему видимому, Claude Code показывает то же сообщение об отсутствии совпадения. Claude Code выводит команду в список только после того, как вы введёте её полное имя, и отправка полного имени запускает её.
