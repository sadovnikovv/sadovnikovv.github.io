Доступность функций #

Сравните, какие функции Claude Code доступны в каждом плане подписки Anthropic, в Anthropic Console и у облачных поставщиков, таких как Amazon Bedrock и Google Cloud.

CLI Claude Code и всё, что работает локально, функционирует одинаково у каждого поставщика. Инструкции по настройке для каждого поставщика см. в разделе Обзор развёртывания для предприятий. Чтобы сразу перейти к тому, что отсутствует у вашего поставщика, см. вкладки сводки по поставщикам.

В таблицах ниже ✓ означает доступно, ✗ означает недоступно, а «See note» ссылается на сноску для частичной поддержки. Квалификатор после ✓ сужает доступность до этого подмножества, а «Admin-enabled» означает, что функция отключена до тех пор, пока администратор организации её не включит.

Доступность по поставщику модели #

Способ аутентификации определяет, какие функции может использовать Claude Code. Для единого списка того, что отсутствует у вашего поставщика, см. вкладки сводки по поставщикам. Чтобы найти свой столбец в таблицах:

  • Подписка Claude: вы входите с учётной записью claude.ai в плане Pro, Max, Ultra, Team или Enterprise
  • Anthropic Console: вы аутентифицируетесь с помощью ключа API Anthropic или входите в учётную запись Console без ключа
  • Amazon Bedrock: вы используете модели Claude из каталога моделей Amazon Bedrock и устанавливаете CLAUDE_CODE_USE_BEDROCK. Конечная точка Mantle (CLAUDE_CODE_USE_MANTLE) охватывается этим столбцом
  • Claude Platform на AWS: вы приобрели Claude через AWS Marketplace, но вызываете API Anthropic и устанавливаете CLAUDE_CODE_USE_ANTHROPIC_AWS
  • Google Cloud (Anthropic managed): вы используете Claude Models on Google Cloud (Anthropic managed) и устанавливаете CLAUDE_CODE_USE_ANTHROPIC_GOOGLE_CLOUD. Вы обращаетесь к Claude API, которым управляет Anthropic, через свой проект Google Cloud. Чтобы различить два предложения Google Cloud, см. Каким предложением вы пользуетесь?
  • Google Cloud (Google managed): управляется Google в рамках Google Cloud's Agent Platform, ранее Vertex AI; вы устанавливаете CLAUDE_CODE_USE_VERTEX и используете Claude Models on Google Cloud (Google managed)
  • Microsoft Foundry: управляется Anthropic; вы устанавливаете CLAUDE_CODE_USE_FOUNDRY

Функции, доступные у каждого поставщика #

Они работают у каждого поставщика:

  • CLI и Agent SDK
  • Расширения VS Code и JetBrains
  • Subagents, hooks, commands и skills
  • Память CLAUDE.md, plugins и MCP servers
  • Checkpoints, sandboxing и Workflows
  • Метрики OpenTelemetry и управляемый файл параметров

Они имеют различия, зависящие от поставщика:

  • MCP-серверы: коннекторы из claude.ai загружаются только когда ваша подписка claude.ai является активным методом аутентификации. Поиск инструментов не поддерживается на развёртываниях Microsoft Foundry, размещённых на Azure. На Google Cloud (Google managed) поиск инструментов не поддерживается на моделях более ранних, чем Claude Opus 4.5, Claude Sonnet 4.5 и Claude Haiku 4.5
  • Субагенты: когда родительский диалог работает на Fable, встроенный субагент Explore работает на Opus при использовании подписки Claude, учётной записи Anthropic Console или LLM-шлюза, доступ к которому осуществляется через ANTHROPIC_BASE_URL. У других провайдеров, включая Claude Platform on AWS, он работает на Fable
  • Команды:
  • /design-sync и /import с его формой подкоманды claude import недоступны у облачных поставщиков, а также через Claude apps gateway
  • /voice требует учётную запись claude.ai
  • /list-agents и его псевдоним /peers доступны только в сессиях, где включена передача сообщений между сессиями

Функции, требующие подписку Claude #

Они требуют входа с учётной записью claude.ai и недоступны с ключом API Anthropic Console или от поставщика третьей стороны:

  • Облачные сессии и Claude Code на мобильном устройстве
  • Claude Code в Slack: планы Pro, Max и Ultra
  • Claude Code Desktop
  • Облачные запланированные задачи (/schedule)
  • Ultrareview
  • Code Review: планы Team и Enterprise
  • Remote Control
  • Расширение Chrome
  • Computer use: планы Pro, Max и Ultra
  • Артефакты: планы Pro, Max, Ultra, Team и Enterprise
  • Voice dictation

Desktop — частичное исключение: маршрутизация шлюза может быть настроена в приложении или администратором. Claude Desktop на 3P также запускает вкладку Code на Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry или самостоятельно размещённом LLM-шлюзе. Он также запускает вкладку Code на Claude API с API-ключом Anthropic Console. Для доступности этих функций по плану см. Доступность по плану подписки.

[!NOTE]

Если вы аутентифицируетесь через LLM-шлюз, доступность функций соответствует базовому поставщику, на который шлюз перенаправляет запросы, за исключением функций, которые сам Claude Code отключает. Когда ANTHROPIC_BASE_URL указывает на хост, отличный от api.anthropic.com, Claude Code отключает такие функции, как Remote Control и server-managed settings, независимо от того, куда перенаправляет шлюз. Некоторые функции, такие как Advisor, работают, только если шлюз перенаправляет запросы без изменений.

Для информации о том, как запросы, которые отправляет Claude Code, различаются между шлюзом в формате Amazon Bedrock или Agent Platform, шлюзом ANTHROPIC_BASE_URL и входом в Claude apps gateway, см. поведение клиента по методу подключения.

Сводка по поставщикам #

Каждая вкладка содержит список того, что недоступно или частично поддерживается у этого поставщика, с альтернативами, где они существуют. См. также различия, зависящие от поставщика. На Amazon Bedrock, Google Cloud (Google managed), Microsoft Foundry и Claude Platform на AWS отчёты об ошибках и телеметрия для Anthropic отключены по умолчанию. См. поведение по умолчанию по поставщику API для информации о том, какой трафик всё ещё достигает Anthropic и как отказаться.

[tab] Amazon Bedrock

Недоступно: все функции, требующие подписку Claude, плюс веб-поиск, быстрый режим, Advisor, Каналы, Code Mode, панель управления аналитики, server-managed settings и команды /design-sync и /import.

Частичная поддержка:

  • Desktop: только через Claude Desktop на 3P
  • Авторежим: только Sonnet 5 или более поздние версии, Opus 4.7 или более поздние версии, Haiku 5.5 и модели Fable
  • Cross-session messaging: между вашими сеансами на этой машине только <sup>5</sup>
  • Zero Data Retention: в соответствии с вашим соглашением AWS

Альтернативы: для планирования используйте /loop вместо /schedule. Для облачных сеансов используйте GitHub Actions или GitLab CI/CD. Для веб-поиска используйте инструмент WebFetch с конкретным URL.

[tab] Claude Platform на AWS

Недоступно: все функции, требующие подписку Claude, плюс быстрый режим, Каналы, GitHub Actions, Code Mode, панель управления аналитики, server-managed settings и команды /design-sync и /import.

Доступно здесь, но не на Amazon Bedrock: веб-поиск, а также Advisor в Claude Code v2.1.300 или более поздней версии.

Частичная поддержка:

  • Cross-session messaging: между вашими сеансами на этой машине только <sup>5</sup>

Альтернативы: для планирования используйте /loop вместо /schedule. Для облачных сеансов используйте GitLab CI/CD.

[tab] Google Cloud (Anthropic managed)

Недоступно: все функции, требующие подписку Claude, плюс быстрый режим, Каналы, GitHub Actions, Code Mode, панель управления аналитики, server-managed settings и команды /design-sync и /import.

Доступно здесь, но не на Google Cloud (Google managed): Advisor в Claude Code v2.1.300 или более поздней версии.

Частичная поддержка:

  • Cross-session messaging: только между вашими сессиями на этой машине <sup>5</sup>
  • Zero Data Retention: доступно по запросу. Обратитесь к представителю Anthropic, ведущему вашу учётную запись

Альтернативы: для планирования используйте /loop вместо /schedule.

[tab] Google Cloud (Google managed)

Если вы устанавливаете CLAUDE_CODE_USE_VERTEX, чтобы использовать Claude Code с Google Cloud's Agent Platform, вы используете этого поставщика.

  • Авторежим: только Sonnet 5 или более поздние версии, Opus 4.7 или более поздние версии, Haiku 5.5 и модели Fable

План Ultra #

Ultra — это новое название плана Max 20x, а Max — новое название Max 5x. Чтобы узнать, какой у вас план, проверьте свою подписку на claude.ai.

В Claude Code планы Max и Ultra имеют одинаковые функции, указанные в столбцах Max и Ultra таблицы доступности. Информацию о лимитах использования и ценах см. на странице цен Claude.

Доступность моделей #

Для информации о том, какие модели Claude и размеры контекстного окна доступны для каждого поставщика и региона, см. Model configuration и Models overview. Vision, PDF input и extended thinking — это возможности модели, а не функции Claude Code, и работают у каждого поставщика, который предлагает модель. Prompt caching работает одинаково у большинства поставщиков; на Amazon Bedrock поддержка варьируется в зависимости от модели.
