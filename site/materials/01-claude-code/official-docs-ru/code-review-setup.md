# Настройка Code Review

> Включите Code Review для вашей организации Claude: подключите GitHub, установите Claude GitHub App, выберите репозитории и настройте, когда запускаются ревью

Как Owner вашей организации Claude, вы включаете Code Review в разделе [**Admin settings > Claude Code**](https://claude.ai/admin-settings/claude-code#code-review) на claude.ai. Ревью выполняются на инфраструктуре Anthropic, поэтому вам не нужно добавлять файлы workflow в свои репозитории.

После настройки вы выбираете, насколько тщательными будут ревью и когда они будут запускаться в каждом репозитории. Расходы растут при более высоком уровне ревью и при более частом запуске ревью. См. [Стоимость Code Review](https://code.claude.com/docs/ru/code-review-costs.md#pricing).

## Что нужно для включения Code Review

Сначала убедитесь, что ваша организация [соответствует требованиям Code Review](https://code.claude.com/docs/ru/code-review.md#availability). Затем убедитесь, что у вас есть следующие права доступа или есть человек, у которого они есть:

| Доступ | Для чего нужен |
| :- | :- |
| [Роль Owner](https://code.claude.com/docs/ru/server-managed-settings.md#access-control) в вашей организации Claude | Каждый шаг на странице администратора |
| Owner организации GitHub | Установка Claude GitHub App и [привязка его к вашей организации Claude](https://code.claude.com/docs/ru/admin-setup.md#connected-github-accounts). Если вы не являетесь owner, попросите owner установить и привязать приложение, прежде чем начинать |
| Доступ на запись к каждому добавляемому репозиторию из учетной записи GitHub, которую вы подключаете к Claude | Добавление репозитория |

## Включение Code Review

**1. Нажмите переключатель Allow code review**

Перейдите в раздел **Code review** на странице [**Admin settings > Claude Code**](https://claude.ai/admin-settings/claude-code#code-review) и нажмите переключатель **Allow code review**.

Если Code Review включается сразу без диалогового окна, значит, в вашей организации уже привязан Claude GitHub App или добавлены репозитории. Перейдите к разделу [Добавление репозиториев](#add-more-repositories), а затем вернитесь к последнему шагу.

**2. Подключите учетную запись GitHub**

Если открылось диалоговое окно **Connect GitHub**, нажмите **Connect**. Если ваша организация использует GitHub Enterprise Server, сначала выберите свой экземпляр в диалоговом окне. GitHub попросит вас авторизовать Claude, а затем вернет вас на страницу администратора с открытым диалоговым окном **Add a repository**.

Если сразу открылось окно **Add a repository**, ваша учетная запись уже подключена, поэтому переходите к следующему шагу.

**3. Установите Claude GitHub App**

Если нужные репозитории отображаются в диалоговом окне **Add a repository** или вы находите их с помощью поиска в нем, переходите к следующему шагу. Диалоговое окно показывает репозиторий, только если у Claude GitHub App есть к нему доступ, поэтому, если их там нет, установите приложение:

* Нажмите **Install GitHub App**. Если в списке нет репозиториев, это кнопка в диалоговом окне. В противном случае она находится внизу меню фильтра организаций GitHub в диалоговом окне. Страница установки GitHub откроется в новой вкладке.
* Выберите организацию GitHub, которой принадлежат репозитории.
* Выберите, к каким репозиториям приложение получит доступ.
* Подтвердите запрашиваемые разрешения. Этот набор шире, чем требуется для ревью, и используется совместно с другими функциями Claude, такими как [GitHub Actions](https://code.claude.com/docs/ru/github-actions.md). См. [к чему имеет доступ ревью](https://code.claude.com/docs/ru/code-review.md#what-a-review-can-access) и [полный список разрешений](https://code.claude.com/docs/ru/github-actions.md#github-app-permissions).
* После завершения установки вкладка вернется в Claude. Если на ней отображается кнопка **Finish connecting GitHub**, нажмите ее, чтобы привязать установку к вашей организации Claude.
* Вернитесь на вкладку страницы администратора, где список в диалоговом окне обновится.

**4. Выберите репозитории**

Выберите репозитории, для которых нужно ревью, затем нажмите **Continue**. Для добавления репозитория у подключенной учетной записи GitHub должен быть доступ на запись к нему. Вы можете [добавить другие репозитории](#add-more-repositories) позже.

**5. Нажмите Finish**

Далее откроется диалоговое окно **Code review is set up**. Нажмите **Finish**, чтобы включить Code Review. Если вы закроете диалоговое окно другим способом, ваши репозитории останутся добавленными, но **Allow code review** останется выключенным, и вам нужно будет включить его с помощью переключателя.

Каждый репозиторий изначально настроен на ревью после каждого push, что дает наибольшее количество ревью. Чтобы запускать их реже, [настройте, когда запускаются ревью](#set-when-reviews-run).

**6. Проверьте с помощью тестового pull request**

Откройте тестовый pull request в одном из добавленных репозиториев и не помечайте его как черновик. В течение нескольких минут появится check run с именем **Claude Code Review**. Если вы уже установили для репозитория режим **Manual (@claude review)**, оставьте комментарий `@claude review` в pull request, чтобы запустить первое ревью.

Если check run не появился, см. [No check run appears on the test pull request](https://code.claude.com/docs/ru/code-review-troubleshooting.md#no-check-run-appears-on-the-test-pull-request).

Когда ревью будет готово, отправьте своим разработчикам страницу [Чтение и запрос ревью в pull request](https://code.claude.com/docs/ru/code-review-pull-requests.md), где описаны уровни серьезности, команды в комментариях и то, как реагировать на найденные проблемы.

## Настройка значений по умолчанию для организации

Как Owner, вы решаете, насколько тщательными будут ревью и как часто они будут запускаться. Обе настройки находятся в разделе **Code review** на странице [**Admin settings > Claude Code**](https://claude.ai/admin-settings/claude-code#code-review).

### Настройка уровня ревью по умолчанию

Уровень ревью определяет, насколько тщательным будет каждое ревью, и более тщательное ревью стоит дороже. Вы задаете одно значение по умолчанию для организации и можете переопределить его для отдельных репозиториев.

| Уровень | Компромисс |
| :- | :- |
| Quick | Более легкая проверка. Самый быстрый уровень с наименьшей стоимостью |
| Standard | Сбалансированные глубина, скорость и стоимость. Уровень по умолчанию |
| Deep | Самая тщательная проверка. Занимает больше всего времени и стоит дороже всего |

* **Значение по умолчанию для организации**: выберите уровень в разделе **Review level** и подтвердите нажатием **Change level**. Каждый репозиторий использует его, если вы не задали для этого репозитория собственный уровень.
* **Отдельный репозиторий**: нажмите **Edit** в строке репозитория, затем выберите **Review level**. Первый вариант, **Default**, следует настройке организации. Уровень сохраняется сразу после выбора.

Новый уровень применяется к ревью, которые начинаются после изменения. О других факторах, влияющих на стоимость каждого ревью, см. [Стоимость и использование Code Review](https://code.claude.com/docs/ru/code-review-costs.md).

### Настройка времени запуска ревью

У каждого репозитория есть собственная настройка **Review runs**, которая определяет, когда проводится ревью его pull request.

* **Once after PR creation**: ревью запускается, когда pull request открывается, повторно открывается или помечается как готовый к ревью
* **After every push**: ревью запускается при каждом push в ветку pull request, выявляя новые проблемы по мере развития pull request и автоматически закрывая обсуждения, когда вы исправляете отмеченные проблемы
* **Manual (@claude review)**: открытие pull request или push в него не запускает ревью. Оставьте комментарий [`@claude review`](https://code.claude.com/docs/ru/code-review-pull-requests#comment-commands), чтобы запросить ревью, или `@claude review always`, чтобы также подписать pull request на ревью при последующих push.

Режим Manual полезен для репозиториев с высокой активностью, где вы хотите включать ревью только для определенных pull request, или чтобы начинать ревью pull request только тогда, когда они готовы. Чтобы сравнить, как каждый вариант влияет на расходы, см. [Как часто запускаются ревью](https://code.claude.com/docs/ru/code-review-costs.md#how-often-reviews-run).

Чтобы изменить настройку, нажмите **Edit** в строке репозитория в таблице **Repositories** и выберите вариант **Review runs**. Выбор сохраняется сразу, а в столбце **Review runs** таблицы он отображается в сокращенном виде: Once per PR, Every push или Manual.

* **Черновики и pull request из форков**: какой бы вариант вы ни выбрали, [автоматические ревью пропускают и те, и другие](https://code.claude.com/docs/ru/code-review-pull-requests.md#review-drafts-and-pull-requests-from-forks)
* **Новые репозитории**: репозиторий, добавленный через диалоговое окно **Add a repository**, изначально использует **After every push**. Если его организация GitHub [охвачена целиком](#cover-a-whole-github-organization), он вместо этого получает настройку из строки этой организации.

### Включение и отключение комментариев-подсказок

Комментарий-подсказка — это короткий комментарий, который Claude публикует в pull request, когда ревью не запускается, объясняя причину и дальнейшие действия. Настройка **Show tips on pull requests** включена по умолчанию. Когда она включена, Claude публикует подсказку в каждом из следующих случаев, объясняя:

* **Репозиторий настроен на Manual**: как запросить ревью с помощью комментария
* **Pull request создан из форка**: что ревью может запросить мейнтейнер
* **Бот или пользователь без доступа на запись, не являющийся автором pull request, оставляет комментарий `@claude review`**: что ревью не было запущено и кто может его запросить
* **Организация GitHub не привязана к вашей организации Claude**: что ревью приостановлены и как привязать организацию

Отключите эту настройку, чтобы прекратить публикацию таких комментариев.

### Что могут изменить разработчики

Чтобы изменить уровень ревью, настройку **Review runs** или список репозиториев, для которых проводятся ревью, разработчики обращаются к вам. В GitHub без роли Owner они могут делать следующее:

* **Запросить ревью**: оставить комментарий [`@claude review`](https://code.claude.com/docs/ru/code-review-pull-requests#comment-commands) в pull request. Для этого нужен доступ на запись к репозиторию, и это работает для [черновиков и pull request из форков](https://code.claude.com/docs/ru/code-review-pull-requests.md#review-drafts-and-pull-requests-from-forks), которые автоматические ревью пропускают.
* **Подписать отдельный pull request на ревью при каждом push**: оставить комментарий `@claude review always` в pull request, который не является [черновиком или pull request из форка](https://code.claude.com/docs/ru/code-review-pull-requests.md#review-drafts-and-pull-requests-from-forks), например в репозитории, настроенном на Manual
* **Изменить то, что помечают ревью**: сделать коммит [файлов `REVIEW.md` и `CLAUDE.md`](https://code.claude.com/docs/ru/code-review-customize) в репозиторий, например чтобы добавить проверку

Ревью, запрошенные разработчиками, [оплачиваются вашей организацией](https://code.claude.com/docs/ru/code-review-costs.md#pricing). Чтобы ограничить расходы Code Review за месяц, см. [Ограничение расходов](https://code.claude.com/docs/ru/code-review-costs.md#limit-your-spend).

## Управление репозиториями

Вы можете добавлять репозитории по одному или охватить сразу всю организацию GitHub, а также остановить ревью там, где они вам не нужны.

### Добавление репозиториев

Чтобы добавить репозитории после настройки, нажмите **Add** над таблицей **Repositories** в разделе **Code review**. Откроется диалоговое окно **Add a repository**. Выберите репозитории и нажмите **Continue**.

* **Репозиторий отсутствует в списке**: см. [A repository isn't listed in Add a repository](https://code.claude.com/docs/ru/code-review-troubleshooting.md#a-repository-isn’t-listed-in-add-a-repository).
* **Вам нужны все репозитории организации GitHub**: [охватите организацию](#cover-a-whole-github-organization) вместо того, чтобы выбирать репозитории по одному

### Охват всей организации GitHub

Чтобы включить Code Review для всех репозиториев организации GitHub, задайте **Review runs** в строке организации в таблице **Repositories**. Это охватывает все репозитории этой организации, к которым у Claude GitHub App есть доступ, включая репозитории, добавленные позже. Это может значительно увеличить расходы. Для этого необходимо выполнение всех следующих условий:

* Учетная запись GitHub, которую вы подключили к Claude, является owner этой организации GitHub.
* Организация находится на github.com. Экземпляры GitHub Enterprise Server и личные учетные записи GitHub не подходят.
* Установлен [месячный лимит расходов](https://code.claude.com/docs/ru/code-review-costs.md#limit-your-spend) для вашей организации Claude или для Code Review.

Чтобы охватить организацию, нажмите **Edit** в ее строке, выберите вариант **Review runs** и подтвердите. Доступны три варианта из раздела [Настройка времени запуска ревью](#set-when-reviews-run), а также **Off**.

После подтверждения вступают в силу следующие изменения:

* **Охват**: каждый репозиторий охватывается начиная со следующего pull request. Если Claude GitHub App был установлен на выбранные репозитории, а не на все, Claude проводит ревью этих репозиториев; чтобы охватить остальные, измените доступ приложения к репозиториям на GitHub.
* **Существующие настройки**: каждый репозиторий в этой организации GitHub получает выбранный вами вариант, включая репозитории, которые вы настраивали по отдельности. Повторная настройка строки приводит к тому же результату. Репозитории, которые вы отключили в их собственных строках, остаются отключенными.
* **Последующие индивидуальные изменения**: репозиторий, которому вы позже зададите настройку, отличающуюся от настройки его организации, помечается в таблице как **Custom**.
* **Уровень ревью**: у строки организации нет собственного уровня ревью.

### Отключение Code Review или удаление репозитория

В разделе **Code review** на странице [**Admin settings > Claude Code**](https://claude.ai/admin-settings/claude-code#code-review) выберите элемент управления, соответствующий тому, что вы хотите остановить:

* **Один репозиторий с сохранением его в списке**: нажмите **Edit** в его строке и отключите **Code review**. В таблице репозиторий будет отображаться как Off.
* **Один репозиторий с его удалением**: нажмите **Edit** в его строке, затем **Remove repository** внизу диалогового окна. Ревью в нем прекращаются, и после этого другая организация Claude может настроить этот репозиторий. Пока организация GitHub этого репозитория охвачена целиком, удалить его нельзя; вместо этого отключите его переключатель **Code review**.
* **Вся организация GitHub**: нажмите **Edit** в строке организации и выберите **Off**. Это также отключает репозитории этой организации, которые вы добавляли по одному.
* **Все**: отключите **Allow code review**. Новые ревью не запускаются ни в одном репозитории, а ваш список репозиториев сохраняется, чтобы вы могли снова включить функцию позже.
