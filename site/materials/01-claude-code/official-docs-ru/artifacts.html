Поделитесь выходом сеанса как артефактами #

Артефакты превращают работу Claude Code в живые интерактивные страницы на claude.ai, которые вы можете хранить в приватном режиме, делиться с вашей организацией или публиковать по общедоступной ссылке.

[!NOTE]

Артефакты доступны в планах Pro, Max, Ultra, Team и Enterprise и требуют сессии, вошедшей в систему с помощью /login. Полный набор требований см. в разделе Доступность.

Артефакт — это живая интерактивная веб-страница, которую Claude Code публикует из вашего сеанса на приватный URL на claude.ai. Вы открываете её в браузере, и она обновляется на месте по мере продолжения сеанса. Поделитесь ею из заголовка страницы, когда захотите, чтобы кто-то ещё её увидел.

Когда использовать артефакт #

Используйте артефакт, когда текст терминала — неправильный способ представления того, что создал Claude: вывод, который легче просматривать и с которым легче взаимодействовать, чем читать построчно. Claude создает страницу из всего, что может достичь ваша сессия, включая вашу кодовую базу и данные, которые она получает через ваши подключенные инструменты, поэтому страница может показывать вещи, которые потребовали бы абзацев для описания. Например, попросите Claude:

  • Провести рецензента через pull request с аннотированными diff'ами
  • Отрендерить панель управления из данных, которые сессия уже получила
  • Расположить несколько вариантов дизайна или реализации рядом
  • Вести временную шкалу расследования, которая заполняется во время выполнения длительной задачи
  • Отправить коллеге ссылку вместо вставки вывода в Slack
  • Опубликовать доску статуса, которая получает свежие данные через MCP connectors каждый раз, когда кто-то её открывает

См. Что вы можете создать для подсказок, которые соответствуют этим задачам, и Получение живых данных с помощью MCP connectors для подсказки доски с поддержкой connectors.

Что артефакт не является #

Артефакт — это снимок работы: одна самодостаточная страница без бэкенда, поэтому она не может обслуживать несколько маршрутов. Для размещённого внутреннего инструмента с бэкендом разверните его на собственной инфраструктуре. См. Ограничения страницы для полного набора ограничений.

Создание артефакта #

Claude может опубликовать артефакт самостоятельно, когда результат подходит для страницы, или вы можете попросить его напрямую. Чтобы попросить, назовите функцию или опишите желаемый визуальный результат простым языком. Хорошим кандидатом является все, что легче увидеть, чем прочитать как текст, например аннотированный diff, диаграмма или набор вариантов для сравнения. Приведенные ниже подсказки — два примера; см. Что вы можете создать для получения дополнительных шаблонов.

```text wrap theme={null} Make an artifact that walks through this PR with the diff annotated inline.

Build a dashboard artifact of last week's deploy failures by service and keep it updated as you investigate.


Если вы не указали местоположение, Claude записывает страницу в файл HTML или Markdown во временный каталог вне вашего проекта, а затем публикует его. Артефакт остается приватным для вас до тех пор, пока вы не [поделитесь им](#share-an-artifact).

После первой публикации Claude выводит URL, и ваш браузер открывает новую страницу.

* **Повторное открытие страницы**: нажмите `Ctrl+]` в любой момент, чтобы переоткрыть самый последний артефакт сессии
* **Просмотр артефактов этой сессии**: метка `⧉` под промптом показывает название артефакта или их количество, если в сессии их несколько. В [полноэкранном режиме отображения](https://code.claude.com/docs/ru/fullscreen.md) нажмите на нее, чтобы открыть список [`/artifacts`](#find-an-artifact-again)
* **Запрет открытия браузера**: установите `CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0` в вашей среде
* **Remote Control**: если вы отправили промпт через [Remote Control](https://code.claude.com/docs/ru/remote-control.md) с claude.ai, Claude Desktop или мобильного приложения Claude, вкладка не открывается на машине, на которой работает сессия. Браузер открывается там в следующий раз, когда Claude публикует артефакт из промпта, который вы вводите в терминале

Claude выбирает название артефакта и значок вкладки браузера, который соответствует тому, что представляет собой страница, например диаграмма или календарь. Название появляется в вашей [галерее артефактов](#share-an-artifact) на claude.ai и в общих ссылках. Попросите Claude выбрать конкретное название или значок вкладки, если хотите.

Если Claude ответит, что не может опубликовать, или напишет локальный файл HTML без ссылки, артефакты не включены для вашей сессии. Проверьте требования раздела [Доступность](#availability). Если в терминале отображается `Artifacts need a claude.ai login`, см. [описание этой ошибки](https://code.claude.com/docs/ru/errors.md#artifacts-need-a-claude-ai-login), чтобы узнать, как войти.

### Когда Claude Code спрашивает перед публикацией

Новый артефакт, который Claude публикует в ответ на введенный вами промпт, проходит без запроса разрешения или проверки классификатором. В следующих случаях Claude Code сначала спрашивает вас или в [авторежиме](https://code.claude.com/docs/ru/permission-modes.md#eliminate-prompts-with-auto-mode) поручает классификатору проверить публикацию:

| Когда | Что делает Claude Code |
| :- | :- |
| Сессия находится в [режиме планирования](https://code.claude.com/docs/ru/permission-modes.md#analyze-before-you-edit-with-plan-mode) | Спрашивает перед первой публикацией каждого артефакта |
| Публикация объявляет возможности выполнения для страницы, такие как [вызовы коннекторов](#pull-live-data-with-mcp-connectors) или [загрузки файлов](#offer-a-file-download) | Спрашивает перед этой публикацией |
| Вы поделились артефактом публично | Спрашивает один раз за диалог перед его изменением, а также перед каждым ответом на комментарий к нему |
| Claude публикует в ходе, который запустила сработавшая в вашей сессии [запланированная задача уровня сессии](https://code.claude.com/docs/ru/scheduled-tasks.md), а не введенный вами промпт | Спрашивает перед первой публикацией каждого артефакта |
| Claude не может прочитать файл без вашего подтверждения | Спрашивает перед его публикацией. Разрешающее правило для инструмента `Artifact` не позволяет пропустить этот запрос |
| В режиме [Manual](https://code.claude.com/docs/ru/permission-modes.md) или `acceptEdits` Claude вносит небольшое изменение в файл артефакта, который он не может редактировать без вашего подтверждения, например в файл проекта в режиме Manual | Спрашивает перед публикацией изменения. Запрос появляется, даже если разрешающее правило распространяется на инструмент `Artifact`, потому что изменение файла требует вашего подтверждения |

Чтобы Claude мог читать файл вне ваших [рабочих каталогов](https://code.claude.com/docs/ru/permissions.md#working-directories) без вашего подтверждения, добавьте его папку как рабочий каталог с помощью [`--add-dir`](https://code.claude.com/docs/ru/cli-reference#cli-flags) при запуске или `/add-dir` во время сессии. Claude уже читает файлы в этих каталогах, а также во временном каталоге, в который записывает страницы, не спрашивая.

Если запрос на публикацию содержит предложение вроде `Also makes 1 edit to that file on disk.`, Claude изменяет файл артефакта и публикует его за один шаг. Когда вы подтверждаете запрос, Claude Code публикует страницу, а затем записывает изменение в ваш файл.

## Обновление артефакта

Попросите Claude пересмотреть страницу или позвольте долгоживущей задаче переопубликовать её по мере выполнения. Claude редактирует базовый файл и переопубликовывает его на тот же URL.

Добавьте разбивку по регионам ниже диаграммы сводки и переопубликуйте.


Любой, у кого открыта страница, видит обновление на месте. Каждая публикация становится версией, и из элемента управления **Share** в заголовке страницы вы можете выбрать, какую версию видят зрители.

Чтобы обновить артефакт из другого сеанса, укажите Claude его URL или прикрепите его с помощью [`/artifacts`](#find-an-artifact-again). Без одного из них новый сеанс создаст новый артефакт вместо обновления существующего.

Обновите https://claude.ai/code/artifact/5fbea6f3-... с сегодняшними числами.


### Отключение одношаговых обновлений артефактов

Одношаговое обновление — это небольшое изменение, которое Claude вносит в файл артефакта в ходе публикации, а не через вызов `Edit` или `Write`.

Чтобы отключить одношаговые обновления, установите для [`CLAUDE_CODE_ARTIFACT_PUBLISH_EDITS`](https://code.claude.com/docs/ru/env-vars) значение `0`. В этом примере переменная добавляется в блок `env` в `~/.claude/settings.json`:

{ "env": { "CLAUDE_CODE_ARTIFACT_PUBLISH_EDITS": "0" } }


Затем закройте и снова запустите Claude Code, поскольку запущенная сессия не перечитывает эту переменную.

## Найти артефакт снова

Выполните `/artifacts` в Claude Code, чтобы вывести список принадлежащих вам артефактов и артефактов, которые с вами поделились. Артефакты текущей сессии отображаются первыми, в разделе **This session**.

Выберите артефакт, затем нажмите одну из следующих клавиш:

* **`Enter`**: открывает его в браузере, если он уже прикреплен к текущей сессии, и прикрепляет его, если нет
* **`o`**: открывает его в браузере
* **`c`**: копирует его ссылку
* **`d`**: вне [облачной сессии](https://code.claude.com/docs/ru/claude-code-on-the-web.md) безвозвратно удаляет принадлежащий вам артефакт после вашего подтверждения. Его ссылка перестает работать для всех, включая вас

Claude Code читает список из вашей учетной записи claude.ai, поэтому `/artifacts` работает в новой сессии и после `/clear`, когда ссылка на артефакт прокрутилась из терминала.

## Поделиться артефактом

Новый артефакт видна только вам. Чтобы поделиться ею, откройте артефакт в браузере и используйте элемент управления **Share** в заголовке страницы. Заголовок также содержит ссылку на вашу галерею на [claude.ai/code/artifacts](https://claude.ai/code/artifacts), в которой перечислены все созданные вами артефакты.

Зрители в вашей организации могут видеть, кто опубликовал страницу: на артефакте, общем доступе в пределах вашей организации, ваше имя находится в меню заголовка, а на общедоступном артефакте оно находится в заголовке страницы для вошедших в систему зрителей в вашей организации. Зритель, который открывает общедоступную ссылку без входа в систему или из-за пределов вашей организации, видит метку `Content is user-generated and unverified.` вместо вашего имени.

Кого вы можете добавить в общий доступ, зависит от вашего плана:

* **В пределах вашей организации**: в планах Team и Enterprise предоставьте доступ определённым людям в вашей организации или всем в ней. Зрители входят в claude.ai как члены вашей организации, чтобы увидеть страницу.
* **Люди с доступом к общей папке**: в планах Team и Enterprise переместите артефакт в папку, владельцем или редактором которой вы являетесь. Переместите его со [страницы Artifacts](https://claude.ai/artifacts), которая доступна, если вы можете использовать чат claude.ai. После этого все, у кого есть доступ к папке, смогут открыть его, а владелец и редакторы папки смогут его изменять.
* **Публично**: поделитесь ссылкой, которую может открыть любой в интернете, без необходимости входа в claude.ai. В планах Team и Enterprise общедоступный доступ отключён до тех пор, пока владелец не [включит его для организации](#control-public-sharing).

### Ссылка на определённое представление

Если на странице есть несколько представлений, например вкладки или разделы, вы можете дать ссылку непосредственно на одно из них. Попросите Claude предоставить ссылки:

Give me a link to each tab of the deploy failures dashboard.


Каждая ссылка — это ссылка на артефакт с якорем в конце, например `#overview`.

### Позвольте кому-то редактировать вместе с вами

Люди, с которыми вы делитесь, по умолчанию являются зрителями: они видят каждую опубликованную вами версию, но не могут изменять страницу. В планах Team и Enterprise вы также можете сделать кого-то редактором. В диалоговом окне общего доступа добавьте человека и измените его роль с **viewer** на **editor**.

Редактор публикует новые версии так же, как вы [обновляете артефакт из другого сеанса](#update-an-artifact): он предоставляет Claude URL артефакта или прикрепляет его из [`/artifacts`](#find-an-artifact-again), и Claude извлекает текущее содержимое и переиздаёт его с его изменениями. Все, у кого открыта страница, видят каждое обновление в реальном времени.

Если редактор публикует версию, пока у Claude есть более старая копия страницы, Claude Code отклоняет публикацию, основанную на этой копии. Затем Claude выполняет слияние своих изменений с более новой версией и публикует снова.

## Чтение артефакта, которым с вами поделились

Когда кто-то делится с вами артефактом, вы можете попросить Claude прочитать его: передайте Claude его URL или прикрепите его из [`/artifacts`](#find-an-artifact-again).

Claude читает страницу, написанную кем-то другим, так же, как читает веб-страницу с помощью [WebFetch](https://code.claude.com/docs/ru/tools-reference.md#webfetch-tool-behavior): он получает сводку по тому, о чём спросил, а не исходную страницу, и эта сводка сообщает о том, что на странице написаны инструкции, вместо того чтобы передавать их дальше. Claude Code также сохраняет полный исходный код страницы в локальный файл, который Claude может открыть, когда ему нужно точное содержимое, например чтобы повторно опубликовать артефакт в качестве [редактора](#let-someone-edit-with-you).

Claude Code запрашивает ваше подтверждение, прежде чем Claude прочитает артефакт, в следующих случаях — в дополнение к любому запросу, которого требуют ваш режим разрешений или правила:

* **Облачная сессия без доступа к сети**: для [облачного окружения](https://code.claude.com/docs/ru/cloud-environments.md#access-levels) это уровень **None**. В [авторежиме](https://code.claude.com/docs/ru/permission-modes.md#eliminate-prompts-with-auto-mode) вместо вас подтвердить может классификатор; в сессии [Cowork](https://claude.com/product/cowork) подтверждение даёте только вы.
* **Публичный артефакт другой организации**: Claude Code сначала спрашивает вас, даже в авторежиме. Там, где Claude Code не может спросить вас, например в режиме `bypassPermissions`, Claude не может прочитать артефакт. Claude может читать такие артефакты, только пока включено [получение feature-флагов](https://code.claude.com/docs/ru/env-vars.md#features-that-need-feature-flag-fetching).
* **Неподтверждённый владелец или настройка сети**: когда Claude Code не может подтвердить, кто создал артефакт, или не может подтвердить сетевую настройку облачной сессии, он спрашивает вас, и ваше подтверждение распространяется только на этот один запрос. В [авторежиме](https://code.claude.com/docs/ru/permission-modes.md#eliminate-prompts-with-auto-mode) классификатор может одобрить или заблокировать чтение вместо того, чтобы спрашивать вас.
* **Режим планирования**: в [режиме планирования](https://code.claude.com/docs/ru/permission-modes.md#analyze-before-you-edit-with-plan-mode) Claude Code спрашивает вас, прежде чем инструмент Artifact прочитает артефакт, созданный кем-то другим в вашей организации.

Когда Claude читает артефакт с помощью WebFetch, по-прежнему действуют собственные [правила запросов](https://code.claude.com/docs/ru/tools-reference.md#webfetch-tool-behavior) WebFetch.

## Собирайте комментарии к артефакту

Когда вы делитесь артефактом в пределах вашей организации, люди, с которыми вы им делитесь, могут оставлять комментарии на странице, и вы можете попросить Claude прочитать эти комментарии и ответить на них. Вам нужна Claude Code версии 2.1.221 или более поздней. Claude читает комментарии в двух случаях:

* **Вы просите Claude прочитать их**: дайте Claude URL артефакта и попросите комментарии. Claude перечисляет каждый тред и отмечает комментарии, которые отправил ему кто-то, кто может редактировать артефакт.
* **Кто-то, кто может редактировать артефакт, отправляет комментарий Claude**: в треде на странице они отправляют комментарий с помощью **Send to Claude**, или упоминают `@claude` в нём. В любом случае они активируют тред.

Claude может ответить или разрешить только активированный тред. Другие треды остаются открытыми до тех пор, пока человек не разрешит их на странице. Зрители видят каждый ответ, приписываемый Claude, через вас.

Если вы делитесь артефактом публично, люди, чей единственный доступ — это публичная ссылка, не видят его комментарии и не могут добавлять их. Существующие треды комментариев остаются на артефакте, и вы и его редакторы по-прежнему можете читать и отвечать на них.

Чтобы попросить комментарии самостоятельно, дайте Claude URL:

Read the comments on https://claude.ai/code/artifact/5fbea6f3-... and make the changes the commenters ask for.


Если Claude говорит вам, что не может читать комментарии, подтвердите вашу версию, вашу сессию и параметр флага функции:

* Вы используете Claude Code версии 2.1.221 или более поздней.
* Вы не находитесь в своей первой сессии после установки Claude Code или обновления с версии до v2.1.221. В этой [первой сессии после установки или обновления](https://code.claude.com/docs/ru/env-vars.md#first-session-after-an-install-or-upgrade) Claude может быть не в состоянии читать комментарии; начните новую сессию и попросите снова.
* Вы не отключили получение флагов функций.

### Позвольте Claude отвечать на комментарии самостоятельно

После того как ваша сессия опубликует артефакт, Claude Code следит за этим артефактом на предмет комментариев. Когда кто-то, кто может редактировать артефакт, отправляет комментарий Claude, он сразу же поступает в вашу сессию, и Claude может прочитать тред и ответить без вашего участия.

Вам нужна Claude Code версии 2.1.228 или более поздней. Если вы отключили [получение флагов функций](https://code.claude.com/docs/ru/env-vars.md#features-that-need-feature-flag-fetching), Claude Code не следит за комментариями.

Ваш [режим разрешений](https://code.claude.com/docs/ru/permission-modes.md) определяет, что делает Claude, когда приходит отправленный комментарий:

* **Claude отвечает самостоятельно**: если вы находитесь в режиме разрешений, который позволяет Claude опубликовать ответ, не спрашивая вас, Claude читает тред и отвечает. Вы видите `Auto-replied to comment thread on Artifact: <name>`.
* **Claude ждёт вас**: вне режима планирования, когда публикация ответа [потребует вашего подтверждения](#when-claude-code-asks-before-publishing), вы видите `Comments are waiting on Artifact: <name>`. Claude затем просит у вас подтверждение на чтение треда и снова на публикацию ответа.
* **Claude делает паузу в режиме плана**: вы видите `Comments are waiting on Artifact: <name>`, и Claude не отвечает до тех пор, пока вы не выйдете из режима плана и не попросите его прочитать и ответить.

Claude также прекращает отвечать самостоятельно на артефакт после обработки 60 отправленных комментариев или активаций тредов на этом артефакте в течение часа. Вы видите `Comments are waiting on Artifact: <name>` один раз, и Claude возобновляет работу по мере того, как комментарии этого часа устаревают.

Запустите `/tasks`, чтобы увидеть артефакты, за которыми следит ваша сессия. `/tasks` группирует наблюдения, которые Claude Code запустил самостоятельно, в строке **System tasks**. Нажмите `Enter` на этой строке, чтобы вывести их список. Наблюдение, которое вы попросили Claude запустить, отображается в разделе **Monitors**.

Вы можете остановить Claude от самостоятельного ответа любым из этих способов:

* **Нажмите Ctrl+C один раз в неактивном пустом промпте**: Claude приостанавливает ответы на каждый артефакт, за которым следит ваша сессия. Ответы возобновляются после того, как вы отправите следующее сообщение.
* **Остановите задачу в `/tasks`**: Claude прекращает отвечать на этот артефакт до тех пор, пока вы не попросите его возобновить ответы там. Повторная публикация артефакта не запускает ответы снова, и остановка по-прежнему применяется при возобновлении сессии позже.
* **Нажмите `Ctrl+X Ctrl+K` дважды в течение 3 секунд**: комбинация, которая [останавливает каждого работающего фонового подагента](https://code.claude.com/docs/ru/interactive-mode.md#general-controls), также останавливает Claude от ответа на каждый артефакт на оставшуюся часть сессии. Просьба Claude возобновить ответы не отменяет эту остановку.

Наблюдение, которое Claude Code запустил самостоятельно, может завершиться, если в артефакте несколько часов не было активности. Чтобы снова запустить наблюдение, опубликуйте артефакт ещё раз или попросите Claude следить за ним.

Если служба, которая доставляет комментарии, становится недоступной или перестаёт отвечать, Claude Code продолжает пытаться переподключиться в течение некоторого времени, а затем прекращает следить за каждым артефактом, за которым следила ваша сессия.

## Получение актуальных данных с помощью коннекторов MCP

Артефакт может вызывать [коннекторы MCP](https://code.claude.com/docs/ru/mcp.md#use-mcp-servers-from-claude-ai) каждый раз, когда кто-то его просматривает, поэтому страница отображает текущие данные, а не снимок из сессии, в которой она была создана. Вызовы коннекторов из артефактов доступны в планах Pro, Max, Ultra, Team и Enterprise и требуют Claude Code версии 2.1.209 или более поздней. В более ранних версиях Claude публикует страницу с теми данными, которые сессия собрала во время её создания.

Чтобы создать страницу с поддержкой коннектора, назовите коннектор и данные, которые вам нужны, в вашем запросе:

Build a dashboard artifact of our open pull requests that pulls the live list through my GitHub connector when the page loads.


Claude объявляет, какие коннекторы может вызывать страница, как часть публикации, и страница не может вызывать коннекторы вне этого объявления. Только коннекторы из вашей учётной записи claude.ai подходят: Claude называет их в объявлении, и когда кто-то просматривает страницу, каждый вызов [выполняется через собственное подключение учётной записи просмотра](#how-connector-calls-work-for-viewers) к этому коннектору. Локальные MCP серверы, которые вы настраиваете в Claude Code, такие как серверы из `.mcp.json`, могут предоставлять данные во время создания страницы Claude, но опубликованная страница не может их вызывать.

Страница получает данные при загрузке и может обновляться по расписанию или когда зритель использует элемент управления обновлением на странице. Ответы кэшируются в браузере зрителя, поэтому повторно открытая страница отображается из кэшированных ответов немедленно, а затем обновляется с новыми результатами.

### Как работают вызовы коннекторов для зрителей

Когда опубликованная страница вызывает коннектор, вызов использует учётную запись человека, просматривающего страницу, а не учётную запись человека, который её опубликовал:

* **Каждый зритель использует свои собственные коннекторы**: вызовы проходят через подключённые инструменты учётной записи просмотра, поэтому два человека, открывающие одну и ту же панель управления, могут видеть разные данные в зависимости от того, к чему имеют доступ их учётные записи. Страница никогда не видит учётные данные никого; claude.ai делает вызовы от имени страницы.
* **Зрители сначала одобряют доступ**: claude.ai просит разрешение у каждого зрителя перед первым вызовом коннектора на странице. Зритель, который отказывает, или у которого нет подключённого коннектора, используемого страницей, всё равно видит страницу без её живых разделов.
* **Действия также используют учётную запись зрителя**: страница может предлагать элементы управления, которые вызывают инструменты коннектора с побочными эффектами, такие как отправка сообщения или обновление проблемы. Действие выполняется через учётную запись того, кто выбирает элемент управления.

Когда вы планируете поделиться страницей с поддержкой коннектора, попросите Claude включить резервное сообщение в каждый живой раздел, который называет коннектор, который ему нужен. Зритель, у которого отсутствует подключение, затем видит, что нужно подключить, вместо пустого раздела.

Вы можете [поделиться страницей с поддержкой коннектора](#share-an-artifact) в пределах вашей организации или публично, как позволяют ваш план и параметры организации. Вызовы коннекторов не выполняются для зрителя, который открывает публичную ссылку без входа в claude.ai или из-за пределов вашей организации. Этот зритель видит страницу без её живых разделов.

### Страница не показывает живые данные для зрителя

Когда страница с поддержкой коннектора отображается, но её живые разделы остаются пустыми для зрителя в вашей организации, проработайте эти причины:

* **Зритель не подключил коннектор**: коннекторы привязаны к учётной записи, поэтому каждому зрителю нужно своё подключение к каждому коннектору, который вызывает страница. Он может добавить его на [claude.ai/customize/connectors](https://claude.ai/customize/connectors), а затем перезагрузить страницу.
* **Зритель отказал в разрешении**: отказ действует до конца этой загрузки страницы. Перезагрузка страницы возвращает запрос разрешения.
* **Вызовы коннекторов отключены для организации**: владелец управляет переключателем [**Enable artifact connectors**](#control-connector-calls-from-artifacts) в параметрах администратора.
* **Страница вызывает имена инструментов, которые коннектор не предоставляет**: затронутые разделы остаются пустыми для всех, включая вас. Это может произойти, когда страница называет отдельные инструменты за коннектором в стиле шлюза, который предоставляет только несколько собственных инструментов. Попросите Claude исправить имена инструментов, которые вызывает страница, и опубликуйте её снова.

  Когда Claude публикует страницу и инструменты этого коннектора доступны в вашем сеансе, Claude Code проверяет имена инструментов, которые объявляет страница, против них, предупреждает Claude об именах, которые не совпадают, и отказывает в публикации, когда ни один не совпадает. До версии 2.1.265 она публиковала страницу без их проверки.

## Предложить загрузку файла

Артефакт может предложить зрителям файл, который генерирует страница, например CSV-экспорт таблицы или PNG диаграммы. Зритель сохраняет его через элемент управления загрузкой на странице, например кнопку. Загрузки файлов — это возможность во время выполнения, которую claude.ai включает для каждой учетной записи, поэтому Claude проверяет, есть ли у вашей учетной записи эта возможность, прежде чем создавать элемент управления.

Зрители не могут сохранить файл из обычной ссылки для загрузки или скрипта на странице, потому что средство просмотра артефактов на claude.ai блокирует любую загрузку, которую инициирует сама страница, включая ссылки на URL-адреса `data:` или `blob:`. Если на странице есть кнопки загрузки, созданные таким образом, попросите Claude перестроить их с использованием возможности загрузок.

Чтобы предложить файл, запросите элемент управления и формат файла в вашем приглашении:

Add a button that downloads this table as a CSV file.


Claude объявляет возможность загрузок как часть публикации, так же как это [объявляет connectors](#pull-live-data-with-mcp-connectors).

## What you can build

Артефакт — это одна страница HTML, поэтому всё, что вы можете выразить в HTML, CSS и встроенном JavaScript, находится в области действия. Приведённые ниже шаблоны встречаются чаще всего.

### Walk through a change

Попросите страницу, которая отображает diff или изменение дизайна с аннотациями рядом с соответствующими строками, чтобы рецензенты могли прочитать ваше обоснование рядом с кодом вместо того, чтобы восстанавливать его из описания.

Make an artifact that walks through this PR. Render the diff with margin annotations and color-code findings by severity.


### Compare alternatives

Попросите несколько вариантов на одной странице, чтобы вы могли оценить их друг против друга. Это работает для макетов, копии, форм API или планов реализации.

Make an artifact with four distinctly different layouts for the settings panel. Vary density and grouping, and lay them out as a grid with a one-line tradeoff under each.


### Tune with interactive controls

Попросите ползунки, переключатели или поля ввода, привязанные к тому, что вы настраиваете, чтобы вы могли исследовать значения напрямую вместо их описания.

Build an artifact with sliders for the easing curve, duration, and delay so I can try values on this transition. Show the animation live as I move them.


### Bring the result back to your session

Артефакт может действовать как лёгкий редактор для решения, которое вы затем передаёте Claude. Попросите элемент управления экспортом, который производит текст, который вы можете вставить в терминал, чтобы результат взаимодействия со страницей вернулся в сеанс вместо того, чтобы остаться на странице.

Make a triage board artifact with each open issue as a draggable card across Now, Next, Later, and Cut columns. Add a "Copy as prompt" button that gives me the final ordering to paste back here.


### Track work in progress

Попросите Claude держать артефакт в актуальном состоянии во время выполнения длительной задачи, чтобы любой, у кого есть ссылка, мог следить без чтения терминала.

Turn this migration plan into a checklist artifact. Check items off as you complete them and add a note for anything you skip.


## Улучшение визуального дизайна

Claude применяет встроенный навык дизайна при создании артефакта, поэтому страницы получают продуманную палитру, типографику и макет без дополнительных подсказок. Этот навык также ищет существующую систему дизайна в вашем проекте перед выбором собственной. Дизайн-токены — это названные значения цвета, типографики и интервалов, которые ваша система дизайна переиспользует. Чтобы сохранить артефакты в соответствии с брендингом вашего продукта, запишите их там, где Claude сможет их найти, например в файле [CLAUDE.md](https://code.claude.com/docs/ru/memory.md) вашего проекта или в файле темы в вашем репозитории:

Design system #

  • Colors: primary #1a4d8f, accent #f59e0b, surface #f8fafc
  • Typography: Inter for body, JetBrains Mono for code
  • Spacing: 8px scale, 6px border radius

Claude рассматривает вашу систему дизайна как имеющую более высокий приоритет, чем его собственные выборы, а вашу подсказку как имеющую более высокий приоритет, чем оба. Заголовок и формат выше — это пример; подойдет любой четкий список цветов, шрифтов и интервалов.

Для типографики Claude может загружать шрифт из Google Fonts, единственного внешнего источника шрифтов, из которого может загружаться страница артефакта. Claude встраивает любой другой шрифт как `@font-face` data URI и предоставляет каждому шрифту резервный стек, поэтому страница все еще отображается, если шрифт не загружается. Чтобы использовать определенный шрифт, назовите его в вашей подсказке или в вашей системе дизайна.

## Создание артефакта из шаблона

[Шаблоны артефактов](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them#h_11d5a9a5fa) в вашей учетной записи claude.ai также работают из Claude Code. Например, используйте шаблон [Claude Design](https://support.claude.com/en/articles/14604416-get-started-with-claude-design) для визуального дизайна или шаблон [Claude Docs](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs) для документа, который будут читать и редактировать другие люди. В вашей учетной записи могут быть и другие шаблоны, например Sheets, Whiteboards или Data. Чтобы узнать, какие из них доступны в вашей сессии, попросите Claude перечислить доступные вам шаблоны артефактов.

Чтобы использовать шаблон из Claude Code, вам нужно:

* Сессия, в которой [артефакты доступны](#availability)
* В планах Team и Enterprise шаблон должен быть включен для вашей организации. Если он отключен, попросите владельца (Owner) [включить шаблон](https://support.claude.com/en/articles/16994751-artifacts-admin-guide-for-team-and-enterprise-plans#h_6e06d8f1a8) в разделе **Organization settings > Artifacts** на claude.ai.
* В планах Enterprise с пользовательскими ролями — роль, которая [включает шаблон](https://support.claude.com/en/articles/16994751-artifacts-admin-guide-for-team-and-enterprise-plans#h_d830917488)
* Для шаблонов Docs и Sheets — [коннектор Claude Docs](#write-a-document-with-claude-docs), который Claude использует для написания содержимого обоих. Если вы [отключили коннектор](https://code.claude.com/docs/ru/mcp.md#disable-claude-ai-connectors), сначала включите его снова.
* Claude Code версии 2.1.265 или более поздней, если вы запускаете шаблон Design с помощью его [команды `/design`](#draft-a-design-canvas)

Чтобы начать с шаблона, назовите его или опишите, что вы хотите, например «оформите этот план как документ для команды» или «сделайте общую таблицу задач». Claude выбирает подходящий шаблон, заполняет его на основе вашего промпта и того, что уже есть в сессии, и дает вам ссылку. Чтобы вместо этого получить файл, укажите формат, например `.csv`.

Чтобы отредактировать артефакт самостоятельно, откройте ссылку, которая ведет в редактор этого шаблона на claude.ai. Вы также можете продолжать просить Claude внести изменения из своей сессии. Форматы экспорта описаны в разделе [View and export](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them#h_1403132eb8).

### Создайте макет дизайна

Чтобы создать макет пользовательского интерфейса, потока экранов, целевой страницы или постера вместо создания страницы, запустите `/design` с кратким описанием. Claude создает дизайн в виде артбордов на одном холсте и публикует холст как артефакт Claude Design. В кратком описании указывается, что вы хотите нарисовать:

/design a settings screen for a mobile banking app


Откройте опубликованный артефакт в браузере рабочего стола для просмотра артбордов. Выберите элемент на артборде и измените его, и ваши правки сохранятся автоматически. Вы можете экспортировать каждый артборд как PNG или PDF.

### Напишите документ с помощью Claude Docs

Claude Docs подключается к Claude Code как [соединитель](https://code.claude.com/docs/ru/mcp.md#use-mcp-servers-from-claude-ai) claude.ai, а не как команда. Когда он подключен, `/mcp` отображает его как `claude.ai Claude Docs`. Запрос на документ, предназначенный для других людей, затем переходит в Claude Docs вместо страницы артефакта: спецификация, предложение или описание плана, который вы разработали в сеансе. Claude дает вам ссылку на документ, когда он создан.

Документ, который принадлежит кодовой базе, например README, остается файлом. Чтобы получить файл для чего-то, что Claude иначе поместил бы в Claude Docs, укажите формат, например `.docx` или файл Markdown в репозитории. Чтобы отключить только коннектор `claude.ai Claude Docs`, см. раздел [Отключение коннекторов claude.ai](https://code.claude.com/docs/ru/mcp.md#disable-claude-ai-connectors). Не отключайте коннектор, если вы используете шаблон Sheets, которому он тоже нужен.

## Ограничения страницы

Каждый артефакт — это одна самостоятельная страница. Claude Code оборачивает опубликованный файл в оболочку HTML-документа и обслуживает его в соответствии со строгой политикой безопасности контента (CSP), которая определяет возможности страницы.

| Ограничение | Эффект |
| :- | :- |
| Внешние запросы | Страница может загружать шрифты из Google Fonts и скрипты с [пяти общедоступных хостов CDN](#allowlist-the-viewer-domain): cdnjs, unpkg, Tailwind и jQuery CDN, а также выбранные пути на jsDelivr, такие как `/npm/`. CSP блокирует все внешние изображения и все остальные внешние скрипты, таблицы стилей и шрифты, а также позволяет вызовам `fetch`, XHR и WebSocket достигать только собственного источника страницы и хостов Google Fonts. Claude поэтому загружает любую библиотеку, которая требуется странице, с одного из этих CDN, встраивает все остальные CSS и JavaScript, а также встраивает изображения как data URI. [Вызовы Connector](#pull-live-data-with-mcp-connectors) проходят через claude.ai, который сам выполняет сетевой вызов. |
| Нет бэкенда | Артефакт — это статическая страница. Она не может самостоятельно аутентифицировать зрителей. |
| Загрузки | Страница не может самостоятельно инициировать загрузку. Чтобы позволить зрителям сохранить файл, который генерирует страница, Claude объявляет возможность загрузок. См. [Предложить загрузку файла](#offer-a-file-download). |
| Типы исходных файлов | Опубликованный файл должен быть `.html`, `.htm` или `.md`, и должен декодироваться как UTF-8, или как little-endian UTF-16 по его метке порядка байтов. Файлы Markdown отображаются как стилизованные страницы документов с подсветкой синтаксиса кода. Файл, который не декодируется, или который содержит символ замены `U+FFFD`, [отклоняется с указанием строки и столбца для исправления](https://code.claude.com/docs/ru/errors.md#the-source-file-is-not-valid-utf-8-text). |
| Расположение исходного файла | Файл по пути, указывающему на сетевой хост, отклоняется без чтения. О том, какие пути отклоняются, и об исключении для подключённых сетевых дисков в Windows см. [Не опубликовано: файл находится в сетевой папке](https://code.claude.com/docs/ru/errors.md#not-published-that-file-is-on-a-network-share). |
| Размер отрендеренной страницы | Отрендеренная страница должна быть размером 16 МиБ или меньше. Большие встроенные изображения — обычная причина, когда публикация не удается из-за размера. |

Создание артефакта использует выходные токены, как и любой другой ответ, а стилизованная страница требует больше токенов, чем тот же контент в виде текста терминала. Встроенный CSS, JavaScript для интерактивных элементов управления и особенно изображения, встроенные как data URI, являются основными факторами. Чтобы снизить стоимость артефакта в токенах:

* Предпочитайте SVG или HTML и CSS для диаграмм вместо встроенных растровых изображений
* Опускайте интерактивность, которая вам не нужна
* Пусть страница суммирует большие наборы данных вместо того, чтобы встраивать их полностью

## Availability

Артефакты требуют каждого условия ниже. Когда одно из них не выполнено, Claude записывает локальный файл HTML или говорит, что не может опубликовать вместо этого.

| Requirement | Available when |
| :- | :- |
| Plan | Pro, Max, Ultra, Team или Enterprise. На планах Pro, Max и Ultra артефакты являются приватными для вас до тех пор, пока вы ими не поделитесь, и управление администратором не применяется. На планах Team и Enterprise артефакты включены по умолчанию, и Owner может [отключить их для организации](#manage-artifacts-for-your-organization) в настройках администратора claude.ai. |
| Authentication | Сессия поддерживается учётной записью claude.ai: войдите с помощью `/login` в CLI или приложении для рабочего стола. Сессиям Claude Tag не требуется шаг входа. Сессии, использующие API-ключ, [токен шлюза](https://code.claude.com/docs/ru/llm-gateway) или учётные данные поставщика облачных услуг, не могут публиковать. |
| Model provider | Anthropic API. Недоступно на [Amazon Bedrock](https://code.claude.com/docs/ru/amazon-bedrock.md), [Google Cloud's Agent Platform](https://code.claude.com/docs/ru/google-vertex-ai.md) или [Microsoft Foundry](https://code.claude.com/docs/ru/microsoft-foundry.md). |
| Organization policy | Ключи шифрования, управляемые клиентом (CMEK), HIPAA и [Zero Data Retention](https://code.claude.com/docs/ru/zero-data-retention.md) не включены для организации. |
| Surface | Claude Code CLI или приложение Claude для рабочего стола версии 1.13576.0 или позже. Сессии [Claude Tag](https://claude.com/docs/claude-tag/overview) также могут публиковать артефакты, когда и Claude Tag, и артефакты включены для организации. Сессии, обслуживаемые [`claude remote-control`](https://code.claude.com/docs/ru/remote-control), могут публиковать артефакты, если вы запустили сессию самостоятельно. Требуется Claude Code v2.1.281 или более поздней версии. По умолчанию отключено в [Agent SDK](https://code.claude.com/docs/ru/agent-sdk/overview.md), GitHub Action и контекстах MCP-сервера, при запуске Claude Code с [`-p`](https://code.claude.com/docs/ru/headless) из вашего собственного терминала или скриптов, а также когда установлен [`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`](https://code.claude.com/docs/ru/env-vars). |

Доступность артефактов для вашей организации определяется политикой вашей организации, которую Claude Code загружает из `api.anthropic.com`. Когда Claude Code не может загрузить политику, артефакты недоступны. Когда вы просите один, Claude объясняет почему.

Если задействован прокси, VPN или веб-фильтр, попросите вашего администратора IT разрешить `api.anthropic.com`. Claude Code продолжает повторять попытки в фоновом режиме, и артефакты становятся доступными после загрузки политики и её разрешения.

## Отключение артефактов

Чтобы отключить артефакты для своих сеансов независимо от параметра вашей организации, используйте любой из следующих способов:

| Где | Что делать |
| :- | :- |
| [`/config`](https://code.claude.com/docs/ru/commands) | Отключите строку **Artifacts**, которая записывает [`"enableArtifact": false`](https://code.claude.com/docs/ru/settings-reference#enableartifact) в ваши пользовательские параметры |
| [Файл параметров](https://code.claude.com/docs/ru/settings.md) | Установите `"enableArtifact": false`. Устаревший параметр `"disableArtifact": true` также отключает артефакты |
| [Переменная окружения](https://code.claude.com/docs/ru/env-vars.md) | Установите `CLAUDE_CODE_DISABLE_ARTIFACT=1` |
| [Правило разрешений](https://code.claude.com/docs/ru/permissions.md) | Добавьте `Artifact` в `permissions.deny` |

После того как вы отключите артефакты в файле [`--settings`](https://code.claude.com/docs/ru/cli-reference#cli-flags) или с помощью `CLAUDE_CODE_DISABLE_ARTIFACT`, или ваш администратор отключит их в [управляемых параметрах](https://code.claude.com/docs/ru/server-managed-settings.md), ни один файл параметров не включит их обратно.

Вы также можете установить `"enableArtifact": false` в файле `.claude/settings.json` или `.claude/settings.local.json` проекта, чтобы отключить артефакты для сеансов в этом проекте. Параметр `"enableArtifact": true` в любом из этих файлов не включит их обратно. Поддержка этого ключа в параметрах проекта и локальных параметрах требует Claude Code версии 2.1.242 или более поздней.

Если вы добавите правило `WebFetch` deny или ask без части `domain:`, оно не отключит артефакты и не заблокирует чтение артефактов. [Правило `WebFetch(domain:claude.ai)` в `deny` или `ask` применяется к чтению артефактов](https://code.claude.com/docs/ru/permissions#allow-or-deny-every-fetch).

## Управление артефактами для вашей организации

Владельцы планов Team и Enterprise управляют артефактами из [параметров администратора claude.ai](https://claude.ai/admin-settings/artifacts). Содержимое артефактов хранится на инфраструктуре, управляемой Anthropic, и видно только аутентифицированным членам организации-издателя и людям, с которыми они его совместно используют, если только артефакт не [опубликован публично](#control-public-sharing).

### Включение или отключение артефактов

Чтобы включить или отключить артефакты для всей организации, перейдите в [**Organization settings > Artifacts**](https://claude.ai/admin-settings/artifacts) и используйте переключатель **Artifacts**. На планах Enterprise с управлением доступом на основе ролей вы можете дополнительно ограничить артефакты определёнными ролями: перейдите в [**Organization settings > Roles**](https://claude.ai/admin-settings/roles), отредактируйте роль и установите разрешение **Artifacts**.

### Управление вызовами соединителей из артефактов

[Вызовы соединителей из артефактов](#pull-live-data-with-mcp-connectors) имеют собственный переключатель, отдельный от переключателя **Artifacts**, который включает или отключает артефакты. Перейдите в [**Organization settings > Capabilities**](https://claude.ai/admin-settings/capabilities) и используйте переключатель **Enable artifact connectors**. Один и тот же переключатель управляет вызовами соединителей из артефактов, созданных в беседах claude.ai.

### Управление публичным совместным использованием

Публичное совместное использование отключено по умолчанию на планах Team и Enterprise. Чтобы позволить членам публиковать артефакты на публичные ссылки, которые может просматривать любой без входа, перейдите в [**Organization settings > Artifacts**](https://claude.ai/admin-settings/artifacts) и включите **External sharing** под переключателем **Artifacts**. Отключение его обратно блокирует доступ через существующие публичные ссылки без изменения аудитории каждого артефакта; доступ возобновляется, если вы его снова включите.

### Установка политики хранения

Чтобы установить, как долго артефакты хранятся перед автоматическим удалением, перейдите в [**Organization settings > Data and privacy**](https://claude.ai/admin-settings/data-privacy-controls). Вы можете установить отдельные периоды хранения для артефактов, которые остаются приватными для их автора, и артефактов, которые были совместно использованы.

### Аудит активности артефактов с помощью API соответствия

На планах Enterprise выполните запрос к [Activity Feed](https://platform.claude.com/docs/en/manage-claude/compliance-activity-feed) API соответствия, чтобы увидеть, кто опубликовал, предоставил в совместное использование или удалил артефакт. Чтобы найти типы активности для фильтрации, разверните `activity_types` в [справочнике Activity Feed](https://platform.claude.com/docs/en/api/compliance/activities/list) и найдите имена, содержащие `artifact`.

### Добавление домена средства просмотра в список разрешений

Средство просмотра на claude.ai загружает каждый артефакт из изолированного источника `*.claudeusercontent.com`. Если ваша организация ограничивает исходящий сетевой доступ, добавьте этот домен в список разрешений вместе с `claude.ai`. См. [Требования к сетевому доступу](https://code.claude.com/docs/ru/network-config.md#network-access-requirements) для полного списка.

Артефакт, который загружает шрифт из [Google Fonts](#improve-the-visual-design), также запрашивает `fonts.googleapis.com` и `fonts.gstatic.com`. Оба хоста являются необязательными. Если вы их блокируете, артефакты отображаются в резервных шрифтах. Блокируйте с быстрым отклонением, а не с молчаливым отбросом, чтобы запрос шрифта завершился немедленно, а не задержал первый рендер страницы.

Артефакты также могут загружать библиотеки JavaScript, такие как React или пакет для построения диаграмм, из `cdnjs.cloudflare.com`, `cdn.jsdelivr.net`, `cdn.tailwindcss.com`, `code.jquery.com` и `unpkg.com`, и ни откуда больше. Если вы блокируете эти хосты, части артефакта, которые зависят от библиотеки, не работают, и в отличие от заблокированного шрифта, заблокированная библиотека не имеет резервного варианта. Блокируйте с быстрым отклонением и здесь, чтобы заблокированный запрос библиотеки завершился сразу, а не зависал до истечения времени ожидания.

### Список и удаление артефактов с помощью API соответствия

[API соответствия](https://docs.claude.com/en/api/compliance) предоставляет конечные точки для списка артефактов организации, получения содержимого определённой версии и удаления артефакта:

| Метод | Конечная точка |
| :- | :- |
| `GET` | `/v1/compliance/apps/code/artifacts` |
| `GET` | `/v1/compliance/apps/code/artifacts/{artifact_id}/versions/{version_id}` |
| `DELETE` | `/v1/compliance/apps/code/artifacts/{artifact_id}` |

Для схем запроса и ответа см. [справочник API соответствия](https://platform.claude.com/docs/en/api/compliance/apps/code/artifacts).
