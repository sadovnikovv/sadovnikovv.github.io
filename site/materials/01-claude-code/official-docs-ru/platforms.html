Платформы и интеграции #

Выберите, где запустить Claude Code и что к нему подключить. Сравните CLI, Desktop, VS Code, JetBrains, веб, мобильные приложения и интеграции, такие как Chrome, Slack и CI/CD.

Claude Code запускает один и тот же базовый движок везде, но каждая поверхность оптимизирована для разного способа работы. Эта страница поможет вам выбрать правильную платформу для вашего рабочего процесса и подключить инструменты, которые вы уже используете.

Где запустить Claude Code #

Выберите платформу в зависимости от того, как вы предпочитаете работать и где находится ваш проект.

| Платформа | Лучше всего для | Что вы получаете | | :- | :- | :- | | CLI | Рабочие процессы терминала, скриптинг, удалённые серверы | Полный набор функций, Agent SDK, использование компьютера на macOS (Pro, Max и Ultra), сторонние поставщики | | Desktop | Визуальный просмотр, параллельные сессии, управляемая установка | Средство просмотра различий, предпросмотр приложения, использование компьютера и Dispatch на Pro, Max и Ultra | | VS Code | Работа внутри VS Code без переключения на терминал | Встроенные различия, интегрированный терминал, контекст файла | | JetBrains | Работа внутри IntelliJ, PyCharm, WebStorm или других IDE JetBrains | Средство просмотра различий, совместное использование выделения, сеанс терминала | | Web | Долгосрочные задачи, которые не требуют большого управления, или работа, которая должна продолжаться, когда вы не в сети | Облако, по умолчанию управляемое Anthropic; продолжается после отключения | | Mobile | Запуск и мониторинг задач вдали от вашего компьютера | Облачные сессии из приложения Claude для iOS и Android, Remote Control для локальных сессий, Dispatch на Desktop на Pro, Max и Ultra |

CLI — это наиболее полная поверхность для работы, ориентированной на терминал: скриптинг и Agent SDK доступны только в CLI. Сторонние поставщики также работают в VS Code и в JetBrains, который запускает CLI в терминале вашей IDE. Корпоративные развёртывания Desktop поддерживают Google Cloud's Agent Platform, и Desktop поддерживает поставщиков шлюза; для Amazon Bedrock или Microsoft Foundry используйте CLI или расширение IDE, или Claude Desktop on 3P, который запускает вкладку Code на этих поставщиках. Desktop и расширения IDE обменивают некоторые функции, доступные только в CLI, на визуальный просмотр и более тесную интеграцию с редактором. Веб работает в облаке, поэтому задачи продолжают выполняться после отключения. Mobile — это тонкий клиент для этих же облачных сеансов или для локального сеанса через Remote Control, и может отправлять задачи на Desktop с помощью Dispatch.

Вы можете смешивать поверхности в одном проекте. Конфигурация, память проекта и MCP серверы совместно используются на локальных поверхностях.

Подключите ваши инструменты #

Интеграции позволяют Claude работать с сервисами вне вашей кодовой базы.

| Интеграция | Что она делает | Используйте для | | :- | :- | :- | | Chrome | Управляет вашим браузером с вашими авторизованными сеансами | Тестирование веб-приложений, заполнение форм, автоматизация сайтов без API | | GitHub Actions | Запускает Claude в вашем конвейере CI | Автоматические проверки PR, сортировка проблем, запланированное обслуживание | | GitLab CI/CD | То же самое, что GitHub Actions для GitLab | Автоматизация, управляемая CI на GitLab | | Code Review | Автоматически проверяет каждый PR | Выявление ошибок перед проверкой человеком | | Slack | Отвечает на упоминания @Claude в ваших каналах от имени вашей собственной учётной записи | Превращение отчётов об ошибках в pull requests из чата команды на планах Pro, Max и Ultra | | Claude Tag | Запускает @Claude как общую идентификацию вашей организации с настроенным администратором доступом | Общий доступ команды на планах Team и Enterprise вместо сеансов Slack для каждого пользователя |

Для интеграций, не указанных здесь, MCP серверы и соединители позволяют подключить почти всё: Linear, Notion, Google Drive или ваши собственные внутренние API.

Работайте, когда вы вдали от вашего терминала #

Claude Code предлагает несколько способов работы, когда вы находитесь не у терминала. Они отличаются тем, что запускает работу, где работает Claude, и сколько настроек вам нужно выполнить.

| | Триггер | Claude работает на | Настройка | Лучше всего для | | :- | :- | :- | :- | :- | | Dispatch | Отправьте задачу из мобильного приложения Claude | Ваша машина (Desktop) | Свяжите мобильное приложение с Desktop | Делегирование работы, когда вас нет, минимальная настройка | | Remote Control | Управляйте запущенной сессией из claude.ai/code или мобильного приложения Claude | Ваша машина (CLI, Desktop или VS Code) | Запустите claude remote-control или /remote-control | Управление текущей работой с другого устройства | | Channels | Отправляйте события из приложения чата, такого как Telegram или Discord, или с вашего собственного сервера | Ваша машина (CLI) | Установите плагин канала или создайте свой | Реагирование на внешние события, такие как сбои CI или сообщения в чате | | Slack | Упомяните @Claude в канале команды | Облако Anthropic | Установите приложение Slack с включенным Claude Code в веб-версии, в планах Pro, Max и Ultra | PR и рецензии из чата команды | | Self-hosted environments | Запустите облачную сессию и выберите окружение вашей организации | Инфраструктура вашей организации | Разверните runners, в планах Team и Enterprise | Облачные сессии, которые должны работать внутри вашей сети | | Scheduled tasks | Установите расписание | CLI, Desktop или облако | Выберите частоту | Повторяющаяся автоматизация, такая как ежедневные проверки |

Если вы не уверены, с чего начать, установите CLI и запустите его в каталоге проекта. Если вы предпочитаете не использовать терминал, Desktop предоставляет вам тот же движок с графическим интерфейсом.

Связанные ресурсы #

Платформы #

  • Быстрый старт CLI: установка и запуск вашей первой команды в терминале
  • Desktop: визуальный просмотр различий, параллельные сеансы, использование компьютера и Dispatch
  • VS Code: расширение Claude Code внутри вашего редактора
  • JetBrains: расширение для IntelliJ, PyCharm и других IDE JetBrains
  • Web: облачные сеансы из вашего браузера на claude.ai/code, которые продолжают работать при отключении
  • Projects: один разговор, в котором Claude координирует множество облачных сеансов для выполнения работы и отправляет отчёты
  • Mobile: приложение Claude для iOS и Android для запуска и мониторинга задач вдали от вашего компьютера

Интеграции #

  • Chrome: автоматизация задач браузера с вашими авторизованными сеансами
  • Computer use: позвольте Claude открывать приложения и управлять вашим экраном на macOS
  • GitHub Actions: запуск Claude в вашем конвейере CI
  • GitLab CI/CD: то же самое для GitLab
  • Code Review: автоматическая проверка при каждом pull request
  • Slack: отправка задач из чата команды и получение PR обратно в планах Pro, Max и Ultra
  • Claude Tag: запуск @Claude как общей идентификации вашей организации в планах Team и Enterprise

Удалённый доступ #

  • Dispatch: отправьте задачу со своего телефона, и она может создать сеанс Desktop
  • Remote Control: управляйте работающим сеансом со своего телефона или браузера
  • Channels: отправляйте события из приложений чата или ваших собственных серверов в сеанс
  • Варианты планирования: запускайте промпты по повторяющемуся расписанию
