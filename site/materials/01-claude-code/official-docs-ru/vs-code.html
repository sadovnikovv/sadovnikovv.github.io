Использование Claude Code в VS Code #

Установите и настройте расширение Claude Code для VS Code. Получите помощь AI при кодировании с встроенными diff, @-упоминаниями, проверкой плана и сочетаниями клавиш.

Расширение VS Code предоставляет собственный графический интерфейс для Claude Code, интегрированный непосредственно в вашу IDE. Это рекомендуемый способ использования Claude Code в VS Code.

С расширением вы можете:

  • Просматривать и редактировать планы Claude перед их принятием
  • Автоматически принимать правки по мере их внесения
  • Использовать @-упоминания файлов с определёнными диапазонами строк из вашего выделения
  • Получать доступ к истории диалога
  • Открывать несколько диалогов в отдельных вкладках или окнах

Предварительные требования #

Перед установкой убедитесь, что у вас есть:

  • VS Code версии 1.94.0 или выше
  • Учётная запись Anthropic: подойдёт любая платная подписка Claude (Pro, Max, Ultra, Team или Enterprise) или учётная запись Claude Console, API-ключ не требуется. Вы войдёте с помощью этой учётной записи при первом открытии расширения. Если вы получаете доступ к Claude через поставщика услуг третьей стороны, такого как Amazon Bedrock или Google Cloud's Agent Platform, см. Использование поставщиков третьей стороны для инструкций по настройке.

[!TIP]

Расширение включает собственную копию CLI (интерфейс командной строки) для панели чата. Чтобы запустить claude во встроенном терминале VS Code, вам также нужна автономная установка CLI. Подробности см. в разделе Расширение VS Code и Claude Code CLI.

Установка расширения #

Нажмите на ссылку для вашей IDE, чтобы установить расширение напрямую:

  • Установить для VS Code
  • Установить для Cursor

Или в VS Code нажмите Cmd+Shift+X (Mac) или Ctrl+Shift+X (Windows/Linux), чтобы открыть представление Extensions, найдите «Claude Code» и нажмите Install.

[!NOTE]

Маркетплейсы расширений — это стороннее программное обеспечение, которое Anthropic не одобряет, не поддерживает и не проверяет. Anthropic отправляет расширения для публикации в Visual Studio Marketplace и Open VSX Registry.

Номер версии расширения соответствует версии Claude Code, которая в него входит. Например, для функции, требующей Claude Code v2.1.286 или новее, нужна версия расширения 2.1.286 или новее; её можно увидеть в представлении Extensions.

Claude Code также работает в других редакторах и контейнерах:

  • Другие форки VS Code: расширение также устанавливается в форках, таких как Devin Desktop или Kiro. Найдите «Claude Code» в представлении Extensions редактора или установите его из Open VSX Registry.
  • Редакторы, в которые нельзя установить расширение: установите CLI и запускайте claude во встроенном терминале редактора. CLI работает в любом терминале.
  • Dev-контейнеры: чтобы запустить Claude Code внутри dev-контейнера, см. раздел Контейнеры для разработки.

[!NOTE]

Если расширение не появилось после установки, перезапустите VS Code или выполните «Developer: Reload Window» из палитры команд.

Начало работы #

После установки вы можете начать использовать Claude Code через интерфейс VS Code:

1. Откройте панель Claude Code

Во всём VS Code значок Spark обозначает Claude Code:

Самый быстрый способ открыть Claude — нажать на значок Spark на панели инструментов редактора (правый верхний угол редактора). Значок отображается только тогда, когда у вас открыт файл.

Другие способы открыть Claude Code:

  • Панель действий (Activity Bar): нажмите на значок Spark на левой боковой панели, чтобы открыть список сессий. Нажмите на любую сессию, чтобы открыть её в предпочитаемом расположении, или начните новую. Этот значок всегда виден на панели действий.
  • Палитра команд: Cmd+Shift+P (Mac) или Ctrl+Shift+P (Windows/Linux), введите «Claude Code» и выберите вариант, например «Open in New Tab»
  • Строка состояния: нажмите ✻ Claude Code в правом нижнем углу окна. Это работает, даже когда ни один файл не открыт.

Вы можете перетащить панель Claude в любое место VS Code. Подробнее см. в разделе Настройка рабочего процесса.

2. Войдите в систему

При первом открытии панели появляется экран входа. Нажмите Sign in и завершите авторизацию в браузере.

Если позже вы увидите Not logged in · Please run /login, расширение автоматически снова откроет экран входа. Если он не появился, перезагрузите окно из палитры команд с помощью Developer: Reload Window.

Если в вашей оболочке задана переменная ANTHROPIC_API_KEY, но запрос на вход всё равно появляется, возможно, VS Code не унаследовал окружение вашей оболочки. Запустите VS Code из терминала командой code ., чтобы он унаследовал ваши переменные окружения, или вместо этого войдите с помощью своей учётной записи Claude.

После входа появится контрольный список Learn Claude Code. Пройдите по каждому пункту, нажимая Show me, или закройте его с помощью X. Чтобы снова открыть его позже, снимите флажок Hide Onboarding в настройках VS Code в разделе Extensions > Claude Code.

3. Отправьте промпт

Попросите Claude помочь с вашим кодом или файлами — будь то объяснение того, как что-то работает, отладка проблемы или внесение изменений.

[!TIP]

Claude автоматически видит выделенный вами текст. Нажмите Option+K (Mac) / Alt+K (Windows/Linux), чтобы также вставить в промпт ссылку с @-упоминанием (например, @file.ts#5-10).

4. Просмотрите изменения

Проверьте режим разрешений, отображаемый в нижней части поля ввода промпта:

  • В режиме Auto или Edit automatically Claude редактирует большинство файлов в вашей рабочей области, не спрашивая.
  • В режиме Manual, когда Claude хочет отредактировать файл, он показывает сравнение исходного содержимого и предлагаемых изменений бок о бок, а затем запрашивает разрешение. Вы можете принять, отклонить изменения или сказать Claude, что сделать вместо этого. Если вы отредактируете предлагаемое содержимое непосредственно в представлении diff перед принятием, Claude получит информацию о том, что вы его изменили, чтобы он не предполагал, что файл соответствует его исходному предложению.

Чтобы просматривать предлагаемую правку по одному изменению за раз, используйте кнопки Accept this change и Reject this change под каждым изменением в diff. Отклонение изменения отменяет его в предлагаемом содержимом; принятие помечает его как просмотренное. Для просмотра по отдельным изменениям требуется Claude Code v2.1.275 или более поздней версии.

Принятие или отклонение всего файла по-прежнему завершает просмотр. Diff, содержащий более 100 изменений, открывается без кнопок для отдельных изменений, поэтому просматривайте его как целый файл.

Те же действия доступны в позиции курсора из контекстного меню редактора и из палитры команд как Claude Code: Accept Change at Cursor и Claude Code: Reject Change at Cursor.

Больше идей о том, что можно делать с Claude Code, см. в разделе Типичные рабочие процессы.

[!TIP]

Запустите «Claude Code: Open Walkthrough» из палитры команд, чтобы пройти пошаговый обзор основ.

Использование поля ввода промпта #

Поле ввода промпта поддерживает несколько функций:

  • Режимы разрешений: нажмите на индикатор режима внизу поля ввода промпта, чтобы переключить режим разрешений. В Claude Code v2.1.283 и более поздних версиях Auto является встроенным начальным режимом разрешений, а в более ранних версиях — только на тарифах Pro, Max, Ultra и Team. О том, что на это влияет, и обо всех режимах разрешений, которые предлагает индикатор, см. в разделе как расширение выбирает начальный режим разрешений.
  • Auto: классификатор проверяет большинство действий вместо того, чтобы спрашивать вас. О том, что он проверяет и блокирует, см. в разделе авторежим.
  • Manual: Claude запрашивает разрешение перед редактированием файлов и большинством shell-команд.
  • Plan: Claude описывает, что собирается сделать, и ждёт подтверждения, прежде чем вносить изменения. VS Code автоматически открывает план как полноценный документ Markdown, в котором можно добавлять встроенные комментарии, чтобы дать обратную связь до того, как Claude начнёт работу.

Также можно ввести /plan в поле ввода промпта. Требуется Claude Code v2.1.280 или более поздней версии.

  • /plan: переключает в режим планирования. Если вы уже в режиме планирования, вместо этого показывает текущий план.
  • /plan с задачей, например /plan fix the auth bug: переключает в режим планирования и начинает планировать эту задачу.
  • /plan open: если вы уже в режиме планирования, открывает файл плана в редакторе.
  • Edit automatically: Claude вносит правки, не спрашивая.
  • Модель: выберите Switch model… в меню команд, чтобы сменить модель посреди сессии. Также можно нажать на название модели внизу поля ввода промпта, чтобы открыть то же окно выбора. В Claude Code v2.1.284 и более поздних версиях окно выбора также открывается, если ввести в поле ввода промпта только /model.

Если текущая модель поддерживает уровни effort, в окне выбора также отображается строка Effort, а на кнопке с названием модели показывается выбранный уровень. Если вы выбираете уровень, отличный от max, Claude Code сохраняет его для текущей модели как уровень по умолчанию в modelSettings в ваших пользовательских настройках; max применяется только к текущей сессии. Кнопка с названием модели и строка Effort требуют Claude Code v2.1.257 или более поздней версии.

Если включены динамические рабочие процессы и текущая модель их поддерживает, под строкой Effort появляется переключатель Ultracode. Включите его, чтобы Claude планировал рабочий процесс для каждой содержательной задачи в этой сессии с выбранным уровнем effort. Пока он включён, на кнопке с названием модели после уровня отображается · Ultracode. Переключатель требует Claude Code v2.1.284 или более поздней версии.

  • Меню команд: нажмите / или введите /, чтобы открыть меню команд. Среди вариантов — прикрепление файлов и переключение моделей.

Раздел Customize содержит такие пункты, как MCP-серверы, команды, стили вывода, хуки, память, инструкции, разрешения и плагины. Пункты со значком терминала открываются во встроенном терминале.

  • Чтобы просмотреть команды, такие как /usage или /remote-control, выберите Slash commands в разделе Customize. Откроется диалоговое окно со списком команд и полем фильтра. Выберите команду, чтобы выполнить её. Ввод / в поле ввода промпта по-прежнему предлагает команды прямо в строке. Требуется Claude Code v2.1.257 или более поздней версии.

Ввод /skills также открывает это диалоговое окно. В каждой строке скилла отображается его видимость, например On или Name only. Нажмите на значение видимости, чтобы изменить его, за исключением строк с пометкой locked, например скиллов плагинов. Сокращение /skills и элементы управления видимостью требуют Claude Code v2.1.280 или более поздней версии.

  • Выберите Output styles в разделе Customize, чтобы выбрать стиль вывода, включая ваши пользовательские стили. Требуется Claude Code v2.1.257 или более поздней версии.

Чтобы вместо этого создать пользовательский стиль, выберите Build a custom style в меню Output styles. Claude Code создаст для вас файл стиля на уровне проекта или пользователя. Требуется Claude Code v2.1.261 или более поздней версии.

  • Выберите Hooks в разделе Customize, чтобы просмотреть хуки, загруженные в сессии, сгруппированные по событиям. Можно добавлять, редактировать или удалять хуки, сохранённые в ваших файлах пользовательских, проектных и локальных настроек. Хуки из других источников, например из управляемых настроек или плагинов, доступны только для чтения. Требуется Claude Code v2.1.269 или более поздней версии.
  • Выберите Permissions в разделе Customize, чтобы просмотреть правила разрешений сессии, сгруппированные на Allow, Ask и Deny. Можно добавлять правила в пользовательские, проектные или локальные настройки и удалять сохранённые там правила. Правила из других источников, например из управляемых настроек или подтверждений, данных только для этой сессии, доступны только для чтения. Требуется Claude Code v2.1.269 или более поздней версии.
  • Выберите Memory в разделе Customize, чтобы включить или отключить автоматическую память. Пока она включена, можно также просматривать воспоминания, сохранённые Claude, и открывать папки, в которых они хранятся, в файловом менеджере. Требуется Claude Code v2.1.274 или более поздней версии.

Нажмите на сохранённое воспоминание, чтобы прочитать его в диалоговом окне, где можно отредактировать текст, удалить воспоминание или открыть его файл в редакторе. Просмотр, редактирование и удаление воспоминания в диалоговом окне требуют Claude Code v2.1.275 или более поздней версии.

  • Выберите Instructions в разделе Customize, чтобы редактировать файлы CLAUDE.md, которые читает Claude. Выберите файл, чтобы открыть его в редакторе. Если файл ещё не существует, Claude Code сначала создаст его. Требуется Claude Code v2.1.274 или более поздней версии.
  • Выберите Status в разделе Customize или введите /status, чтобы проверить версию Claude Code, учётную запись, модель и сведения о MCP-серверах для сессии. Требуется Claude Code v2.1.280 или более поздней версии.
  • Выберите Sandbox в разделе Customize или введите /sandbox, чтобы узнать, выполняются ли команды Bash от Claude в песочнице. Там же можно переключить режим песочницы и добавить исключённые команды. Требуется Claude Code v2.1.280 или более поздней версии.
  • Выберите Claude in Chrome в разделе Customize или введите /chrome, чтобы проверить подключение Claude in Chrome и управлять им. Оба способа требуют входа с учётной записью claude.ai. Требуется Claude Code v2.1.280 или более поздней версии.
  • Выберите Export conversation в разделе Context или введите /export, чтобы скопировать диалог как обычный текст или сохранить его в файл. Добавьте имя файла, например /export notes.txt, чтобы пропустить диалоговое окно и выбрать, куда сохранить файл. Требуется Claude Code v2.1.280 или более поздней версии.
  • Раздел Settings содержит пункт Enable Remote Control for all sessions, который задаёт remoteControlAtStartup и определяет, будут ли новые интерактивные сессии автоматически подключаться к Remote Control. Требуется Claude Code v2.1.203 или более поздней версии.

Когда вы включаете или отключаете переключатель в окне VS Code, изменение касается не только сессий, которые вы запустите после этого. Оно также применяется к сессиям, уже открытым в этом окне VS Code. Если вы его отключите, открытые сессии отключатся. В Claude Code v2.1.261 и более поздних версиях изменение также распространяется на сессии, открытые в других ваших окнах VS Code.

  • Раздел Settings также содержит пункт Focus view, который скрывает вызовы инструментов, результаты инструментов и размышления за разворачиваемыми строками, оставляя ваши промпты и ответы Claude. Переключайте его там же, сочетанием Ctrl+Option+F (Mac) / Ctrl+Alt+F (Windows/Linux) или из палитры команд с помощью Claude Code: Toggle Focus view. Изменение применяется ко всем открытым сессиям и сохраняется между сессиями. Требуется Claude Code v2.1.221 или более поздней версии.

Последний список задач Claude остаётся видимым, как и текст, о котором спрашивает ожидающий ответа вопрос от Claude; для этого требуется Claude Code v2.1.225 или более поздней версии. Пока Claude запускает субагентов, под группой вызовов инструментов, которая их запустила, появляются строки с ходом выполнения в реальном времени и их последней активностью. Для этого требуется Claude Code v2.1.269 или более поздней версии.

  • Чтобы выйти из учётной записи Anthropic, выберите Sign out в разделе Settings или введите /logout. При использовании стороннего провайдера меню не предлагает ни того, ни другого. Требуется Claude Code v2.1.277 или более поздней версии.
  • Чтобы сообщить об ошибке, нажмите Report a problem внизу меню или введите /bug или /feedback с необязательным описанием, которым будет предварительно заполнен отчёт. Когда вы отправляете отчёт и при этом вошли в Anthropic через собственное подключение Anthropic, Claude Code отправляет его в Anthropic. Требуется Claude Code v2.1.229 или более поздней версии.

При использовании стороннего провайдера или без учётных данных Anthropic ничего не отправляется. Диалоговое окно сообщает об этом до того, как вы начнёте писать. При отправке отчёт сохраняется как локальный архив в ~/.claude/feedback-bundles/, в котором известные шаблоны API-ключей и токенов скрыты. Сохранение отчёта на вашем компьютере требует Claude Code v2.1.284 или более поздней версии.

После сохранения отчёта в подтверждении указывается имя файла и есть кнопка Show folder. Отправьте этот файл представителю вашей учётной записи в Anthropic или прикрепите его к обращению в службу поддержки.

Если политика вашей организации отключает отзывы о продукте, пункт Report a problem не отображается в меню, а /bug и /feedback вместо открытия отчёта показывают уведомление Feedback is turned off by your organization's policy or this environment's settings.. В Claude Code v2.1.284 и более поздних версиях, если вы задали переменную окружения DISABLE_FEEDBACK_COMMAND или CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC, отзывы также отключаются, и при открытии отчёта вместо него показывается это уведомление.

  • Побочные вопросы: введите /btw, а затем вопрос, чтобы спросить о вашей сессии, не добавляя его в диалог. Ответ открывается на панели рядом с чатом, где можно задавать уточняющие вопросы. Требуется Claude Code v2.1.227 или более поздней версии.

Ветка сохраняется при перезагрузке окна. Claude Code хранит 20 последних обменов сообщениями и удаляет сохранённые ветки по расписанию cleanupPeriodDays, если Claude Code может безопасно определить срок хранения. Чтобы очистить ветку, нажмите на значок корзины на панели.

  • Копирование ответа: наведите курсор на ответ и нажмите Copy response, чтобы скопировать его в буфер обмена, или введите /copy, чтобы скопировать последний ответ. /copy 2 копирует предпоследний. Требуется Claude Code v2.1.277 или более поздней версии.
  • Закладки: наведите курсор на ответ и нажмите Bookmark response, чтобы сохранить его, или нажмите Remove bookmark на сохранённом ответе, чтобы удалить закладку.

Чтобы просмотреть сохранённые ответы, откройте панель Bookmarks. Можно нажать на значок закладки вверху панели Claude Code, выбрать Bookmarks в разделе Context меню команд или ввести /bookmarks. Требуется Claude Code v2.1.286 или более поздней версии.

  • Файлы, которые отправляет вам Claude: когда сессия подключена к Remote Control и Claude отправляет вам файлы с помощью инструмента SendUserFile, в диалоге отображается строка вида Sent report.md, chart.png. Нажмите на имя файла, чтобы открыть его в редакторе. Строка остаётся видимой в Focus view. Требуется Claude Code v2.1.295 или более поздней версии.

Файл отображается как полный путь, на который нельзя нажать, например \\server\share\report.md, если его путь указывает на сетевой узел. Claude Code не делает такой файл ссылкой, потому что его открытие привело бы к обращению к этому узлу и в Windows могло бы отправить ваши учётные данные Windows на этот узел.

  • Индикатор контекста: поле ввода промпта показывает, какую часть контекстного окна Claude вы используете. Claude автоматически выполняет сжатие контекста при необходимости, или вы можете запустить /compact вручную.
  • Часы кэша промптов: значок часов рядом с индикатором контекста оценивает, сколько времени осталось до истечения срока действия кэша промптов диалога. Он отсчитывает время от пятиминутного или часового срока жизни кэша, и каждый ответ, использующий кэш, перезапускает отсчёт. Помимо сжатия контекста, действия, которые делают кэш недействительным, не сбрасывают часы, поэтому после смены модели они всё ещё могут показывать оставшиеся минуты.
  • Пока отсчёт не закончился, значок показывает оставшиеся минуты, например 12m.
  • Когда отсчёт заканчивается, минуты исчезают, а значок становится красным или цвета ошибки вашей темы до следующего ответа. Срок действия кэша, скорее всего, истёк, поэтому ожидайте более медленный и более дорогой ответ на следующее сообщение, пока кэш перестраивается. Если пятиминутный срок жизни постоянно истекает между вашими сообщениями, см. раздел Выбор TTL самостоятельно.
  • Сразу после сжатия диалога значок также становится красным без минут до следующего ответа, потому что кэш ещё не охватывает сжатый диалог.
  • Карта агентов: когда диалог включает субагентов, внизу поля ввода промпта появляется счётчик агентов, например 2 agents. Его точка показывает, работает ли какой-либо субагент или ожидает вашего разрешения.

Нажмите на счётчик агентов, чтобы открыть карту агентов, на которой субагенты диалога изображены в виде дерева под основным агентом, у каждого — статус, затраченное время и количество токенов. Нажмите на субагента, чтобы увидеть его промпт и вызовы инструментов, открыть его транскрипт только для чтения или остановить его во время работы. Требуется Claude Code v2.1.269 или более поздней версии.

На карте также перечислены другие фоновые задачи сессии, такие как фоновые shell-команды и мониторы, под агентами. Нажмите на строку, чтобы открыть карточку задачи и остановить её там.

Чтобы открыть карту, когда счётчик агентов не отображается, например когда Claude запустил фоновую оболочку, но не запустил субагентов, введите /tasks в поле ввода промпта. Фоновые задачи на карте и ввод /tasks требуют Claude Code v2.1.277 или более поздней версии.

В Claude Code v2.1.286 и более поздних версиях, когда вы нажимаете Stop или клавишу Esc, текущий ход завершается. Фоновые агенты продолжают работать, пока не закончат или пока вы не остановите их с карты.

  • Расширенное мышление: позволяет Claude тратить больше времени на рассуждения над сложными задачами. Чтобы отключить его или снова включить, используйте переключатель Thinking в разделе Model меню команд (/). В моделях, где мышление нельзя отключить, в меню нет переключателя Thinking, и мышление остаётся включённым.

Блок размышлений, в котором отображается только метка, например Thought for 12s, не содержит текста и не раскрывается при нажатии. Чтобы видеть сводки размышлений, задайте для showThinkingSummaries значение true в ~/.claude/settings.json, затем выполните Developer: Reload Window из палитры команд.

Уже имеющиеся блоки размышлений остаются пустыми. В ответах после перезагрузки нажмите на блок или нажмите Ctrl+O, чтобы развернуть их все.

  • Многострочный ввод: нажмите Shift+Enter, чтобы добавить новую строку без отправки. Это также работает в поле свободного ввода «Other» в диалоговых окнах с вопросами.

Использование или отключение предлагаемых промптов #

После ответа Claude панель может показывать предлагаемый следующий промпт серым курсивным текстом в пустом поле ввода промпта. Каждое предложение использует короткий фоновый запрос, который учитывается в лимитах использования вашего тарифа или в расходах на API.

  • Использовать предложение: нажмите Tab, чтобы превратить его в редактируемый текст, затем отправьте его. Нажатие Enter до того, как вы примете предложение, не отправляет его.
  • Написать собственный промпт: начните вводить текст, и предложение скроется.

Чтобы отключить предложения, задайте для promptSuggestionEnabled значение false в ~/.claude/settings.json. Вы перестанете видеть их в новых диалогах, а в открытых — после того, как выполните Developer: Reload Window из палитры команд. Если вы задали для CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION значение true, измените его на false там, где вы его задали, иначе предложения продолжат появляться.

Ссылайтесь на вывод терминала в промптах с помощью `@terminal:name`, где `name` — заголовок терминала. Это позволяет Claude видеть вывод команд, сообщения об ошибках или логи без копирования и вставки.

* Чтобы прикрепить изображение, вставьте его из буфера обмена в поле ввода промпта.

### Вставка текста

Вставленный текст остаётся видимым в поле ввода промпта, а не сворачивается в заполнитель, как это происходит [в терминале](https://code.claude.com/docs/ru/terminal-config.md#paste-large-content). В сессиях, где Claude Code [помечает вставленный текст](https://code.claude.com/docs/ru/terminal-config.md#how-claude-treats-pasted-text), Claude по-прежнему видит большой фрагмент как вставленный вами текст, а не набранный.

Claude Code также удаляет [невидимые символы Unicode](https://code.claude.com/docs/ru/interactive-mode.md#invisible-characters-in-prompts) из текста, который вы вставляете в поле ввода промпта, и из всего остального, что вы отправляете:

* Если при вставке появляется уведомление, например `Removed 3 invisible characters from the pasted text`, текст был вставлен без этих символов.
* Если уведомление об удалённых символах появляется при отправке, ничего не было отправлено. Очищенный текст возвращается в поле ввода промпта. Отправьте снова, чтобы отправить текст в том виде, в котором он отображается.

### Автоматический контекст из выделения и открытого файла

Когда вы выделяете текст в редакторе, Claude автоматически видит выделенный код. В нижней части поля ввода промпта показывается, сколько строк выделено. Claude также видит, какой файл открыт в редакторе, даже если ничего не выделено, и поле ввода промпта показывает его имя.

Нажмите `Option+K` (Mac) / `Alt+K` (Windows/Linux), чтобы вставить @-упоминание с путём к файлу и номерами строк, например `@app.ts#5-10`.

#### Как не передавать выделение и открытый файл в сообщениях

Чтобы выделенный текст или открытый файл не попадали в ваши сообщения, отключите соответствующую настройку в настройках VS Code:

* **Выделенный текст**: отключите [настройку Attach Selection](vscode://settings/claudeCode.attachSelection). Требуется Claude Code v2.1.300 или более поздней версии. Чтобы убрать одно выделение, нажмите **X** рядом со счётчиком строк. Счётчик вернётся, когда вы выделите другой текст.
* **Открытый файл**: отключите [настройку Attach Open File](vscode://settings/claudeCode.attachOpenFile). Требуется Claude Code v2.1.271 или более поздней версии. Файл не передаётся, если только ваше сообщение не включает выделенный в нём текст.

Чтобы добавить текст как @-упоминание при отключённой настройке Attach Selection, выделите его и нажмите `Option+K` на Mac или `Alt+K` в Windows и Linux.

Обе настройки также применяются, когда вы запускаете `claude` во встроенном терминале VS Code.

#### Выделенный текст из исключённых или игнорируемых файлов

На панели чата расширение не передаёт выделенный текст из некоторых файлов:

* Если файл находится внутри вашей рабочей области и соответствует настройкам `files.exclude` или `search.exclude`, Claude получает не более чем путь к файлу, но не выделенный вами текст.
* То же самое относится к файлу, который игнорируется git, при условии что настройка VS Code `search.useIgnoreFiles` и [настройка `respectGitIgnore`](#extension-settings) расширения обе включены, что является значением по умолчанию.

Этот фильтр распространяется только на панель чата. Когда Claude Code работает во встроенном терминале, Claude может получать текст, который вы выделяете в этих файлах. Чтобы скрыть содержимое файла от Claude в этом случае, добавьте [правило запрета `Read`](https://code.claude.com/docs/ru/permissions#read-and-edit).

### Математика LaTeX в ответах

Панель чата отображает математические выражения LaTeX в ответах Claude в виде свёрстанных формул. Отрисовка математики требует Claude Code v2.1.301 или более поздней версии. В [режиме терминала](#switch-to-terminal-mode) математика не верстается. Панель верстает как выносные, так и строчные формулы:

* **Выносные формулы**: блок `$$ … $$` или `\[ … \]` на отдельной строке или строках, а также огороженный блок кода с языком `math`
* **Строчные формулы**: `$…$` или `\(…\)`, которые открываются и закрываются на одной строке, например `$E = mc^2$` или `\(a^2 + b^2 = c^2\)`

Панель пытается отличать математику от других вариантов использования тех же символов, поэтому такой текст, как `$HOME`, цена вроде `$5` или `sed 's/\(foo\)/\1/'`, не верстается. Не верстается и текст внутри фрагмента кода или внутри любого блока кода, кроме огороженного блока `math`. Если формула отображается в исходном виде, хотя вы ожидали её свёрстанной, см. раздел [Формула отображается как необработанный LaTeX](#a-formula-shows-as-raw-latex).

Когда вы выделяете и копируете текст, содержащий свёрстанную формулу, вы получаете исходный код TeX формулы в разделителях `$…$` или `$$…$$`, а не отрисованные символы. [**Copy response**](#use-the-prompt-box) и `/copy` дают ответ в том виде, в котором его написал Claude, включая исходный код TeX.

### Возобновление прошлых диалогов

Нажмите кнопку **Session history** вверху панели Claude Code, чтобы получить доступ к истории диалогов. Можно искать по ключевому слову или просматривать по времени.

Нажмите на любой диалог, чтобы возобновить его. Если диалог уже открыт в другой вкладке текущего окна, нажатие переключит на эту вкладку. Если уведомление сообщает, что диалог всё ещё открыт в другом месте, см. раздел [как продолжить его в этом окне](#the-conversation-is-still-open-somewhere-else). Если диалог открывается без отображаемых сообщений, см. раздел [почему возобновлённый диалог поначалу пуст](#a-resumed-conversation-is-blank-at-first). Подробнее о возобновлении сессий см. в разделе [Управление сессиями](https://code.claude.com/docs/ru/sessions.md).

* **Заголовки сессий**: новые сессии получают сгенерированные ИИ заголовки на основе вашего первого сообщения.
* **Переименование и архивация**: наведите курсор на сессию, чтобы увидеть эти действия. Переименуйте её, чтобы дать описательный заголовок, или заархивируйте, чтобы переместить в группу **Archived sessions** внизу списка.
* **Диалоги отсутствуют, когда задана настройка [`claudeProcessWrapper`](#extension-settings)**: обновите расширение до версии 2.1.304 или более поздней. После этого в списке появятся отсутствовавшие диалоги, а также сессии, которые `claude -p` или [Agent SDK](https://code.claude.com/docs/ru/agent-sdk/overview.md) запустили в этой рабочей области.

По умолчанию сессия без активности в течение 14 дней автоматически перемещается в **Archived sessions**, если она не открыта, не является непрочитанной и не находится в [группе](#organize-sessions-into-groups). Автоматическая архивация требует Claude Code v2.1.265 или более поздней версии. Чтобы изменить период или отключить её, откройте [настройку Archive Inactive Sessions](vscode://settings/claudeCode.archiveInactiveSessions) и выберите количество дней или **Never**.

Чтобы восстановить заархивированные сессии:

* **Одна сессия**: разверните **Archived sessions** и нажмите **Unarchive session**.
* **Все заархивированные сессии сразу**: наведите курсор на заголовок **Archived sessions** в списке сессий на панели действий и нажмите на его значок разархивации. Требуется Claude Code v2.1.277 или более поздней версии.

До v2.1.257 это действие называлось **Delete session** и скрывало сессию без возможности восстановления. Сессии, которые вы тогда удалили, после обновления появятся в разделе **Archived sessions**.

Если возобновляемый диалог завершился в режиме планирования, Claude Code восстанавливает режим планирования. Требуется Claude Code v2.1.246 или более поздней версии. Claude Code не восстанавливает его в следующих случаях:

* Расширение [выбирает начальный режим разрешений](https://code.claude.com/docs/ru/permission-modes.md#switch-permission-modes) из `claudeCode.initialPermissionMode` или из выбора, перенесённого из более раннего диалога
* У вас настроен `claudeCode.claudeProcessWrapper`
* [Правило запрета](https://code.claude.com/docs/ru/permissions.md#manage-permissions) удаляет инструмент [`ExitPlanMode`](https://code.claude.com/docs/ru/tools-reference)
* Включена настройка [`permissions.denyInsteadOfPrompting`](https://code.claude.com/docs/ru/settings-reference#permissions-denyinsteadofprompting)

#### Диалог всё ещё открыт в другом месте

Чтобы продолжить в этом окне, когда уведомление сообщает, что диалог всё ещё открыт в другом месте, нажмите **Open here anyway** после выполнения шага для вашего случая:

* **У вас больше ничего не открыто**: процесс Claude, запущенный до перезапуска расширения, возможно, всё ещё держит диалог открытым. Обычно такой процесс завершается сам примерно в течение 10 минут, поэтому подождите это время, а затем нажмите. Если нажать до его завершения, диалог будет открыт в двух местах, пока процесс не завершится.
* **Диалог открыт у вас в другом месте**: сначала закройте его там, например выйдите из `claude` в терминале или закройте его вкладку в другом окне VS Code

Когда диалог всё ещё открыт в другом процессе Claude Code, вместо поля ввода промпта появляется следующее уведомление:

This conversation is still open somewhere else. Using it in two places at once can mix up its messages. If the extension restarted recently, a Claude process from before the restart may still be finishing. It usually ends on its own within about 10 minutes. This notice stays until you choose Open here anyway.


Если задана настройка [`claudeProcessWrapper`](#extension-settings), расширение пропускает эту проверку и открывает диалог напрямую.

### Возобновление облачных сессий из claude.ai

Если вы запускаете [облачные сессии](https://code.claude.com/docs/ru/claude-code-on-the-web.md), их можно возобновлять прямо в VS Code. Для этого требуется вход с помощью **Claude.ai Subscription**, а не Anthropic Console.

**1. Откройте историю сессий**

Нажмите кнопку **Session history** вверху панели Claude Code.

**2. Выберите вкладку Web**

В диалоговом окне отображаются две вкладки: Local и Web. Нажмите **Web**, чтобы увидеть сессии из claude.ai.

**3. Выберите сессию для возобновления**

Просмотрите сессии или найдите нужную. Нажмите на сессию, чтобы продолжить диалог локально.

> [!NOTE]
>
> Если открытая папка является репозиторием GitHub, на вкладке Web отображаются только сессии из этого репозитория.
>
> При возобновлении облачной сессии расширение загружает копию истории диалога; изменения не синхронизируются обратно с claude.ai.

На вкладке Web также перечислены ваши сессии [Remote Control](https://code.claude.com/docs/ru/remote-control.md). Если нажать на сессию, которая выполнялась в открытой у вас папке, расширение откроет этот локальный диалог вместо загрузки копии. Расширение переходит на вкладку, в которой он уже отображается, если такая есть. Если расширение не может исключить, что диалог открыт другим процессом Claude, вместо этого вы получите загруженную копию.

Если какую-либо часть диалога не удаётся загрузить, появляется ошибка и копия не сохраняется. Выберите сессию снова, чтобы повторить попытку. Если вы выбираете сессию, в которой ещё нет диалога для загрузки, ошибка сообщит, где его можно продолжить.

### Проверка учётной записи и использования

Выполните `/usage`, чтобы открыть диалоговое окно Account & usage, в котором отображаются учётная запись, с которой вы вошли, и ваше использование. Показатели использования зависят от способа входа:

* **Тариф claude.ai**: полосы использования для лимитов вашего тарифа, например для текущей сессии и недели.

  Диалоговое окно также показывает разбивку того, что влияет на лимиты тарифа:

  * **Рекомендации**: предлагаемые изменения, по одному в строке, например `Trim ~/code/api/CLAUDE.md · 49k tokens per request`
  * **Кнопка исправления**: чтобы Claude Code применил те рекомендации, которые может, нажмите кнопку под ними, например **Fix both**. О том, на какие строки действует кнопка и что затем происходит в вашей сессии, см. в разделе [Применение рекомендаций с помощью кнопки исправления](https://code.claude.com/docs/ru/costs.md#apply-recommendations-with-the-fix-shortcut). Требуется Claude Code v2.1.305 или более поздней версии.

    Кнопка не отображается, пока подключён [Remote Control](https://code.claude.com/docs/ru/remote-control.md). Если после подключения Remote Control появляется предупреждение `The usage fix wasn’t fully sent. Open usage and try again.`, [отключите Remote Control](https://code.claude.com/docs/ru/remote-control.md#check-connection-status), прежде чем повторить попытку.
  * **Атрибуция**: таблицы, показывающие, сколько использования пришлось на каждый скилл, субагент, плагин и MCP-сервер

  Используйте переключатель Day и Week, чтобы переключаться между последними 24 часами и последними 7 днями. Показатели приблизительны и вычисляются по локальным сессиям на этой машине, поэтому использование с других устройств или claude.ai не учитывается.
* **Другие способы входа**: когда лимиты тарифа не применяются к вашему способу входа, например при использовании [стороннего провайдера](#use-third-party-providers) или API-ключа, раздел Usage вместо этого показывает стоимость и использование токенов самой сессии. `/usage` в CLI показывает те же итоги в своём [блоке Session](https://code.claude.com/docs/ru/costs.md#track-your-costs). Список сессий на панели действий также показывает итоги активной сессии под заголовком **Account & usage**. Требуется Claude Code v2.1.277 или более поздней версии.

Подробнее об отслеживании и сокращении использования см. в разделе [Отслеживание расходов](https://code.claude.com/docs/ru/costs.md#track-your-costs).

### Откат с помощью чекпоинтов

Расширение VS Code поддерживает чекпоинты, которые отслеживают правки файлов, сделанные Claude, и позволяют вернуться к предыдущему состоянию. Наведите курсор на любое сообщение, чтобы увидеть кнопку отката, затем выберите один из трёх вариантов:

* **Fork conversation from here**: начать новую ветку диалога с этого сообщения, сохранив все изменения кода
* **Rewind code to here**: откатить изменения файлов к этому моменту диалога, сохранив полную историю диалога
* **Fork conversation and rewind code**: начать новую ветку диалога и откатить изменения файлов к этому моменту

Подробнее о том, как работают чекпоинты, и об их ограничениях см. в разделе [Чекпоинты](https://code.claude.com/docs/ru/checkpointing.md).

## Настройка рабочего процесса

Вы можете переместить панель Claude и изменить её шрифт. Также можно вести несколько диалогов, группировать или фильтровать список сессий, а также переключиться в режим терминала.

### Выбор расположения Claude

Вы можете перетащить панель Claude в любое место в VS Code. Захватите вкладку или заголовок панели и перетащите её в одно из следующих мест:

* **Вторичная боковая панель**: правая часть окна. Claude остаётся на виду, пока вы пишете код.
* **Основная боковая панель**: левая боковая панель со значками Explorer, Search и т. д.
* **Область редактора**: Claude открывается как вкладка рядом с вашими файлами. Удобно для побочных задач.

Когда Claude открывает вкладку в новой группе редакторов, расширение блокирует эту группу. Файлы, которые вы открываете, пока вкладка Claude в фокусе, в этом случае попадают в другую группу, а не рядом с ней.

Чтобы расширение не блокировало группы, отключите [настройку Lock Editor Groups](vscode://settings/claudeCode.lockEditorGroups). Уже заблокированные группы остаются заблокированными, пока вы их не разблокируете. Для этой настройки требуется Claude Code v2.1.274 или новее.

> [!TIP]
>
> Используйте боковую панель для основной сессии Claude и открывайте дополнительные вкладки для побочных задач. Claude запоминает выбранное вами расположение. Значок списка сессий на панели действий (Activity Bar) не связан с панелью Claude. Список сессий всегда доступен на панели действий, а значок панели Claude появляется там, только когда панель закреплена на левой боковой панели.

### Изменение шрифта

Панель Claude использует настройки шрифта чата VS Code — те же, что задают оформление встроенного представления чата VS Code. Откройте настройки VS Code с помощью `Cmd+,` на Mac или `Ctrl+,` на Windows и Linux, затем выполните поиск по `chat font`.

| Настройка | На что влияет |
| - | - |
| [`chat.fontSize`](vscode://settings/chat.fontSize) | Размер текста диалога и поля ввода промпта в пикселях. Блоки кода и вывод инструментов масштабируются вместе с ним. Требуется VS Code 1.104 или новее |
| [`chat.fontFamily`](vscode://settings/chat.fontFamily) | Шрифт текста диалога и поля ввода промпта. Требуется VS Code 1.104 или новее |
| [`chat.editor.fontSize`](vscode://settings/chat.editor.fontSize) | Размер diff в пикселях. Требуется Claude Code v2.1.300 или новее |
| [`chat.editor.fontFamily`](vscode://settings/chat.editor.fontFamily) | Шрифт блоков кода и вывода инструментов |

Чтобы масштабировать весь VS Code вместе с панелью Claude, увеличьте масштаб окна с помощью `Cmd+=` на Mac или `Ctrl+=` на Windows и Linux.

### Продолжение диалогов после перезагрузки

После выполнения **Developer: Reload Window** или перезапуска VS Code проверьте, где был открыт диалог:

* **Вкладка редактора**: диалог возвращается вместе со своей вкладкой.
* **Боковая панель**: диалог возвращается, если в последние 10 минут вы отправили в нём сообщение или Claude ответил в нём. Если диалог не вернулся, возобновите его из [истории сессий](#resume-past-conversations).

Если вместо поля ввода промпта отображается уведомление о том, что диалог всё ещё открыт в другом месте, см. раздел [о том, как продолжить диалог здесь](#the-conversation-is-still-open-somewhere-else). Если сообщения поначалу пустые, см. раздел [о том, почему они пустые и когда появятся](#a-resumed-conversation-is-blank-at-first).

#### Прерванные шаги после перезагрузки

Если перезагрузка прервала Claude посреди шага, Claude продолжит этот шаг, когда диалог вернётся, а уведомление в чате отметит продолжение. Требуется Claude Code v2.1.274 или новее. Если шаг был прерван более часа назад или сессия открыта в другом месте, диалог вернётся в неактивном состоянии.

Если уведомление в чате содержит `plan mode is now off, so Claude did not continue on its own`, шаг был прерван в режиме планирования. Чтобы продолжить планирование, выберите **Plan** в индикаторе режима, прежде чем отправить следующее сообщение.

#### Отключение продолжения после перезагрузки

Чтобы Claude не продолжал прерванный шаг после перезагрузки, откройте [настройку Continue After Reload](vscode://settings/claudeCode.continueAfterReload) и снимите флажок.

Если вы задали [`CLAUDE_CODE_RESUME_INTERRUPTED_TURN`](https://code.claude.com/docs/ru/env-vars#variables) или любую другую переменную `CLAUDE_CODE_RESUME_` в окружении VS Code или в [настройке `environmentVariables`](#extension-settings), это не повлияет на панель. Дело в том, что расширение удаляет эти переменные перед запуском сессий панели.

#### Диалог не был открыт повторно

Если после перезагрузки открылся новый чат с подобным уведомлением над полем ввода промпта, значит, панель оставила ваш диалог закрытым, потому что два последних его открытия не завершились:

“Fix the login bug” was not reopened. It did not finish opening the last 2 times, and opening it again may stop Claude Code from responding here.


Открытие не завершается, если панель аварийно завершает работу или перестаёт отвечать во время загрузки диалога, либо если вы перезагружаете или закрываете окно примерно в течение трёх секунд после его открытия. Диалог не изменяется и остаётся в [истории сессий](#resume-past-conversations).

* **Чтобы всё равно открыть его**: нажмите **Open it anyway** или выберите диалог в истории сессий. Как только диалог завершит открытие, он [будет возвращаться при последующих перезагрузках как обычно](#continue-conversations-after-a-reload).
* **Если панель перестаёт отвечать во время загрузки диалога**: перезагрузите окно. Откроется новый чат.
* **Чтобы оставить его закрытым**: продолжайте работать в новом чате. Уведомление исчезнет, как только вы отправите промпт.

### Несколько диалогов одновременно

Используйте **Open in New Tab** или **Open in New Window** из палитры команд, чтобы начать дополнительные диалоги. Каждый диалог хранит собственную историю и контекст, что позволяет работать над разными задачами параллельно.

При использовании вкладок небольшая цветная точка на значке искры показывает статус: синяя означает ожидающий запрос разрешения, оранжевая — что Claude завершил работу, пока вкладка была скрыта.

### Группировка сессий

В списке сессий на панели действий можно объединять связанные сессии в именованные сворачиваемые группы. Требуется Claude Code v2.1.229 или новее.

* **Добавление сессии в группу и удаление из неё**: щёлкните сессию правой кнопкой мыши, чтобы создать на её основе группу, переместить её в существующую группу или удалить из группы. Каждая сессия одновременно принадлежит только одной группе, поэтому при перемещении в другую группу она удаляется из первой.
* **Перемещение нескольких сессий сразу**: щёлкните каждую сессию с `Cmd` (Mac) / `Ctrl` (Windows/Linux) или щёлкните с `Shift`, чтобы выбрать диапазон, затем щёлкните выделение правой кнопкой мыши.
* **Добавление сессии в группу с её вкладки**: выполните **Claude Code: Add Session Tab to Group** из палитры команд, затем выберите или создайте группу. Требуется Claude Code v2.1.257 или новее.
* **Переименование или удаление группы**: щёлкните заголовок группы правой кнопкой мыши. При удалении группы удаляется только сама группа, а её сессии возвращаются в список без группы.

Расширение сохраняет группы для каждой папки рабочей области, поэтому они сохраняются после перезагрузки окна и отображаются в каждом окне, где открыта та же папка. При поиске по списку расширение показывает совпадения единым плоским списком по всем группам.

### Фильтрация списка сессий

Чтобы сократить длинный список сессий на панели действий, используйте два элемента фильтрации в верхней части списка. Требуется Claude Code v2.1.271 или новее. Архивированные сессии не отображаются, пока включён любой из фильтров.

* **Active**: включите этот переключатель, чтобы показывать только сессии, которые ожидают вашего ввода, выполняются или не прочитаны, а также сессию во вкладке Claude, на которой вы последний раз были в фокусе.
* **Фильтр по статусу**: щёлкните значок воронки, затем отметьте **Needs input**, **Working** или **Completed**, чтобы показать сессии в любом из этих состояний. Отметьте **Open** или **Closed**, чтобы отфильтровать сессии по тому, открыты ли они. Сессия считается открытой, если у неё есть вкладка в этом окне или она выполняется в другом процессе Claude Code на этом компьютере, например в терминале.

Когда **Active** включён и вы отмечаете статус, **Open** или **Closed**, в списке также отображаются все сессии, соответствующие отмеченным условиям. Заданные вами фильтры сохраняются после перезагрузки окна.

### Переключение в режим терминала

По умолчанию расширение открывает графическую панель чата. Если вы предпочитаете интерфейс в стиле CLI, откройте [настройку Use Terminal](vscode://settings/claudeCode.useTerminal) и установите флажок.

Также можно нажать `Cmd+,` на Mac или `Ctrl+,` на Windows/Linux, чтобы открыть настройки VS Code, перейти в **Extensions > Claude Code** и отметить **Use Terminal**.

## Управление плагинами

Расширение VS Code включает графический интерфейс для установки [плагинов](https://code.claude.com/docs/ru/plugins/overview.md) и управления ими. Введите `/plugins` в поле промпта, чтобы открыть интерфейс **Manage plugins**.

### Установка плагинов

В диалоговом окне плагинов есть две вкладки: **Plugins** и **Marketplaces**.

На вкладке Plugins:

* **Установленные плагины** отображаются вверху с переключателями для их включения или отключения.
  * Если вы отключаете плагин, который включён в общем файле `.claude/settings.json` вашего проекта, расширение сначала задаёт вопрос: **Disable for me** отключает его только для вас, а **Disable for everyone** изменяет общий файл.
  * Для плагина, который не удалось загрузить, в его строке отображается краткая причина. Нажмите на причину, чтобы узнать, что можно сделать, включая копирование полного сообщения об ошибке для поиска в разделе [Устранение неполадок с плагинами](https://code.claude.com/docs/ru/plugins/troubleshooting.md).
* **Доступные плагины** из настроенных вами маркетплейсов отображаются ниже
* Используйте поиск, чтобы отфильтровать плагины по имени или описанию
* Нажмите **Install** у любого доступного плагина

При установке плагина выберите область действия установки:

* **Install for you**: доступен во всех ваших проектах (область действия пользователя)
* **Install for this project**: доступен участникам проекта (область действия проекта)
* **Install locally**: только для вас и только в этом репозитории (локальная область действия)

После завершения установки появляется форма, запрашивающая те [параметры конфигурации](https://code.claude.com/docs/ru/plugins/components.md#user-configuration) плагина, которые ещё не заданы. Чтобы просмотреть или изменить параметры позже, нажмите значок шестерёнки в строке плагина.

Конфиденциальные текстовые поля маскируются, а для ранее сохранённого секрета отображается **(unchanged)**. Оставьте поле пустым, чтобы сохранить прежнее значение. После сохранения изменений открытые сессии перезагружают свои плагины, а в диалоговом окне отображается **Restart Claude to apply plugin changes**.

### Удаление плагинов

В каждой строке установленного плагина указана [область действия](https://code.claude.com/docs/ru/plugins/install.md#choose-an-install-scope), на уровне которой он установлен. Чтобы удалить эту установку, нажмите значок корзины в строке. Затемнённый значок корзины отмечает строку, которую нельзя удалить из этой рабочей области, например плагин, управляемый вашей организацией, или плагин, установленный для другого проекта.

Расширение сначала задаёт вопрос в двух случаях:

* **Плагин, который включён в общем файле `.claude/settings.json` вашего проекта**: выберите **Disable for me**, чтобы плагин остался установленным для ваших коллег, или **Uninstall for everyone**, чтобы удалить установку проекта с флагом [`--keep-data`](https://code.claude.com/docs/ru/plugins/cli-reference#what-an-uninstall-deletes-and-keeps), при этом каталог сохранённых данных плагина останется. Если вы уже отключили плагин для себя, значок корзины удаляет вашу собственную установку без вопроса.
* **В остальных случаях — последняя установка плагина с сохранёнными данными**: выберите, сохранить или удалить данные; по умолчанию выбрано **Keep**

### Отправка ссылки на установку плагина

Чтобы сразу направить кого-либо к установке определённого плагина, отправьте ему URL расширения `install-plugin`. При открытии ссылки запускается или выводится на передний план VS Code, открывается панель Claude Code и диалоговое окно **Manage plugins** на выборе области действия для этого плагина. Ничего не устанавливается, пока человек не выберет область действия. Если маркетплейс плагина ещё не настроен в его Claude Code, диалоговое окно сначала предложит его добавить.

vscode://anthropic.claude-code/install-plugin?plugin=code-review&marketplace=anthropics/claude-plugins-official


URL принимает два параметра запроса:

| Параметр | Описание |
| - | - |
| `plugin` | Имя плагина в том виде, в каком оно указано в маркетплейсе. Обязательный. |
| `marketplace` | [Источник](https://code.claude.com/docs/ru/plugins/install.md#add-a-marketplace) маркетплейса: `owner/repo` на GitHub, URL `https://` или SSH-адрес git, например `git@github.com:owner/repo.git`. Если не указан, по умолчанию используется `anthropics/claude-plugins-official`. |

Расширение проверяет оба значения, прежде чем что-либо открыть:

* **Имя плагина**: не более 100 символов, начинается с ASCII-буквы или цифры и в остальном содержит только ASCII-буквы, цифры, `.`, `_` и `-`.
* **Источник маркетплейса**: только формы, перечисленные для параметра `marketplace`, то есть не локальный путь, не адрес `http://` и не имя маркетплейса, например `claude-plugins-official`. URL `https://` не может содержать имя пользователя, пароль или строку запроса.
* **Git-ссылка (ref)**: чтобы закрепить маркетплейс за веткой или тегом, добавьте ref к источнику после `%23` — закодированной формы `#`, например `marketplace=owner/repo%23v1.0`. Ссылка с незакодированным `#` не сработает. Маркетплейсы в организации GitHub `anthropics` нельзя закрепить в ссылке.

Тот, кто откроет ссылку, нарушающую эти правила, увидит ошибку, начинающуюся с `Invalid plugin installation URL`. Панель Claude Code и диалоговое окно не открываются, и ничего не устанавливается. Если имя вашего плагина или маркетплейс нельзя поместить в ссылку, попросите пользователей добавить маркетплейс на вкладке **Marketplaces**, а затем установить плагин на вкладке **Plugins**.

В следующих случаях вместо выбора области действия в диалоговом окне отображается сообщение:

* **В маркетплейсе нет плагина с таким именем**: диалоговое окно сообщает, что плагин не найден. Сверьте значение `plugin` со списком маркетплейса.
* **Плагин уже установлен**: диалоговое окно сообщает об этом, и ничего не меняется.
* **Уже добавлен другой маркетплейс с тем же именем**: диалоговое окно сообщает, что маркетплейс из ссылки не был добавлен, и ничего не устанавливается.

README и issues на GitHub, а также некоторые другие платформы для markdown удаляют ссылки, схема которых не `http` или `https`, поэтому ссылка `vscode://` там отображается как обычный текст. На таких платформах помещайте URL в блок кода, как описано в разделе [Ссылка отображается как обычный текст, а не как кликабельная](https://code.claude.com/docs/ru/deep-links.md#the-link-renders-as-plain-text-instead-of-being-clickable) для ссылок `claude-cli://`.

### Управление маркетплейсами

Перейдите на вкладку **Marketplaces**, чтобы добавить или удалить источники плагинов:

* Введите репозиторий GitHub, URL или локальный путь, чтобы добавить новый маркетплейс
* Нажмите значок обновления, чтобы обновить список плагинов маркетплейса
* Нажмите значок корзины, чтобы удалить маркетплейс. Его удаление [удаляет все плагины, которые вы из него установили](https://code.claude.com/docs/ru/plugins/install.md#manage-marketplaces), поэтому сначала отображается подтверждение с перечнем этих плагинов

Изменения плагинов, внесённые в диалоговом окне, сразу применяются к сессиям Claude Code, открытым в этом окне VS Code.

Если сессия, из которой вы открыли диалоговое окно, не может перезагрузить свои плагины, диалоговое окно предлагает повторить попытку или перезапустить Claude в этой сессии.

> [!NOTE]
>
> Расширение управляет плагинами, выполняя те же команды, что и CLI. Плагины и маркетплейсы, настроенные в расширении, также доступны в CLI, и наоборот.

Подробнее о системе плагинов см. в разделах [Плагины](https://code.claude.com/docs/ru/plugins/overview.md) и [Маркетплейсы плагинов](https://code.claude.com/docs/ru/plugins/overview.md).

### Плагины, которые отображают содержимое в панели

Плагин, содержащий [мод](https://code.claude.com/docs/ru/plugins/mods/overview.md), может отображать содержимое в панели чата. Для этого требуется расширение версии 2.1.299 или новее. Для сессии, которая [не получает флаги функций](https://code.claude.com/docs/ru/env-vars.md#features-that-need-feature-flag-fetching), например сессии в Amazon Bedrock, требуется версия 2.1.304 или новее. От такого плагина вы можете увидеть:

* Панель рядом с диалогом или над полем промпта
* Всплывающее уведомление или строку состояния над полем промпта
* Сообщение или вызов инструмента, отображённые собственным способом плагина

Когда установленный вами плагин добавляет или изменяет что-либо в панели, это обозначается меткой с формулировками, например такими:

* **From the token-chart plugin**: плагин отобразил или вывел это, либо эта карточка — вопрос плагина к вам
* **Edited by the token-chart plugin**: плагин изменил что-то, что отображает Claude Code, например вызов инструмента
* **Prompt from the token-chart plugin**: плагин отправил это сообщение от вашего имени

Чтобы запретить плагину отображать содержимое, отключите плагин в [диалоговом окне плагинов](#install-plugins).

## Работа с git

Claude Code интегрируется с git для помощи в рабочих процессах контроля версий прямо в VS Code. Попросите Claude совершить коммиты, создать pull request'ы или работать между ветками. Чтобы запустить Claude в изолированном worktree с собственными файлами и веткой, см. [Запуск параллельных сеансов с worktrees](https://code.claude.com/docs/ru/worktrees.md).

### Создание коммитов и pull request'ов

Claude может подготавливать изменения, писать сообщения коммитов и создавать pull request'ы на основе вашей работы:

commit my changes with a descriptive message create a pr for this feature summarize the changes I've made to the auth module


При создании pull request'ов Claude генерирует описания на основе фактических изменений кода и может добавлять контекст о тестировании или решениях по реализации.

### Повторное открытие диалога, перешедшего в worktree

В повторно открытом диалоге баннер **This session is in worktree** означает, что рабочий каталог диалога — это указанный в баннере [worktree](https://code.claude.com/docs/ru/worktrees.md), а не папка, открытая в этом окне. Чтобы открыть worktree в новом окне VS Code, нажмите **Open worktree** на баннере.

Диалог переходит в worktree, например, когда вы [просите Claude работать в нём](https://code.claude.com/docs/ru/worktrees.md#ask-claude-to-create-a-worktree). Когда вы снова открываете его или панель [повторно открывает его после перезагрузки окна](#continue-conversations-after-a-reload), он возобновляется в worktree, если Claude Code создал этот worktree в `.claude/worktrees/` и тот всё ещё существует. До Claude Code v2.1.300 вместо этого открывался пустой диалог. В этих версиях обновите расширение.

## Работа с блокнотами Jupyter

Claude Code редактирует блокноты с помощью [инструмента NotebookEdit](https://code.claude.com/docs/ru/tools-reference.md#notebookedit-tool-behavior).

### Повторный запуск отредактированных ячеек

Когда Claude заменяет ячейку с кодом, он перезаписывает исходный код ячейки в файле и очищает сохранённый вывод ячейки и счётчик выполнения.

Редактирование не требует перезапуска ядра: NotebookEdit записывает только файл и не подключается к вашему ядру. Перезапустите эту ячейку, а также все ячейки, которые используют определённые в ней функции или переменные.

### Сохраняйте блокнот перед редактированием

Сохраните блокнот, прежде чем просить о редактировании: [настройка `autosave`](#extension-settings) расширения не сохраняет блокнот перед запуском NotebookEdit.

## Выполнение работы в фоновом режиме

Отправьте длительную команду или субагента в фоновый режим, а затем проверяйте их состояние из поля ввода промпта.

### Перевод выполняющейся команды или субагента в фоновый режим

Когда команда или [субагент](https://code.claude.com/docs/ru/sub-agents.md) заставляет Claude ждать дольше, чем вам хотелось бы, нажмите **Run in background** под соответствующим вызовом инструмента в диалоге. Требуется Claude Code v2.1.287 или новее.

* **Когда появляется**: действие становится доступным, когда команда выполняется около двух секунд, или сразу после того, как Claude начинает ждать [субагента](https://code.claude.com/docs/ru/sub-agents.md#run-subagents-in-foreground-or-background), которого он запустил из основного диалога.
* **После нажатия**: Claude перестаёт ждать и продолжает ход. Команда или субагент продолжают работать как [фоновая задача](https://code.claude.com/docs/ru/tools-reference.md#background-commands), которая уведомит Claude о завершении.

Чтобы тем временем проверить состояние задачи или остановить её, введите `/tasks` в поле ввода промпта, чтобы открыть [карту агентов](#use-the-prompt-box). Субагент сохраняет своё место в дереве агентов, а команда отображается под агентами с [последним выводом на её карточке](#monitor-background-processes).

#### The Run in background action is missing under a subagent

По умолчанию в VS Code для субагентов это действие не отображается. Чтобы выяснить причину для конкретного субагента, откройте его карточку в [карте агентов](#use-the-prompt-box) и прочитайте строку `Spawned by`:

* **`Spawned by the main agent`**: субагент был запущен в фоновом режиме, поэтому Claude его не ждёт, и вам ничего делать не нужно. Чтобы Claude вместо этого ждал субагентов, см. раздел [Как заставить Claude ждать субагента](https://code.claude.com/docs/ru/sub-agents.md#let-claude-wait-for-a-subagent).
* **В `Spawned by` указан другой субагент**: действие появляется только для субагентов, запущенных основным агентом, но не для [вложенного субагента](https://code.claude.com/docs/ru/sub-agents.md#let-subagents-spawn-their-own-subagents), которого ждёт другой субагент. Чтобы досрочно завершить вложенного субагента, нажмите **Stop agent** на его карточке. После этого ожидающий субагент продолжит работу без этого результата.

### Отслеживание фоновых процессов

Введите `/tasks` в поле ввода промпта, чтобы открыть [карту агентов](#use-the-prompt-box), где перечислены фоновые задачи сессии, например dev-сервер, который Claude оставил работать как фоновую shell-команду. Нажмите на задачу, чтобы открыть её карточку, где её можно остановить. Требуется Claude Code v2.1.277 или новее.

Для фоновой shell-команды или [монитора](https://code.claude.com/docs/ru/tools-reference.md#monitor-tool), который запускает команду, карточка также показывает последний вывод команды и обновляет его, пока команда выполняется.

#### Просмотр вызовов инструментов фонового субагента

Если субагент отображается одной строкой состояния без вызовов инструментов, введите `/tasks` в поле ввода промпта, чтобы открыть [карту агентов](#use-the-prompt-box), и нажмите на этого субагента там. Субагент [работает в фоновом режиме](#the-run-in-background-action-is-missing-under-a-subagent), и его карточка показывает его вызовы инструментов и кнопку, которая открывает его транскрипт.

>
> ```powershell theme={null}
> Start-Process "vscode://anthropic.claude-code/open"
> ```
>
> В `cmd.exe` команда `start` воспринимает первый аргумент в кавычках как заголовок окна, поэтому передайте пустой заголовок перед URL:
>
> ```cmd theme={null}
> start "" "vscode://anthropic.claude-code/open"
> ```

Обработчик принимает два необязательных параметра запроса:

| Параметр | Описание |
| - | - |
| `prompt` | Текст для предварительного заполнения поля ввода промпта. Должен быть закодирован для URL. Промпт подставляется, но не отправляется автоматически. |
| `session` | ID сессии, которую нужно возобновить, из папки, открытой в VS Code. В Claude Code v2.1.300 или новее также возобновляется сессия из основного checkout или [worktree](https://code.claude.com/docs/ru/worktrees.md) репозитория этой папки. Если сессия не найдена, вместо неё начинается новый диалог. Если сессия уже открыта во вкладке, фокус переходит на эту вкладку. Чтобы получить ID сессии программно, см. раздел [Продолжение диалогов](https://code.claude.com/docs/ru/headless.md#continue-conversations). |

Например, чтобы открыть вкладку с предварительно заполненным текстом «review my changes»:

vscode://anthropic.claude-code/open?prompt=review%20my%20changes


Расширение также обрабатывает `vscode://anthropic.claude-code/install-plugin`, который [открывает диалоговое окно плагинов для одного плагина](#share-a-plugin-install-link). Чтобы запустить сессию в терминале вместо вкладки VS Code, используйте обработчик `claude-cli://` из CLI. См. раздел [Запуск сессий по ссылкам](https://code.claude.com/docs/ru/deep-links.md).

## Использование сторонних провайдеров

По умолчанию Claude Code подключается напрямую к API Anthropic. Если ваша организация использует Amazon Bedrock, Google Cloud's Agent Platform или Microsoft Foundry для доступа к Claude, настройте расширение на использование вашего провайдера:

**1. Отключите промпт входа**

Откройте [настройку Disable Login Prompt](vscode://settings/claudeCode.disableLoginPrompt) и установите флажок.

Вы также можете нажать `Cmd+,` на Mac или `Ctrl+,` на Windows/Linux, чтобы открыть настройки VS Code, выполнить поиск по запросу "Claude Code login" и установить флажок **Disable Login Prompt**.

**2. Настройте провайдера**

Следуйте руководству по настройке для вашего провайдера:

* [Claude Code в Amazon Bedrock](https://code.claude.com/docs/ru/amazon-bedrock.md)
* [Claude Code в Google Cloud's Agent Platform](https://code.claude.com/docs/ru/google-vertex-ai.md)
* [Claude Code в Microsoft Foundry](https://code.claude.com/docs/ru/microsoft-foundry.md)

В этих руководствах описана настройка провайдера в `~/.claude/settings.json`, что гарантирует общие настройки для расширения VS Code и CLI.

При использовании стороннего провайдера расширение не предоставляет функции, для которых требуется учётная запись claude.ai, например шкалы использования плана, [голосовую диктовку](https://code.claude.com/docs/ru/voice-dictation.md) и вкладку Web для [облачных сессий](#resume-cloud-sessions-from-claude-ai). О том, что показывает диалог Account & usage при таких способах входа, см. раздел [Проверка учётной записи и использования](#check-account-and-usage).

Вход в claude.ai, оставшийся от предыдущего выполнения `/login`, не используется: расширение не отправляет его ни с одним запросом.

## Использование программы чтения с экрана

Панель чата расширения работает с программами чтения с экрана. Вам не нужно ничего включать: расширение озвучивает активность в диалоге для всех пользователей, без каких-либо визуальных изменений. Это не связано с [режимом чтения с экрана](https://code.claude.com/docs/ru/accessibility.md) в CLI, который включается вручную и адаптирует интерфейс терминала.

Поддержка программ чтения с экрана в панели чата требует Claude Code v2.1.236 или новее.

Во время диалога расширение озвучивает:

* **Ответы Claude**: расширение озвучивает каждый ответ один раз, когда он завершён, и молчит, пока текст поступает потоком. Программа чтения с экрана зачитывает блоки кода в виде сводки с количеством строк, ссылки — по их подписи, а таблицы — ячейка за ячейкой; полный ответ остаётся доступным для чтения в транскрипте.
* **Запросы разрешений и вопросы**: расширение озвучивает запрос, когда появляется запрос разрешения, называя инструмент, который Claude хочет использовать. Аналогичным образом оно сообщает, когда Claude задаёт вам вопрос и когда Claude завершает план и ждёт вашей проверки.
* **Изменения статуса**: расширение сообщает, когда Claude начинает работу, когда Claude готов к вашему вводу и когда Claude Code начинает сжатие диалога. Если вы отправляете промпт, пока хуки [SessionStart](https://code.claude.com/docs/ru/hooks.md#sessionstart) сессии ещё выполняются, программа чтения с экрана также произносит «Running start-up hooks.»
* **Сообщения в очереди**: когда вы отправляете сообщение, пока Claude работает, расширение озвучивает для этого сообщения «Message queued.».
* **Ошибки и запросы, связанные с моделью**: расширение озвучивает ошибки в диалоге, а также сообщает о появлении [запроса согласия на использование кредитов использования](https://code.claude.com/docs/ru/model-config.md#fable-and-usage-credits) или [запроса для помеченного запроса](https://code.claude.com/docs/ru/model-config.md#ask-before-switching).

Пока Claude работает, программа чтения с экрана зачитывает текстовую метку вместо анимации индикатора выполнения.

Когда вы повторно открываете сессию или переключаетесь на другую, расширение ничего не озвучивает: восстановленная история, ожидающие запросы разрешений и статус выполнения остаются без озвучивания, пока не произойдёт что-то новое.

### Использование панели чата с клавиатуры

Каждый ход в транскрипте начинается с визуально скрытого заголовка, подписанного промптом, с которого начался этот ход. Используйте навигацию по заголовкам в вашей программе чтения с экрана, чтобы переходить между ходами.

Внутри хода программа чтения с экрана по мере перемещения сообщает, чьё сообщение перед вами:

* **Ваши сообщения**: «You»
* **Сообщения Claude**: «Claude»
* **Шаги инструментов**: «Claude» плюс название инструмента, например «Claude, Bash»
* **Блоки размышлений**: «Claude, thinking»

Поскольку расширение представляет транскрипт как помеченную область, вы также можете переместить фокус на сам транскрипт с помощью `Tab` и читать его в удобном вам темпе. Чтобы вместо этого переместить фокус на последнее сообщение или ожидающий запрос разрешения, выполните **Claude Code: Focus last message** из [палитры команд](#vs-code-commands-and-shortcuts).

Когда вариант в запросе разрешения сохраняет правило разрешений или доступ к каталогу, его подпись заканчивается указанием места сохранения подтверждения, например «all projects» или «this session». Чтобы изменить место сохранения:

* Установив фокус на этом варианте, нажмите клавишу со стрелкой `Left` или `Right`. Расширение озвучивает каждое место сохранения при переходе к нему. Клавиши со стрелками требуют Claude Code v2.1.268 или новее.
* Щёлкните место сохранения в подписи.

## Расширение VS Code и Claude Code CLI

Claude Code доступен как в виде расширения VS Code (графическая панель), так и в виде CLI (интерфейс командной строки в терминале). Некоторые функции доступны только в CLI. Если вам нужна функция, доступная только в CLI, запустите `claude` во встроенном терминале VS Code. Для этого требуется [автономная установка CLI](https://code.claude.com/docs/ru/setup.md): расширение не добавляет `claude` в ваш PATH. См. раздел [Запуск CLI в VS Code](#run-cli-in-vs-code).

| Функция | CLI | Расширение VS Code |
| - | - | - |
| Команды и скиллы | [Все](https://code.claude.com/docs/ru/commands.md) | Часть (введите `/`, чтобы увидеть доступные) |
| Настройка MCP-серверов | Да | Да: [добавляйте серверы и управляйте ими](#connect-to-external-tools-with-mcp) с помощью `/mcp` в панели чата |
| Чекпоинты | Да | Да |
| Ярлык `!` для Bash | Да | Нет |
| Автодополнение по Tab | Да | Нет |

### Запуск CLI в VS Code

Чтобы использовать CLI, не выходя из VS Code, нажмите `` Ctrl+` `` в Windows/Linux или `` Cmd+` `` на Mac, чтобы открыть встроенный терминал, а затем выполните `claude`.

Чтобы получить такие функции, как просмотр diff и передача диагностики, подключите CLI к расширению из встроенного или внешнего терминала:

* **Встроенный терминал**: [установите расширение](#install-the-extension), а затем запустите `claude`. CLI подключится автоматически. Claude Code v2.1.318 или новее не устанавливает расширение за вас, поэтому, пока вы его не установите, `/ide` сообщает "No available IDEs detected", а `/status` показывает IDE как "Not connected".
* **Внешний терминал**: выполните `/ide` внутри Claude Code, чтобы подключиться к VS Code. Если VS Code запущен без расширения, `/ide` установит его, если только вы не отключили [`autoInstallIdeExtension`](https://code.claude.com/docs/ru/settings-reference#autoinstallideextension).

Установка расширения не добавляет `claude` в PATH вашей оболочки. Расширение содержит собственную копию CLI для своей панели чата, но для ввода `claude` в терминале требуется [автономная установка CLI](https://code.claude.com/docs/ru/setup.md). Выполните установку один раз, и команды на этой странице, включая `claude mcp add` и `claude --resume`, будут работать в любом терминале. Если после установки `claude` по-прежнему не найден, [проверьте ваш PATH](https://code.claude.com/docs/ru/troubleshoot-install.md#verify-your-path).

### Переключение между расширением и CLI

Расширение и CLI используют общую историю диалогов. Чтобы продолжить диалог из расширения в CLI, выполните `claude --resume` в терминале. Откроется интерактивное окно выбора, в котором вы можете найти и выбрать нужный диалог.

## Подключение к внешним инструментам с помощью MCP

MCP-серверы (Model Context Protocol) предоставляют Claude доступ к внешним инструментам, базам данных и API.

Чтобы управлять MCP-серверами, не выходя из VS Code, введите `/mcp` на панели чата. В открывшемся диалоговом окне вы можете:

* Добавлять серверы
* Удалять серверы, сохранённые в локальной, пользовательской или проектной [области действия](https://code.claude.com/docs/ru/mcp.md#mcp-installation-scopes)
* Включать или отключать серверы
* Переподключаться к серверу
* Управлять аутентификацией OAuth

Для добавления и удаления серверов в диалоговом окне требуется Claude Code v2.1.261 или более поздней версии.

Вы также можете выполнить `claude mcp add` во встроенном терминале VS Code (`` Ctrl+` `` или `` Cmd+` ``). Диалоговое окно и команда терминала сохраняют данные в одну и ту же конфигурацию MCP, и изменения, внесённые любым из способов, вступают в силу в диалогах, которые вы начнёте после этого. В примере ниже добавляется удалённый MCP-сервер GitHub, который выполняет аутентификацию с помощью [персонального токена доступа](https://github.com/settings/personal-access-tokens), передаваемого в заголовке:

claude mcp add --transport http github https://api.githubcopilot.com/mcp/ \ --header "Authorization: Bearer YOUR_GITHUB_PAT"


Замените `YOUR_GITHUB_PAT` своим персональным токеном доступа. Команда `claude mcp add` сохраняет конфигурацию без проверки учётных данных, поэтому значение-заполнитель здесь будет принято, но позже сервер не сможет подключиться. Чтобы проверить подключение, начните новый диалог, введите `/mcp` и убедитесь, что у сервера отображается статус **Connected**. Для сервера с неверными учётными данными отображается **Failed**.

После настройки попросите Claude использовать инструменты (например, «Review PR #456»).

> [!NOTE]
>
> Чтобы найти серверы для подключения, см. раздел [Поиск и создание MCP-серверов](https://code.claude.com/docs/ru/mcp.md#find-and-build-mcp-servers).

## Встроенный MCP-сервер IDE

Когда расширение активно, оно запускает локальный MCP-сервер, к которому CLI подключается автоматически. Через этот сервер CLI:

* Открывает diff во встроенном средстве просмотра diff в VS Code
* Считывает ваше текущее выделение для `@`-упоминаний
* Просит VS Code выполнить ячейки, когда вы работаете в блокноте Jupyter

Сервер называется `ide` и скрыт из `/mcp`, поскольку в нём нечего настраивать. Однако если ваша организация использует хук `PreToolUse` для ведения списка разрешённых инструментов MCP, вам нужно знать о его существовании.

**Контекст выделения и открытого файла.** Пока CLI подключён, он включает ваше текущее выделение в редакторе и путь к активному файлу в качестве контекста в каждый отправляемый вами промпт. Когда это происходит, в транскрипте отображается строка `⧉ Selected N lines from <file>`. Следующие случаи изменяют этот контекст:

* **[Настройка Attach Selection](#keep-your-selection-and-open-file-out-of-your-messages) отключена**: CLI не включает ваше выделение в качестве контекста.
* **Настройка Attach Open File отключена**: CLI включает путь к активному файлу только тогда, когда также включает выделение.
* **Сообщения в очереди**: если вы [ставите сообщение в очередь, пока Claude работает](https://code.claude.com/docs/ru/interactive-mode.md#queue-messages-while-claude-works), оно сохраняет выделение, которое было у вас в момент нажатия `Enter`, независимо от того, что вы выделите после этого.
* **Конфиденциальные файлы**: чтобы исключить конфиденциальный файл, например `.env`, добавьте [запрещающее правило `Read`](https://code.claude.com/docs/ru/permissions#read-and-edit) для его пути. Соответствующее запрещающее правило не позволяет ни выделенному тексту, ни уведомлению об открытом файле для этого файла попасть к Claude.

**Транспорт и аутентификация.** Сервер привязывается к `127.0.0.1` на случайном порту в диапазоне 10000–65535, и этот порт нельзя настроить. Транспорт и токен аутентификации работают следующим образом:

* **Транспорт**: незашифрованный `ws://`. Поскольку сокет доступен только через loopback, любой процесс, способный перехватить трафик, может также прочитать токен из lock-файла, поэтому TLS не добавил бы защиты.
* **Токен аутентификации**: при каждой активации расширение генерирует новый случайный токен аутентификации и записывает его в lock-файл `~/.claude/ide/<port>.lock`. Для подключения CLI должен предъявить токен в заголовке `X-Claude-Code-Ide-Authorization`.
* **Права доступа к lock-файлу**: lock-файл имеет права доступа `0600` в каталоге с правами `0700`, поэтому прочитать его может только пользователь, запустивший VS Code. Если задана переменная `CLAUDE_CONFIG_DIR`, lock-файл вместо этого записывается в `$CLAUDE_CONFIG_DIR/ide/`.

**Инструменты, доступные модели.** Сервер предоставляет около дюжины инструментов, но модели видны только два. Остальные — это внутренние RPC, которые CLI использует для собственного интерфейса, например для открытия diff, чтения выделения и сохранения файлов. Они отфильтровываются до того, как список инструментов попадает к Claude.

| Имя инструмента (как его видят хуки) | Что он делает | Только для чтения |
| - | - | - |
| `mcp__ide__getDiagnostics` | Возвращает диагностику языкового сервера: ошибки и предупреждения из панели Problems в VS Code. При необходимости может ограничиваться одним файлом. | Да |
| `mcp__ide__executeCode` | Выполняет код Python в ядре активного блокнота Jupyter. См. процесс подтверждения ниже. | Нет |

**Диагностика в панели чата.** В панели чата при использовании Claude Code v2.1.285 или более поздней версии Claude считывает панель Problems в VS Code через отдельный встроенный сервер с именем `claude-vscode`. Claude может запросить у него текущие ошибки и предупреждения в одном файле или во всех файлах, для которых у VS Code есть диагностика.

Хуки и правила разрешений видят инструмент диагностики панели чата как `mcp__claude-vscode__getDiagnostics`. Чтобы охватить диагностику и в CLI, и в панели чата, укажите в хуке или правиле оба имени: `mcp__ide__getDiagnostics` и `mcp__claude-vscode__getDiagnostics`.

Этот пример `settings.json` запрещает оба инструмента:

{ "permissions": { "deny": [ "mcp__ide__getDiagnostics", "mcp__claude-vscode__getDiagnostics" ] } }


Запрещающее правило `Read` не распространяется ни на один из этих инструментов, поэтому блокируйте их по имени с помощью [запрещающего правила](https://code.claude.com/docs/ru/permissions.md#mcp), как показано в примере.

**Выполнение в Jupyter всегда требует подтверждения.** `mcp__ide__executeCode` не может ничего выполнить незаметно. Каждый вызов проходит следующие шаги:

1. Код вставляется как новая ячейка в конец активного блокнота.
2. VS Code прокручивает представление к этой ячейке.
3. Встроенное окно Quick Pick предлагает выбрать **Execute** или **Cancel**.

Отмена или закрытие окна выбора клавишей `Esc` возвращает Claude ошибку, и ничего не выполняется. Инструмент также сразу отказывает в выполнении, если нет активного блокнота, если не установлено расширение Jupyter (`ms-toolsai.jupyter`) или если ядро не Python.

> [!NOTE]
>
> Подтверждение через Quick Pick не связано с хуками `PreToolUse`. Запись в списке разрешённых для `mcp__ide__executeCode` позволяет Claude *предложить* выполнить ячейку; а *фактически* выполнить её позволяет именно Quick Pick внутри VS Code.

### Расширение не устанавливается

* Убедитесь, что у вас совместимая версия VS Code (1.94.0 или новее)
* Проверьте, что у VS Code есть разрешение на установку расширений
* Попробуйте установить расширение напрямую из [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)

### Значок Spark не отображается

Значок Spark появляется на **панели инструментов редактора** (в правом верхнем углу редактора), когда у вас открыт файл. Если вы его не видите:

1. **Откройте файл**: для отображения значка должен быть открыт файл. Открытой папки недостаточно.
2. **Проверьте версию VS Code**: требуется 1.94.0 или новее. Проверьте в разделе **Help > About**
3. **Перезапустите VS Code**: выполните «Developer: Reload Window» из палитры команд
4. **Отключите конфликтующие расширения**: временно отключите другие AI-расширения (Cline, Continue и т. д.)
5. **Проверьте доверие к рабочей области**: расширение не работает в ограниченном режиме (Restricted Mode)

Кроме того, можно нажать **✻ Claude Code** в **строке состояния** в правом нижнем углу окна. Это работает даже без открытого файла. Также можно открыть **палитру команд** (`Cmd+Shift+P` / `Ctrl+Shift+P`) и ввести «Claude Code».

### Cmd+Esc ничего не делает в macOS

В macOS Tahoe и новее системное сочетание клавиш Game Overlay по умолчанию назначено на `Cmd+Esc` и перехватывает нажатие до того, как оно дойдёт до VS Code. Чтобы освободить это сочетание клавиш:

1. Откройте System Settings
2. Перейдите в Keyboard, затем Keyboard Shortcuts, затем Game Controllers
3. Снимите флажок Game Overlay

Либо назначьте расширению другое сочетание клавиш: откройте в VS Code [редактор сочетаний клавиш](https://code.visualstudio.com/docs/configure/keybindings) (`Cmd+K Cmd+S`), найдите `Claude Code: Focus input` и назначьте новое сочетание.

### Ctrl+J добавляет новую строку в поле ввода промпта

Чтобы `Ctrl+J` перестало добавлять новую строку в поле ввода промпта, [отмените привязку клавиши](https://code.claude.com/docs/ru/keybindings.md#unbind-default-shortcuts) в файле `keybindings.json` Claude Code. Расширение читает этот файл начиная с версии 2.1.309, поэтому сначала обновите устаревшее расширение в представлении Extensions.

Этот пример — весь файл с единственной записью, которая отменяет привязку клавиши: `"ctrl+j": null` в блоке `Chat`:

{ "bindings": [ { "context": "Chat", "bindings": { "ctrl+j": null } } ] }


Файл находится в каталоге конфигурации Claude Code, которым является `~/.claude`, если вы не перенесли его с помощью `CLAUDE_CONFIG_DIR`. Посмотрите в этот каталог и выполните шаг, соответствующий тому, что вы найдёте:

* **Файла `keybindings.json` ещё нет**: создайте его точно с содержимым из примера
* **Есть `keybindings.json` без блока `Chat`**: добавьте блок `Chat` из примера в массив `bindings` верхнего уровня, в любую позицию
* **Есть блок `Chat` без строки `"ctrl+j"`**: добавьте `"ctrl+j": null` в `bindings` этого блока
* **Есть блок `Chat`, в котором уже есть строка `"ctrl+j"`**: измените значение этой строки на `null`

После сохранения файла нажатие `Ctrl+J` в поле ввода промпта не добавляет новую строку.

Если `Ctrl+J` всё ещё добавляет строку в поле ввода промпта, выполните по порядку эти две команды из палитры команд:

1. **Developer: Reload Window**, затем снова нажмите `Ctrl+J` в поле ввода промпта
2. **Claude Code: Show Logs**, затем найдите предупреждение, содержащее `Ctrl+J in the chat input still inserts a newline`. Исправьте указанную в нём проблему в названном в нём файле, сохраните файл и снова нажмите `Ctrl+J`.

Если в логе нет такого предупреждения, проверьте, что файл находится в каталоге конфигурации Claude Code и что его блок `Chat` задаёт для `"ctrl+j"` значение `null`. [Сообщите о проблеме](https://github.com/anthropics/claude-code/issues), если `Ctrl+J` всё ещё добавляет строку.

### Панель Claude Code пуста или не удалось её загрузить

Если панель Claude Code открывается, но ничего не показывает, даже поле ввода промпта, обновите расширение до v2.1.309 или новее в представлении Extensions. Затем выполните **Developer: Reload Window** из палитры команд. Если после этого вы увидите уведомление `Claude Code couldn’t load`, выполните по порядку перечисленные в нём шаги.

Если панель по-прежнему не загружается, откройте лог расширения и [сообщите о проблеме](https://github.com/anthropics/claude-code/issues), приложив его копию:

* **Панель всё ещё пуста на v2.1.309 или новее**: откройте лог с помощью **Claude Code: Show Logs** из палитры команд
* **Шаги из уведомления не помогли**: нажмите **Show logs** в уведомлении, чтобы открыть лог

### Возобновлённый диалог сначала пуст

Когда вы [возобновляете прошлый диалог](#resume-past-conversations) или диалог [восстанавливается после перезагрузки](#continue-conversations-after-a-reload), его сообщения могут оставаться пустыми, пока запускается процесс Claude Code для этого диалога. Примерно через секунду на пустом месте появляется `Waiting for your plugins…`.

Ничего делать не нужно. Сообщения появятся, как только процесс запустится и подтвердит, что ни одному плагину не нужно предварительно их проверить, либо через 20 секунд, если запуск занимает больше времени.

### Панель перестаёт отвечать каждый раз, когда перезагрузка заново открывает диалог

Если вся панель аварийно завершает работу, зависает или показывает только `Something went wrong` каждый раз, когда вы перезагружаете окно и ваш диалог восстанавливается, обновите расширение до v2.1.301 или новее. Затем снова перезагрузите окно или перезапустите VS Code. После того как диалогу дважды подряд не удастся полностью открыться, вместо него вы получите новый чат с уведомлением о том, что [он не был открыт заново](#a-conversation-was-not-reopened).

### Формула отображается как исходный LaTeX

Если никакие математические выражения в ответах Claude не отображаются в наборе, проверьте версию расширения в представлении Extensions, поскольку [отображение математики](#latex-math-in-responses) требует версии 2.1.301 или новее. Если вы используете [режим терминала](#switch-to-terminal-mode), который не отображает математику независимо от версии, снимите флажок [настройки Use Terminal](vscode://settings/claudeCode.useTerminal), чтобы Claude Code открывался в панели чата.

Если одна формула отображается в исходном виде, а соседние — в наборе, проверьте её на следующие причины:

* **Формула встроенная, и панель не считает её математикой**: попросите Claude отправить её ещё раз в виде блока `$$` на отдельных строках. Панель оставляет встроенную формулу в исходном виде, если текст между её разделителями `$…$`:
  * Сложнее простой арифметики, но не содержит символа вроде `=`, `+` или `^`, который помечал бы его как математику, например `$O(n log n)$`
  * Начинается с цифры и не содержит такого символа, например `$30$` и `$1/N$`
  * Содержит пробелы внутри знаков доллара, например `$ x^2 $`
  * Длиннее 60 символов
  * Разбит на две строки. Формула `\(…\)`, разбитая на две строки, тоже не отображается в наборе.
* **В формуле синтаксическая ошибка TeX**: попросите Claude переписать её с исправленной ошибкой.
* **Формула определяет макрос**: формула с определением макроса, например `\newcommand` или `\def`, отображается в исходном виде. Попросите Claude переписать её без макроса.
* **Формула содержит неэкранированный `%`**: попросите Claude переписать её с `\%` для знака процента.
* **Формула слишком большая**: формула длиннее 8 192 символов или формула, которая при отрисовке получилась бы намного больше своего исходного текста TeX, отображается в исходном виде. Попросите Claude разбить её на формулы поменьше или записать компактнее.
* **Формула следует за большим объёмом математики**: в пределах одного текстового блока ответа панель отображает формулы в наборе по порядку до определённого предела. Последующая формула, которая превысила бы этот предел, отображается в исходном виде. Попросите Claude отправить нужную вам формулу ещё раз отдельно.

### Диктовка или вкладка Web не работают за прокси с TLS-инспекцией

Если диктовка или вкладка Web завершаются с ошибкой сертификата, например `unable to get local issuer certificate`, задайте [`NODE_EXTRA_CA_CERTS`](https://code.claude.com/docs/ru/network-config#custom-ca-certificates) в блоке `env` файла `~/.claude/settings.json`. Укажите в ней путь к PEM-файлу с корневым CA-сертификатом вашего прокси, который может предоставить ваша IT-команда. Сбой отображается на кнопке микрофона или вкладке Web либо в логах:

* **Диктовка**: кнопка микрофона показывает текст ошибки после `Dictation error: WebSocket error:`.
* **Вкладка Web**: вкладка со списком [облачных сессий](#resume-cloud-sessions-from-claude-ai) показывает `Remote server is not connected` без текста ошибки. Чтобы прочитать его в логах:
  1. Выполните **Claude Code: Show Logs** из [палитры команд](#vs-code-commands-and-shortcuts), чтобы открыть канал вывода `Claude VSCode`.
  2. Нажмите **Reconnect** на вкладке и подождите, пока она перестанет показывать `Connecting…`.
  3. Найдите в канале `Error fetching remote sessions:` или `Failed to fetch organization UUID:`, затем прочитайте текст ошибки после этого префикса в самой новой подходящей строке.
* **Предупреждение в логе**: предупреждение, в котором упоминается `an authority that Claude Code does not trust`, сообщает об ошибке сертификата. За прокси с TLS-инспекцией задайте `NODE_EXTRA_CA_CERTS` в `env` в `~/.claude/settings.json`. Версии до v2.1.309 не записывают это предупреждение в лог.

Для этого исправления требуется расширение версии 2.1.307 или новее, поэтому сначала обновите расширение. Затем задайте в `NODE_EXTRA_CA_CERTS` полный путь к файлу сертификата без `~`. Для пути Windows в `settings.json` пишите каждую обратную косую черту дважды, например `C:\\certs\\example-ca.pem`.

> [!NOTE]
>
> В окне, подключённом к WSL, SSH-хосту, dev-контейнеру или другой системе, сохраните файл сертификата и отредактируйте `~/.claude/settings.json` в этой системе, а не на вашем локальном компьютере.

В этом примере указан файл сертификата по пути Linux или macOS `/etc/ssl/certs/example-ca.pem`:

{ "env": { "NODE_EXTRA_CA_CERTS": "/etc/ssl/certs/example-ca.pem" } }


Сохраните `settings.json`, затем начните запись или снова нажмите **Reconnect**. Если ошибка возвращается, откройте канал вывода с помощью **Claude Code: Show Logs** и найдите в нём `use the CA certificates file`. Такое предупреждение сообщает причину, по которой расширение не может использовать ваш файл, и указывает, откуда был прочитан путь. Затем найдите в этой таблице каждое место, где вы задали `NODE_EXTRA_CA_CERTS`, и выполните указанное в соответствующей строке:

| Где вы её задали | Что сделать |
| - | - |
| Окружение, с которым был запущен VS Code | Заданное здесь значение имеет приоритет над значением в `~/.claude/settings.json`, даже если указанный в нём файл нельзя использовать. Исправьте или удалите его, затем перезапустите VS Code |
| `env` в `~/.claude/settings.json` | Исправьте значение или указанный в нём файл, затем начните запись или снова нажмите **Reconnect** |
| Настройка VS Code [`claudeCode.environmentVariables`](#extension-settings), `~/.claude.json`, файл проекта `.claude/settings.json` или `.claude/settings.local.json` либо управляемые настройки | Заданное здесь значение не применяется к диктовке и вкладке Web. Задайте переменную также в `env` в `~/.claude/settings.json` |

### Claude Code не отвечает

Если Claude Code не отвечает на ваши промпты:

1. **Проверьте подключение к интернету**: убедитесь, что у вас стабильное подключение к интернету
2. **Начните новый диалог**: попробуйте начать новый диалог, чтобы проверить, сохраняется ли проблема
3. **Попробуйте CLI**: запустите `claude` в терминале, чтобы увидеть более подробные сообщения об ошибках

Если проблемы не исчезают, [создайте issue на GitHub](https://github.com/anthropics/claude-code/issues) с подробным описанием ошибки.

## Удаление расширения

Чтобы удалить расширение Claude Code:

1. Нажмите `Cmd+Shift+X` на Mac или `Ctrl+Shift+X` на Windows/Linux, чтобы открыть представление Extensions
2. Найдите «Claude Code»
3. Нажмите **Uninstall**

Если после удаления вы выполните любое из следующих действий, расширение вернётся:

* Запуск `/ide` во внешнем терминале, пока запущен VS Code
* Запуск `claude` во встроенном терминале в версии Claude Code ниже v2.1.318

Чтобы расширение не возвращалось, выполните одно из следующих действий, а затем снова удалите его, если оно уже вернулось:

* Задайте для [`autoInstallIdeExtension`](https://code.claude.com/docs/ru/settings-reference#autoinstallideextension) значение `false` в `~/.claude.json`
* Задайте для [`CLAUDE_CODE_IDE_SKIP_AUTO_INSTALL`](https://code.claude.com/docs/ru/env-vars#variables) значение `1` в разделе `env` [файла настроек](https://code.claude.com/docs/ru/env-vars.md#in-settings-files)
* Во встроенном терминале отключите **Auto-install IDE extension** в `/config`

Чтобы также удалить данные расширения и сбросить все настройки, удалите каталог хранилища расширения для вашей платформы.

В macOS:

rm -rf ~/Library/"Application Support"/Code/User/globalStorage/anthropic.claude-code


В Linux:

rm -rf ~/.config/Code/User/globalStorage/anthropic.claude-code


В Windows, в PowerShell:

Remove-Item -Recurse -Force "$env:APPDATA\Code\User\globalStorage\anthropic.claude-code"


Дополнительную помощь см. в [руководстве по устранению неполадок](https://code.claude.com/docs/ru/troubleshooting.md).
