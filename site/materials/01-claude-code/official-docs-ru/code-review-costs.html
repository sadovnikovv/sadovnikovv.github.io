Стоимость и использование Code Review #

Оцените и ограничьте расходы вашей организации на Claude Code Review: как ревью оплачиваются через кредиты использования, что влияет на стоимость и где отслеживать использование.

У Code Review нет фиксированной цены за одно ревью. Ваши расходы зависят от стоимости каждого ревью и от того, сколько ревью выполняется:

  • Стоимость каждого ревью: зависит от уровня ревью, размера изменения, сложности окружающего кода и количества потенциальных проблем, требующих проверки
  • Количество ревью: определяется тем, как часто выполняются ревью в каждом репозитории

Цены #

Code Review тарифицируется по использованию токенов через кредиты использования, отдельно от использования, включённого в ваш план. Ревью оплачиваются вашей организацией, а не разработчиком, который открыл PR или запросил ревью. Расходы отображаются в вашем счёте Anthropic независимо от того, использует ли ваша организация Amazon Bedrock, Google Cloud's Agent Platform или Microsoft Foundry для других функций Claude Code.

Как часто выполняются ревью #

Репозиторий, который вы добавляете на странице администратора, по умолчанию использует режим After every push, при котором выполняется больше всего ревью. Настройка Review runs каждого репозитория определяет, сколько ревью получает pull request:

  • Once after PR creation: ревью выполняется, когда pull request открывается, открывается повторно или помечается как готовый к ревью
  • After every push: ревью выполняется при каждом push, умножая стоимость на количество push
  • Manual (@claude review): ревью не выполняются ни при открытии, ни при push

Команды в комментариях, черновики и pull request из форков влияют на это количество:

  • @claude review always в режиме Once after PR creation или Manual: подписывает PR на ревью, запускаемые при push, поэтому после этого комментария за каждый push начисляется дополнительная стоимость
  • @claude review always в режиме After every push: push уже запускают ревью, поэтому подписка не меняет стоимость за push
  • @claude review: выполняет одно ревью без подписки на будущие push
  • Черновики и pull request из форков: автоматические ревью пропускают и те, и другие, поэтому push в них не добавляют ревью

Оценка расходов #

Перед широким развёртыванием проведите небольшой пилот, чтобы оценить ежемесячные расходы на основе ваших собственных pull request.

  1. Установите ежемесячный лимит расходов для пилота.
  2. Включите Code Review для нескольких репрезентативных репозиториев, установив для Review runs значение Once after PR creation или Manual (@claude review).
  3. После выполнения нескольких ревью посмотрите среднюю стоимость одного ревью для каждого репозитория в столбце Average cost таблицы Repositories в разделе Code review на странице Admin settings > Claude Code.
  4. Умножьте это среднее значение на количество pull request, открываемых в репозитории за месяц. Для After every push умножьте ещё раз на типичное количество push на один pull request.

Среднее значение для репозитория меняется в зависимости от размера его pull request и выбранного вами уровня ревью.

Ограничение расходов #

Чтобы установить ежемесячный лимит расходов для Code Review, перейдите на claude.ai/admin-settings/usage и настройте лимит для сервиса Claude Code Review. Лимит применяется ко всей организации.

Code Review пропускает ревью, когда исчерпывается любой из следующих ресурсов:

  • Лимит расходов Code Review: ежемесячный лимит, который вы установили для сервиса Claude Code Review. Он сбрасывается в начале следующего расчётного периода, а если вы его повысите, ревью возобновятся раньше.
  • Лимит расходов организации: общий ежемесячный лимит расходов вашей организации на кредиты использования. Его можно повысить на той же странице.
  • Баланс кредитов использования: баланс кредитов использования вашей организации. Кредиты можно добавить на той же странице.

Code Review также пропускает ревью, если оставшаяся сумма меньше ожидаемой стоимости одного ревью. Когда ревью пропускается, разработчики видят комментарий в PR, в котором указана причина и есть ссылка на настройки использования.

Для мониторинга расходов используйте панель аналитики.

Просмотр использования #

Перейдите на claude.ai/analytics/code-review, чтобы увидеть активность Code Review по всей вашей организации.

| Раздел | Что отображается | | :- | :- | | PRs reviewed by Code Review | Ежедневное количество pull request, прошедших ревью, за выбранный период | | Code Review cost | Расходы на Code Review с начала текущего месяца | | Code Review feedback | Количество комментариев ревью, которые были автоматически закрыты, потому что разработчик устранил проблему | | Code Review findings | Ежедневное количество находок по уровню серьёзности из ревью, которые Claude опубликовал за выбранный период | | Repository breakdown | Количество PR, прошедших ревью, закрытых комментариев и запусков ревью по каждому репозиторию с оценочной стоимостью и представлением по каждому PR |

Карточка Code Review cost показывает сумму, только когда выбран текущий месяц. Данные о стоимости в аналитике могут отличаться от вашего счёта. Стоимость в Repository breakdown рассчитывается по прейскурантной цене, без учёта скидок и кредитов, и охватывает только ревью, которые Claude опубликовал в pull request. Для получения точных данных о расходах обращайтесь к своему счёту Anthropic.

Связанные ресурсы #

  • Настройка Code Review: где выбрать уровень ревью и момент запуска ревью в каждом репозитории
  • Чтение и запрос ревью в pull request: команды в комментариях, pull request из форков и сообщение о бюджете, которое видят разработчики при пропуске ревью
  • Code Review: что проверяет ревью и что оно публикует
  • Эффективное управление затратами: контроль расходов и отслеживание использования для остальных функций Claude Code
