Примеры #

Найдите полный, готовый к запуску проект Agent SDK или пошаговый рецепт из Claude Cookbook, который соответствует тому, что вы хотите создать.

Эта страница направляет вас к полным, готовым к запуску проектам Agent SDK и пошаговым рецептам Claude Cookbook. Приложения находятся в репозитории claude-agent-sdk-demos, а рецепты Python находятся в Claude Cookbook.

Сначала запустите минимальный агент #

Если вы еще ничего не создавали с помощью SDK, начните с одного из этих вариантов перед полным приложением:

  • Agent SDK quickstart: создайте свой первый работающий агент на TypeScript или Python с включенными шагами настройки. Агент находит и исправляет ошибки в примере файла.
  • Hello World: минимальный проект TypeScript для клонирования, когда вы хотите начать с кода репозитория

Изучите приложение-демонстрацию #

Приложения в claude-agent-sdk-demos — это демонстрации для локальной разработки, от почтового клиента до многоагентной системы исследований. Клонируйте демонстрацию, структура которой соответствует тому, что вы создаете.

Форк готового проекта #

Чтобы создать агента для покупок или агента для продавца с помощью Python SDK, начните с эталонной реализации Claude for commerce.

Работайте с рецептом Python #

Серия Agent SDK в Claude Cookbook — это последовательность рецептов, каждый из которых представляет собой записную книжку Python, которая развивается от простого агента исследований к сложным многоагентным системам. Каждая записная книжка основывается на предыдущей, вводя новые концепции и возможности. Начните с однострочного агента исследований и двигайтесь дальше.

Для рецептов по всем продуктам Claude см. полный Claude Cookbook.
