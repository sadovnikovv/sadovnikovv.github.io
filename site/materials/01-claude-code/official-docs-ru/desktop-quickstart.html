Начало работы с настольным приложением #

Установите настольное приложение Claude, откройте вкладку Code и начните свой первый сеанс Claude Code в папке проекта на вашем компьютере.

Настольное приложение предоставляет вам Claude Code с графическим интерфейсом. Вы можете попросить Claude работать с кодом в папке на вашем компьютере, а затем самостоятельно просмотреть изменения без использования терминала.

Claude Code находится на вкладке Code в верхней части боковой панели приложения. На этой странице описывается установка приложения и начало вашей первой сессии на этой вкладке. Claude Code требует подписку Pro, Max, Ultra, Team или Enterprise.

Установка #

1. Установка и вход в систему

На macOS и Windows загрузите установщик по ссылкам выше и запустите его. На Linux следуйте инструкциям по установке в разделе Claude Desktop на Linux. Запустите Claude из папки Applications на macOS, из меню Start на Windows или из средства запуска приложений на Linux, затем войдите со своей учетной записью Anthropic.

2. Откройте вкладку Code

Нажмите на вкладку Code в верхней части боковой панели. Если на вкладках отображаются только значки, наведите курсор на один из них, чтобы увидеть его название. Если после нажатия на Code появляется запрос или ошибка, воспользуйтесь соответствующим решением:

  • Запрос на обновление: вам необходимо сначала подписаться на платный план
  • Запрос на вход в систему онлайн: завершите вход и перезапустите приложение
  • Ошибка 403: см. устранение неполадок аутентификации

Настольное приложение включает Claude Code, поэтому вам не нужно устанавливать Node.js или CLI для использования вкладки Code.

Начните свой первый сеанс #

С открытой вкладкой Code выберите проект и дайте Claude что-нибудь сделать.

1. Выберите окружение и папку

В строке под полем ввода промпта нажмите первый элемент управления — селектор окружения — и выберите верхний пункт в группе Local. Затем нажмите элемент управления папкой проекта рядом с селектором окружения, выберите Open folder… и укажите директорию вашего проекта.

Если в новой сессии под полем ввода промпта не отображается окружение, у вас более ранняя версия интерфейса. См. Проверьте, какая у вас версия интерфейса.

[!TIP]

Начните с небольшого проекта, который вы хорошо знаете. Это самый быстрый способ увидеть, что может делать Claude Code.

Вы также можете выбрать:

  • Cloud: Запускайте сеансы в облаке, которые продолжают работу даже если вы закроете приложение. См. Use Claude Code in the cloud для информации о том, как работают облачные сеансы.
  • SSH: Подключитесь к удаленной машине через SSH, например к вашим собственным серверам, облачным виртуальным машинам или контейнерам разработки. Сначала добавьте подключение. Desktop автоматически устанавливает Claude Code на удаленную машину при первом подключении. Выполняющаяся задача может продолжать работу, пока Desktop отключен, но при использовании аккаунта Claude она может остановиться, когда истечет срок ее входа в систему.
  • WSL (Windows): Запустите сессию внутри WSL 2 дистрибутива; Claude Code, инструменты и git выполняются на стороне Linux с собственными путями.

2. Выберите модель

Выберите модель в селекторе моделей ближе к правому краю строки под полем ввода промпта. См. models для сравнения доступных моделей. Вы можете изменить модель позже в селекторе моделей.

3. Скажите Claude, что делать

Введите, что вы хотите, чтобы Claude сделал:

  • Find a TODO comment and fix it
  • Add tests for the main function
  • Create a CLAUDE.md with instructions for this codebase

Сессия — это диалог с Claude о вашем коде. Каждая сессия отслеживает свой собственный контекст и изменения.

4. Проверьте и примите изменения

Проверьте ваш режим разрешений в строке под полем ввода промпта, чтобы узнать, ждет ли Claude вашего подтверждения:

  • Auto или Accept edits: Claude применяет изменения файлов, и появляется индикатор, такой как +12 -1, чтобы вы могли просмотреть их в представлении diff
  • Manual: Claude предлагает каждое изменение и ждет вашего подтверждения перед его применением

В режиме Manual вы увидите:

  1. Diff, показывающий точно, что изменится
  2. Кнопки для подтверждения или отклонения каждого изменения
  3. Обновления в реальном времени по мере того, как Claude работает над вашим запросом

Что дальше? #

Вы сделали первое редактирование. Полный справочник по всем возможностям Desktop см. в разделе Use Claude Code Desktop. Вот несколько вещей, которые стоит попробовать дальше.

Прерывание и управление. Вы можете перенаправить Claude в любой момент. Нажмите кнопку остановки, чтобы прервать немедленно, или введите исправление и нажмите Enter, чтобы отправить его без остановки выполняемого действия. В любом случае вам не нужно ждать завершения или начинать заново.

Предоставьте Claude больше контекста. Введите @filename в поле промпта, чтобы добавить конкретный файл в диалог. Чем больше контекста у Claude, тем лучше результаты. См. Add files and context.

Используйте skills для повторяющихся задач. Введите / или нажмите + → Slash commands, чтобы просмотреть built-in commands, custom skills и skills плагинов. Skills — это многократно используемые подсказки, которые вы можете вызывать всякий раз, когда они вам нужны, например контрольные списки проверки кода или этапы развертывания.

Проверьте изменения перед фиксацией. После редактирования файлов Claude появляется индикатор +12 -1. Нажмите на него, чтобы открыть diff view, просмотрите изменения файл за файлом и оставляйте комментарии к конкретным строкам. Claude читает ваши комментарии и вносит исправления. Чтобы Claude сам проверил изменения, введите /code-review в поле промпта.

Отрегулируйте объем контроля. Ваш permission mode определяет, сколько Claude может делать без запроса одобрения:

  • Auto: классификатор проверяет действия в фоновом режиме и блокирует рискованные вместо того, чтобы просить вас.
  • Manual: Claude запрашивает разрешение перед редактированием файлов или запуском команд.
  • Accept edits: Claude автоматически принимает редактирование файлов для более быстрой итерации.
  • Plan: Claude предлагает подход без редактирования каких-либо файлов, что полезно перед крупным рефакторингом.

Добавьте плагины для дополнительных возможностей. Установите плагины, которые добавляют скиллы, агентов, MCP-серверы и многое другое.

Организуйте рабочее пространство. Перетащите панели чата, diff, терминала, файла и браузера в любой нужный вам макет. Откройте терминал с помощью Ctrl+\`, чтобы запускать команды параллельно с вашей сессией, или нажмите на путь файла, чтобы открыть его. См. Arrange your workspace.

Предпросмотр вашего приложения. Когда вы запускаете сервер разработки на рабочем столе, ваше приложение открывается в панели Browser, которая также может открывать внешние сайты. Claude может просматривать работающее приложение, тестировать конечные точки, проверять журналы и повторять итерации на основе того, что он видит. См. Preview your app.

Отслеживайте ваш pull request. После открытия PR Claude Code отслеживает результаты проверок CI и может автоматически исправлять сбои. См. Monitor pull request status.

Поставьте Claude по расписанию. Установите scheduled tasks для автоматического запуска Claude на регулярной основе: ежедневная проверка кода каждое утро, еженедельный аудит зависимостей или брифинг, который извлекает данные из ваших подключенных инструментов.

Масштабируйте, когда будете готовы. Откройте параллельные сессии на боковой панели, чтобы работать над несколькими задачами одновременно, при желании каждая в своем Git worktree, и откройте панель задач, чтобы наблюдать за субагентами и фоновыми командами, которые запускает сессия. Откройте боковой чат, чтобы задать вопрос без отвлечения основного потока. Отправьте долгие задачи в облако, чтобы работа продолжалась, даже если вы закроете приложение, или перенесите уже начатую сессию в облако, если задача займет больше времени, чем ожидалось. Подключите внешние инструменты, такие как GitHub, Slack и Linear, чтобы объединить ваш рабочий процесс.
