Claude Code в Slack #

Делегируйте задачи кодирования из Slack. Эта более ранняя версия отвечает на упоминания только от учетных записей Pro, Max и Ultra в рабочих пространствах, не подключенных к Claude Tag.

[!WARNING]

Эта более ранняя версия Claude Code в Slack отвечает на @упоминания в каналах только от учетных записей Pro, Max и Ultra и только в рабочем пространстве Slack, которое ни одна организация не подключила к Claude Tag. Каждая сессия запускается под учетной записью отдельного пользователя. Claude Tag запускает @Claude как общую идентичность вашей организации с доступом, настроенным администратором.

  • Планы Pro, Max и Ultra: Claude Tag недоступен в индивидуальных планах, поэтому настройте эту версию в рабочем пространстве, не подключенном к Claude Tag.
  • Планы Team и Enterprise: ваше существующее приложение Slack и дескриптор @Claude сохраняются. Настройте Claude Tag для нового рабочего пространства; чтобы перенести то, которое уже использует эту версию, см. Миграция с более ранней версии Claude в Slack.
  • Уведомление вместо ответа: найдите уведомление о настройке или уведомление о прекращении работы, которым ответил @Claude.

Claude Code в Slack приносит мощь Claude Code прямо в ваше рабочее пространство Slack. Когда вы упоминаете @Claude с задачей кодирования, Claude автоматически определяет намерение и создает облачную сессию Claude Code, позволяя вам делегировать работу по разработке, не покидая командные диалоги.

Эта интеграция построена на существующем приложении Claude для Slack, но добавляет интеллектуальную маршрутизацию к облачным сессиям Claude Code для обращений, связанных с кодированием. Каждая сессия работает под вашей собственной учетной записью Claude, используя ваши подключенные репозитории и ограничения вашего плана.

Варианты использования #

  • Исследование и исправление ошибок: Опишите ошибку и попросите Claude исследовать и исправить её.
  • Быстрые код-ревью и модификации: Пусть Claude реализует небольшие функции или рефакторит код.
  • Параллельное выполнение задач: Запустите задачи кодирования в Slack, пока вы продолжаете другую работу, получая уведомления по завершении.

Предварительные требования #

Перед использованием Claude Code в Slack убедитесь, что у вас есть следующее:

| Требование | Детали | | :- | :- | | План Claude | Pro, Max или Ultra | | Рабочее пространство Slack | Не подключено к Claude Tag ни одной организацией. Если @Claude отвечает уведомлением о выводе из эксплуатации, значит, рабочее пространство подключено | | Облачные сессии | Облачные сессии включены для вашей учетной записи | | Учетная запись GitHub | Подключена к claude.ai/code с по крайней мере одним аутентифицированным репозиторием | | Аутентификация Slack | Ваша учетная запись Slack связана с вашей учетной записью Claude через приложение Claude |

Настройка Claude Code в Slack #

1. Установите приложение Claude в Slack

Администратор рабочего пространства должен установить приложение Claude из Slack App Marketplace. Посетите Slack App Marketplace и нажмите "Add to Slack", чтобы начать процесс установки.

2. Подключите вашу учетную запись Claude

После установки приложения аутентифицируйте вашу индивидуальную учетную запись Claude:

  1. Откройте приложение Claude в Slack, нажав на "Claude" в разделе "Apps"
  2. Перейдите на вкладку App Home
  3. Нажмите Connect Claude account, чтобы связать вашу учетную запись Slack с вашей учетной записью Claude
  4. Завершите процесс аутентификации в вашем браузере

3. Настройте облачные сеансы

Убедитесь, что облачные сеансы правильно настроены для вашей учетной записи:

  • Посетите claude.ai/code и войдите с той же учетной записью, которую вы подключили к Slack
  • Подключите вашу учетную запись GitHub, если она еще не подключена
  • Аутентифицируйте по крайней мере один репозиторий, с которым вы хотите, чтобы Claude работал

4. Выберите режим маршрутизации

После подключения ваших учетных записей настройте, как Claude обрабатывает ваши сообщения в Slack. Откройте App Home Claude в Slack, чтобы найти параметр Режим маршрутизации.

| Режим | Поведение | | :- | :- | | Только код | Claude маршрутизирует все @mentions к сеансам Claude Code. Лучше всего для команд, использующих Claude в Slack исключительно для задач разработки. | | Код + Чат | Claude анализирует каждое сообщение и интеллектуально маршрутизирует между Claude Code (для задач кодирования) и Claude Chat (для написания, анализа и общих вопросов). Лучше всего для команд, которые хотят единую точку входа @Claude для всех типов работы. |

[!NOTE]

В режиме "Код + Чат", если Claude отвечает в Chat, но вы хотели сессию кодирования, нажмите Switch to code repo... в ответе и выберите репозиторий. После этого Claude вместо этого запустит сессию Claude Code с вашим сообщением.

5. Добавьте Claude в каналы

Claude не добавляется автоматически ни в какие каналы после установки. Чтобы использовать Claude в канале, пригласите его, введя /invite @Claude в этот канал. Claude может отвечать только на @mentions в каналах, где он был добавлен.

Как это работает #

Автоматическое обнаружение #

В режиме маршрутизации Code + Chat, когда вы упоминаете @Claude в канале или цепочке Slack, Claude автоматически определяет, является ли ваше сообщение задачей кодирования. Задачи кодирования переходят в Claude Code в облачный сеанс. Все остальное получает обычный ответ чата. В режиме только Code каждое упоминание @mention переходит в Claude Code.

Вы также можете явно указать Claude обрабатывать запрос как задачу кодирования, даже если он не обнаружит это автоматически.

[!NOTE]

Claude Code в Slack работает только в каналах (публичных или приватных). Он не работает в прямых сообщениях (DM).

Сбор контекста #

  • Из цепочек: когда вы впервые упоминаете Claude через @mention в цепочке, он собирает контекст из ваших и своих собственных сообщений в этой цепочке.
  • Из каналов: когда вы упоминаете Claude через @mention непосредственно в канале, он просматривает ваши недавние сообщения и свои собственные в этом канале, а также название, тему и описание канала.

Этот контекст помогает Claude понять проблему, выбрать соответствующий репозиторий и определить свой подход к задаче. Чтобы передать Claude то, что написал коллега, например отчет об ошибке, вставьте этот текст в сообщение, в котором вы упоминаете Claude через @mention.

[!WARNING]

Когда @Claude вызывается в Slack, Claude получает доступ к контексту беседы, чтобы лучше понять ваш запрос. Claude может следовать указаниям из других сообщений в контексте, поэтому пользователи должны убедиться, что используют Claude только в доверенных беседах Slack.

Поток сеанса #

  1. Инициирование: Вы упоминаете Claude с запросом кодирования
  2. Обнаружение: Claude анализирует ваше сообщение и обнаруживает намерение кодирования
  3. Создание сеанса: Новый сеанс Claude Code создается на claude.ai/code
  4. Обновления прогресса: Claude публикует обновления статуса в вашу цепочку Slack по мере выполнения работы
  5. Завершение: По завершении Claude обновляет свое сообщение в цепочке, добавляя окончательный ответ и кнопки действий, и отправляет вам личное сообщение со ссылкой на него
  6. Проверка: Нажмите View session, чтобы увидеть полный транскрипт, или Create PR, чтобы открыть pull request

Элементы пользовательского интерфейса #

Действия с сообщениями #

  • View session: Открывает полную сессию Claude Code в вашем браузере, где вы можете увидеть всю выполненную работу, продолжить сессию или сделать дополнительные запросы.
  • Create PR: Открывает страницу сравнения GitHub для ветки сессии, где вы создаёте pull request. Кнопка появляется на статусном сообщении, которое Claude опубликовал при запуске сессии, после завершения сессии.
  • Switch to code repo...: Если Claude ответил в режиме Chat, но вы хотели сессию программирования, нажмите эту кнопку и выберите репозиторий, и Claude запустит сессию Claude Code с вашим исходным запросом.

Выбор репозитория #

Claude автоматически выбирает репозиторий на основе контекста из вашего диалога в Slack. Если Claude не может определить, какой репозиторий вы имеете в виду, он попросит вас выбрать: нажмите Select repository и выберите репозиторий из списка.

Доступ и разрешения #

Доступ на уровне пользователя #

| Тип доступа | Требование | | :- | :- | | Сеансы Claude Code | Каждый пользователь запускает сеансы под своей учетной записью Claude | | Использование и ограничения скорости | Сеансы учитываются в отношении ограничений плана отдельного пользователя | | Доступ к репозиторию | Пользователи могут получать доступ только к репозиториям, которые они лично подключили | | История сеансов | Сеансы отображаются в вашей истории Claude Code на claude.ai/code |

Доступ на уровне рабочего пространства #

Администраторы рабочего пространства Slack контролируют, доступно ли приложение Claude в их рабочем пространстве:

| Управление | Описание | | :- | :- | | Установка приложения | Администраторы рабочего пространства решают, устанавливать ли приложение Claude из Slack App Marketplace | | Распределение Enterprise Grid | Для организаций Enterprise Grid администраторы организации могут контролировать, какие рабочие пространства имеют доступ к приложению Claude | | Удаление приложения | Удаление приложения из рабочего пространства немедленно отзывает доступ для всех пользователей в этом рабочем пространстве |

Управление доступом на основе канала #

Установка приложения не добавляет Claude ни в какие каналы. Claude отвечает на @mentions только в каналах, где он был добавлен; пригласите его с помощью /invite @Claude. Он работает как в публичных, так и в приватных каналах. Администраторы могут контролировать использование Claude Code, управляя тем, в какие каналы приглашается Claude и кто имеет доступ к этим каналам. Это добавляет дополнительный уровень управления доступом помимо разрешений на уровне рабочего пространства.

Что доступно где #

В Slack: Вы увидите обновления статуса, резюме завершения и кнопки действия. Полная стенограмма сохраняется и всегда доступна.

На claude.ai/code: Полный сеанс Claude Code с полной историей беседы, все изменения кода и операции с файлами. Сеансы остаются в истории Claude Code по адресу claude.ai/code, где вы можете продолжить прошлые сеансы, ссылаться на них или создавать запросы на слияние.

Для учетных записей Enterprise и Team сеансы, созданные из Claude в Slack, автоматически видны организации. Дополнительные сведения см. в разделе совместное использование сеансов.

Лучшие практики #

Написание эффективных запросов #

  • Будьте конкретны: Включайте имена файлов, имена функций или сообщения об ошибках, когда это уместно.
  • Предоставьте контекст: Упомяните репозиторий или проект.
  • Определите успех: Объясните, как выглядит "готово" — должен ли Claude писать тесты? Обновить документацию? Создать PR?

Когда использовать Slack vs. веб-версию #

Используйте Slack когда: Вы хотите запустить задачу асинхронно или сотрудничаете с товарищами по команде, которым нужна видимость.

Используйте веб-версию напрямую когда: Вам нужно загрузить файлы, вы хотите взаимодействие в реальном времени во время разработки или работаете над более длительными, более сложными задачами.

Устранение неполадок #

"This workspace isn't set up for Claude Tag yet" #

@Claude отвечает в ветке этим уведомлением вместо ответа, когда выполняются оба условия:

  • Ни одна организация не подключила ваше рабочее пространство Slack к Claude Tag.
  • Учетная запись Claude, которую вы привязали в Slack, не использует план Pro, Max или Ultra.

Claude Tag доступен на планах Team и Enterprise. Чтобы подключить рабочее пространство, начните с команды @Claude connect, указанной в уведомлении, а затем следуйте инструкциям в разделе Настройка Claude Tag.

"The legacy Claude in Slack bot is retired" #

Уведомление начинается с The legacy Claude in Slack bot is retired effective October 5, 2026 and no longer responds in channels. Ваше рабочее пространство Slack подключено к организации Claude, а в настройках Claude Tag этой организации для канала, рабочего пространства или значения по умолчанию организации по-прежнему выбрана предыдущая версия. Уведомление не зависит от вашего собственного плана, поэтому его получают и учетные записи Pro, Max и Ultra.

Если вы являетесь Owner этой организации, откройте настройки администратора Claude и включите Claude Tag для канала. Чтобы исправить все каналы, наследующие эту настройку, измените ее на уровне рабочего пространства или значения по умолчанию организации. Полное описание перехода см. в разделе Миграция с предыдущей версии Claude in Slack. Если вы не являетесь Owner, отправьте эту запись одному из них.

"Claude Code is not enabled for your account" #

Эта ошибка означает, что ваша учетная запись Claude еще не имеет облачной среды. Войдите на claude.ai/code один раз с той же учетной записью, которую вы подключили к Slack, и завершите веб-подготовку, которая создает вашу облачную среду по умолчанию или просит вас создать ее. Ошибка исчезает при следующем упоминании. Каждый пользователь должен сделать это индивидуально.

Сессии не запускаются #

  1. Убедитесь, что ваша учетная запись Claude подключена в Claude App Home
  2. Проверьте, что облачные сессии включены для вашей учетной записи
  3. Убедитесь, что у вас подключен по крайней мере один репозиторий GitHub к Claude Code

Сессии из канала Claude Tag не запускаются #

Эта запись применяется к рабочим пространствам, использующим Claude Tag. Если вы создали облачную среду канала на claude.ai/code, она принадлежит вашей личной учетной записи, и Claude не может запустить сессии канала в личной среде. Claude Code немедленно завершает сессию с ошибкой, и повторная попытка не помогает.

Если вы являетесь Owner и среда принадлежит вам, поделитесь ею с организацией из селектора среды. В противном случае Owner пересоздает ее как организационно-общую среду со страницы Cloud environments в настройках администратора.

Вы можете применить ее двумя способами:

  • Установите ее как организационное значение по умолчанию на claude.ai/admin-settings/claude-code.
  • Установите ее на канале в настройках администратора Claude Tag.

Если вы не являетесь Owner, отправьте эту запись одному из них.

Репозиторий не отображается #

  1. Подключите репозиторий на claude.ai/code
  2. Проверьте ваши разрешения GitHub для этого репозитория
  3. Попробуйте отключить и повторно подключить вашу учетную запись GitHub

Выбран неправильный репозиторий #

Включите имя репозитория в ваш запрос для более точного выбора.

Ошибки аутентификации #

  1. Отключите и повторно подключите вашу учетную запись Claude в App Home
  2. Убедитесь, что вы вошли в правильную учетную запись Claude в вашем браузере

Текущие ограничения #

  • Только GitHub: репозитории должны находиться на GitHub.
  • Один PR за раз: каждая сессия может создать один pull request.
  • Требуется доступ к облачным сессиям: пользователи должны иметь доступ к облачным сессиям.
