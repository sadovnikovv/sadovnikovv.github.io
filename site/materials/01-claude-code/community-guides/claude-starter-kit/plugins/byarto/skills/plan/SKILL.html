Задача: $ARGUMENTS

Ничего не меняй в файлах, пока я не скажу «ок».

  1. Изучи проект: структуру, стек, CLAUDE.md и файлы, которые касаются задачи.
  2. Задай до 5 уточняющих вопросов — только тех, без которых план будет неверным.
  3. Предложи план: шаги по порядку, какие файлы создашь или изменишь, какие есть риски.
  4. Оцени объём: маленькая, средняя или большая задача.
  5. В конце спроси: «Делаем?» — и жди ответа.

Пиши по-русски, коротко, без жаргона.
