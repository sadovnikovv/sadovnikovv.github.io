name: ship description: Подготовить проект к выкладке — сборка, переменные окружения, секреты и пошаговая инструкция для новичка. argument-hint: "[куда: vercel, vps или пусто — подскажи]" disable-model-invocation: true

Куда выкладываем: $ARGUMENTS Если аргумент пустой — предложи вариант под этот проект и объясни, почему он.

  1. Проверь, что сборка проходит без ошибок. Если нет — исправь.
  2. Составь список переменных окружения: какие нужны, где их взять, какие из них секретные.
  3. Убедись, что секреты не попадут в репозиторий: .gitignore, .env.example.
  4. Сайт — на Vercel через GitHub. Бот или сервер — на VPS с Docker.
  5. Напиши инструкцию для новичка: шаги по порядку, что нажать и как проверить, что всё работает. Команды, которые я должен выполнить сам, выдели отдельно.

Сам ничего не выкладывай и не пушь — только подготовь.
