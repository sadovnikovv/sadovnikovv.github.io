name: check description: Строгое ревью перед выкладкой — баги, безопасность, лишняя сложность. Сначала список, правки только после ответа. argument-hint: "[файл, папка или пусто — всё с последнего коммита]" disable-model-invocation: true

Проверь: $ARGUMENTS Если аргумент пустой — проверь всё, что изменилось с последнего коммита.

Смотри как строгий сеньор:

  1. Баги и крайние случаи: пустые данные, ошибки сети, двойные клики.
  2. Безопасность: секреты в коде, открытые ключи, SQL- и XSS-инъекции, права доступа.
  3. Лишняя сложность и дубли.
  4. Производительность там, где её заметит пользователь.

Выдай список проблем по важности: 🔴 критично, 🟡 стоит поправить, ⚪ мелочь. Для каждой — где она и почему это проблема. Потом спроси, что исправлять. Сам ничего не меняй, пока я не отвечу.
