Урок 01. Как выбрать ИИ-инструмент для разработки #

VS CodeCursor или Windsurf (форки VS Code), GitHub Copilot, Cline, Continue, Kilo Code
JetBrains (IntelliJ, PyCharm, WebStorm…)JetBrains AI, GitHub Copilot, Sweep, Continue

УровеньПодходИнструменты

Шаг 3. Подбери по типу задач #

ЗадачаЛучший тип инструмента
Писать код быстрее в течение дняАвтодополнение + чат в IDE
Реализовать фичу или исправить баг «под ключ»Агент в IDE или терминале
Разобраться в чужом большом проектеИнструменты понимания кодовой базы (Cody, Unblocked), агент в режиме «только чтение»
Разгрести бэклог мелких тикетовОблачные агенты (Jules, Codex, Devin, Factory)
Собрать прототип за вечерКонструкторы (Bolt, Lovable, v0)
Повысить качество ревьюБоты для PR (CodeRabbit, Qodo PR Agent, Greptile)
Покрыть код тестамиQodo, Diffblue (Java), Checksum, Meticulous
Запускать много задач параллельноОркестраторы (Conductor, Vibe Kanban, Superset, Parallel Code)

Шаг 4. Посчитай бюджет #

  • Подписка — фиксированная цена и лимиты запросов. Удобно для предсказуемого бюджета.
  • Оплата за токены (BYOK) — платишь провайдеру модели напрямую. Выгодно при нерегулярной нагрузке, но агентские сессии могут стоить дорого.
  • Локально — бесплатно, но нужно железо: для комфортной работы агента — видеокарта от 16–24 ГБ или Mac с 32+ ГБ памяти.

Для контроля расходов используй трекеры из раздела «Учёт токенов и расходов».

Шаг 5. Проведи честный тест #

  1. Возьми 3 реальные задачи из своего проекта: простую, среднюю и сложную.
  2. Дай каждую 2–3 инструментам с одинаковой формулировкой.
  3. Оцени: правильность, сколько правок пришлось делать, время, стоимость, удобство ревью.
  4. Перед тестом добавь в репозиторий AGENTS.md — без контекста любой агент работает хуже.

Частые ошибки #

ОшибкаКак правильно
Давать агенту размытую задачу «сделай красиво»Описывать цель, ограничения и критерий готовности
Принимать изменения без ревьюВсегда смотреть дифф и запускать тесты
Держать один гигантский чатНовая задача — новая сессия; длинный контекст ухудшает качество
Не настраивать правила проектаНаписать AGENTS.md с командами и соглашениями
Давать полный доступ на рабочей машинеПесочницы, worktree, allow-list команд
