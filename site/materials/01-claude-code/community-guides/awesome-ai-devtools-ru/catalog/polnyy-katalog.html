🖥 Среды разработки #

🖥 ИИ-IDE #

Полноценные среды разработки со встроенным ИИ для генерации кода, чата и отладки.

  • Cursor — самая популярная ИИ-IDE: чат, правки, генерация и отладка, режим агента. Форк VS Code, поэтому интерфейс и расширения привычные.
  • Windsurf — ИИ-IDE с чатом, правками и агентом Cascade. Форк VS Code, раньше назывался Codeium.
  • Zed 🟢 🏠 — быстрый совместный редактор от создателей Atom и Tree-sitter, со встроенным ИИ и поддержкой локальных моделей.
  • Replit — облачная IDE в браузере: автодополнение, чат, агент для разработки и деплой в один клик.
  • Google Antigravity — IDE «агенты прежде всего» от Google: автономные агенты планируют, выполняют и проверяют сложные задачи, глубоко интегрированы с браузером.
  • Trae — адаптивная ИИ-IDE с чатом и генерацией кода.
  • Theia IDE 🟢 🏠 — расширяемая open-source IDE (веб и десктоп) с ИИ-чатом, автодополнением, помощью в терминале и своими агентами на любых LLM. Построена на платформе Theia AI.
  • Mutable — веб-IDE с чат-ботом и интеграцией с GitHub.
  • UI Pilot — чат-редактор, который генерирует формы на Material UI.
  • GitWit — веб-редактор для создания React-приложений с ИИ.
  • OneCompiler — бесплатный онлайн-компилятор с ИИ для 70+ языков: пиши, запускай и делись кодом.
  • BuilderStudio — нативное macOS-пространство для агентной разработки: навыки, MCP, изолированное выполнение в контейнерах, параллельные агенты и маршрутизация между 380+ моделями.

🧩 Расширения для IDE #

Плагины, добавляющие автодополнение, чат и рефакторинг в привычные редакторы.

  • GitHub Copilot — самый распространённый ИИ-ассистент: автодополнение, чат, режим агента, генерация описаний PR и тестов. VS Code, JetBrains, Visual Studio, Vim и др.
  • Cline 🟢 🏠 — автономный агент для VS Code: создаёт и правит файлы, выполняет команды и пользуется браузером с твоего разрешения. Поддерживает OpenRouter, Anthropic, OpenAI, Gemini, Bedrock, Azure, Vertex и локальные модели.
  • Continue 🟢 🏠 — расширение для VS Code и JetBrains: чат, рефакторинг, генерация кода, правки в нескольких файлах и запуск команд.
  • Tabnine 🏠 — ассистент автодополнения с возможностью развёртывания у себя; расширения для 15 редакторов, включая VS Code, IntelliJ, Neovim, Eclipse.
  • Supermaven — очень быстрое автодополнение с контекстом до 300 000 токенов.
  • Amazon Q Developer — ассистент AWS для VS Code и JetBrains: ревью, документация, тесты, миграция Java. Бывший CodeWhisperer.
  • JetBrains AI — ИИ-ассистент и агент во всех IDE JetBrains.
  • Refact AI 🟢 🏠 — open-source ассистент: чат, автодополнение, рефакторинг и дообучение на твоей кодовой базе. VS Code и JetBrains.
  • Tabby 🟢 🏠 — self-hosted сервер автодополнения кода, расширения для VS Code, JetBrains и Vim.
  • Blackbox AI — автодополнение и чат со ссылками на онлайн-источники.
  • CodeGeeX 🟢 — ассистент на собственной модели CodeGeeX: чат, автодополнение, рефакторинг; 9 редакторов.
  • Quack AI — следит за соблюдением гайдлайнов проекта.
  • CodeMate — отладка и оптимизация кода в VS Code.
  • AskCodi — ассистент для VS Code, JetBrains и Sublime Text.
  • dbForge AI Assistant — генерация и оптимизация SQL внутри инструментов dbForge.
  • GoCodeo — агент для VS Code, который собирает и деплоит full-stack приложения с Vercel и Supabase.
  • Ptah 🟢 🔌 — мультипровайдерный «оркестр» для VS Code: OpenRouter (200+ моделей), Kimi, GLM, Copilot, Gemini, Codex в одном окне, встроенный MCP-сервер.
  • aiXcoder 🏠 — локальный или облачный ассистент для IntelliJ, CLion, GoLand, PyCharm, WebStorm, VS Code и Eclipse.
  • Sourcery — ИИ-ревьюер и линтер со справочником лучших практик Python и JS/TS.
  • Swimm — понимание кода через статический анализ и автодокументацию; VS Code и все IDE JetBrains.
  • Gemini в Android Studio — ассистент в Android Studio (бывший Studio Bot): генерация кода, поиск ресурсов, лучшие практики.
  • IBM watsonx Code Assistant for Z — модернизация мейнфреймов: перевод COBOL в Java, рефакторинг.
  • EasyCode — чат с GPT-моделями в VS Code.
  • Kilo Code 🟢 🏠 — open-source агент для планирования, написания и исправления кода в VS Code.
  • FlyonUI MCP 🔌 — MCP-сервер для генерации компонентов, блоков и страниц на Tailwind CSS.
  • Traycer — ассистент «сначала план, потом код» для VS Code.
  • shadcn/studio MCP 🔌 — MCP-сервер для генерации компонентов shadcn/ui.
  • onUI 🟢 🔌 — расширение браузера и MCP-сервер: размечаешь элементы на странице и передаёшь контекст в Claude Code, Cursor, Windsurf или Copilot.
  • Sweep — ИИ-плагин для JetBrains: автодополнение, индексация кодовой базы, контекстные подсказки.
  • Antigravity Link 🟢 🔌 — управление сессиями Google Antigravity с телефона: зеркало чата, отправка сообщений, загрузка файлов.
  • Shadcn Space MCP 🔌 — подключает Cursor, Claude Code, VS Code и др. к реестру компонентов Shadcn Space.
  • Blueprint (Imbue) 🟢 — помощник планирования: задаёт вопросы о задаче и пишет markdown-план для любого агента. VS Code, Cursor, Windsurf.

⌨️ Терминал #

⌨️ Агенты в терминале #

Автономные CLI-агенты: пишут код, выполняют команды, работают с несколькими файлами сразу.

  • Claude Code 🔌 — агентный инструмент Anthropic для разработки в терминале: понимает весь репозиторий, правит файлы, запускает тесты, поддерживает MCP, хуки, навыки и субагентов.
  • OpenAI Codex CLI 🟢 🏠 🔌 — официальный open-source агент OpenAI для терминала: выполняет код, правит файлы, работает с разными провайдерами и локальными моделями.
  • Aider 🟢 🏠 — популярный CLI-ассистент: вносит изменения и сам коммитит их в git. Любые LLM, свои бенчмарки моделей.
  • OpenHands 🟢 🏠 — open-source автономный разработчик (бывший OpenDevin) с редактором, терминалом и браузером.
  • Devin — автономный ИИ-инженер от Cognition: планирование, код, отладка и деплой в собственной среде.
  • Gemini CLI 🟢 🔌 — open-source агент Google для командной строки с MCP и интеграцией с shell.
  • Cursor CLI — агент Cursor для генерации и правки кода из терминала.
  • Goose 🟢 🏠 🔌 — open-source агент от Block, работает на твоей машине, расширяется через MCP, поддерживает разные LLM.
  • Amazon Q Developer CLI — автодополнение команд, перевод запроса на естественном языке в команду и агентный чат. macOS, Linux, Windows (WSL).
  • Cosine — агент для корпоративных кодовых баз: баги, фичи, рефакторинг, PR; развёртывание в изолированном контуре.
  • AdaL — агент, в котором совместно работают модели Claude, GPT и Gemini; запоминает паттерны кодовой базы.
  • Axon 🟢 🔌 — ассистент с веб-IDE, мультиагентной системой и 37+ инструментами.
  • Mini SWE-Agent 🟢 — минималистичный агент для обучения и экспериментов с идеями SWE-agent.
  • Micro Agent 🟢 — агент, который пишет код и исправляет его, пока не пройдут тесты.
  • Blueprint 🟢 — плагин для Claude Code: из описания — в план, из плана — в параллельные задачи сборки с автоматической проверкой и перекрёстным ревью моделями.
  • cmux 🟢 — терминал для macOS на базе Ghostty с вертикальными вкладками и уведомлениями от агентов.
  • pi 🟢 🏠 — минималистичный расширяемый агент: расширения на TypeScript, навыки, шаблоны промптов и темы распространяются как npm-пакеты.

🔧 CLI-утилиты #

Лёгкие консольные инструменты: коммиты, контекст для LLM, автоматизация.

  • gptcomet 🟢 — генерирует сообщения коммитов и делает ревью изменений; разные провайдеры и языки.
  • Baz CLI 🟢 — ИИ-ревью кода из терминала с доступом к диффу и коду.
  • models 🟢 — TUI для просмотра моделей, бенчмарков Artificial Analysis и агентов. Rust + Ratatui.
  • Jctx 🟢 — собирает структурированный контекст из проектов на Python, Kotlin и Java для LLM, с картой зависимостей и оценкой токенов.
  • CCG Workflow 🟢 — связка Claude + Codex + Gemini для Claude Code: 28 слэш-команд, умная маршрутизация (Gemini — фронтенд, Codex — бэкенд), параллельная работа.
  • Butterfish 🟢 — ChatGPT прямо в shell с простыми агентными возможностями.
  • TmuxAI — ненавязчивый ИИ-помощник в терминале tmux.
  • IWE 🟢 — граф знаний из markdown с CLI для агентов, без векторной БД.
  • Hermes IDE 🟢 — обёртка для zsh, bash и fish: подсказки команд, выполнение задач, управление git и worktree.
  • codesight 🟢 🔌 — сжимает контекст проекта (роуты, схемы, компоненты) для агентов: в 9–13 раз меньше токенов.
  • prpack 🟢 — упаковывает пулл-реквест (дифф, коммиты, файлы) в один markdown для ревью моделью.
  • Marmot — единая CLI-команда для агентов: ИИ, веб-поиск, скрейпинг и обогащение данных у разных провайдеров.
  • ORCH 🟢 — запускает Claude Code, OpenCode, Codex и Cursor как команду: статусы задач, ретраи, сообщения между агентами, TUI-панель.
  • Octomind 🟢 🔌 — сессионный ИИ-ассистент: 7 провайдеров, план прежде кода, семантический поиск, постоянная память.

🌐 Веб-инструменты #

🏗 Конструкторы приложений #

Создают и деплоят full-stack приложения по описанию на естественном языке.

  • Bolt.new — агент веб-разработки в браузере на WebContainers: npm-пакеты, Node.js-серверы, деплой.
  • Lovable — превращает описание или дизайн в работающее приложение с деплоем и интеграцией с GitHub.
  • Backgrounder.dev — бесплатный интерфейс для агентов (Claude Code, Codex, Gemini, Goose, Pi) в фоновых процессах: ветвление чатов, расписание запусков.
  • Co.dev — создание и деплой full-stack приложений.
  • Capacity — веб-приложения из текстового описания.
  • Leap.new — приложения с настоящим бэкендом и API, деплой в твоё облако.
  • Pico — микроприложения с мгновенным деплоем.
  • SoftGen — генерация веб-приложений.
  • LlamaCoder 🟢 — генерация приложений на open-source моделях.
  • Forge — генерирует Next.js-приложения, работает с твоим API-ключом без наценки.
  • E2B Fragments 🟢 — шаблон для создания ИИ-приложений с выполнением кода в песочницах.
  • Mocha — no-code конструктор веб-приложений.
  • Pythagora — 14 специализированных агентов собирают React/Node.js-приложения; интеграция с VS Code и Cursor.
  • Mage 🟢 — full-stack приложения на Wasp, React, Node.js и Prisma.
  • Make Real — рисуешь интерфейс на холсте tldraw, получаешь HTML/JS-приложение.
  • Glowbom — генерация приложений с экспортом на разные платформы.
  • VULK — React + PostgreSQL, Flutter, игры на Three.js и темы Shopify из описания; хостинг в ЕС, экспорт исходников.
  • Taskade Genesis 🔌 — создание агентов, процессов и приложений на естественном языке.
  • Berrry — превращает посты из X и Reddit в веб-приложения.
  • Blank Space 🟢 🏠 — open-source альтернатива v0, Lovable и Bolt, можно развернуть у себя.
  • Fastshot — no-code создание мобильных приложений.
  • ai-vertical-saas-gen 🟢 — CLI генерирует отраслевые SaaS-приложения (Next.js + Supabase) для 20+ ниш.

🎨 Генераторы интерфейсов #

Генерируют компоненты, макеты и фронтенд-код из текста или дизайна.

  • v0 — генерация и доработка UI-компонентов и приложений от Vercel.
  • Magic Patterns — UI из промпта, картинки или референса; Shadcn, ChakraUI, Tailwind, экспорт в Figma.
  • Tempo — визуальный редактор React-интерфейсов с ИИ.
  • Google Stitch — ИИ-дизайн интерфейсов от Google (бывший Galileo AI).
  • Uizard — многоэкранные макеты из текста, скриншота или наброска от руки.
  • Polymet — прототипирование UI с готовым фронтенд-кодом.
  • Kombai — фронтенд-код из макетов Figma.
  • CodeParrot — плагин VS Code: код из Figma с учётом твоих компонентов и стандартов.
  • Fronty — превращает изображение в HTML/CSS.
  • BoringUi — HTML + Tailwind из JSON-данных.
  • CSS Picker — копирует стили с сайтов, картинка в код, текст в UI.
  • Frontman 🟢 — агент в браузере: кликаешь на элемент, описываешь изменение — получаешь правки кода с горячей перезагрузкой. Next.js, Vite, Astro.

🤖 Облачные агенты для кода #

Агенты, которые работают с существующим репозиторием в фоне и приносят пулл-реквесты.

  • Factory — платформа с агентами «Droids» в IDE, терминале, Slack/Teams и CI/CD: рефакторинг, инциденты, миграции.
  • Jules — асинхронный агент Google, интегрированный с GitHub: исправляет баги и делает задачи в фоне, создаёт PR.
  • Potpie 🟢 — агенты для вопросов по кодовой базе, тестирования, отладки и проектирования систем.

🧠 Понимание кодовой базы #

Навигация, поиск и ответы на вопросы о существующем коде.

  • 4DA 🔌 🏠 — десктоп-приложение и MCP-сервер (36 инструментов): знает стек, зависимости и решения проекта, сканирует уязвимости через OSV.dev.
  • Sourcegraph Cody — ассистент с чатом, рефакторингом и тестами, хорошо работает с большими кодовыми базами.
  • Unblocked — отвечает на вопросы о коде с учётом GitHub, Slack, Jira и Confluence.
  • Magnet — рабочее пространство, где репозитории и задачи служат контекстом.
  • Code to Flow — визуализация кода в интерактивные блок-схемы.
  • Gru.ai — помощь с алгоритмами, отладкой и тестами.
  • sudocode — управление контекстом агентов в долгих задачах.
  • sourcebook 🟢 🔌 — генерирует AGENTS.md/CLAUDE.md из структуры кода и истории git без LLM.
  • Grasp 🟢 🔌 🏠 — граф зависимостей по ссылке на репозиторий, оценка «здоровья», сканер безопасности, тепловая карта изменений.
  • Kasava — читает каждый коммит, чтобы отчёты и планы опирались на реальную архитектуру.
  • SeaGOAT 🟢 🏠 — локальный семантический поиск по коду на векторных эмбеддингах.
  • ContextWire 🔌 — бесплатный API поиска для агентов (105 поисковиков).
  • Reflex 🟢 🏠 🔌 — локальный полнотекстовый поиск по коду для агентов: < 100 мс на 10k+ файлов, JSON-вывод.

🗄 Базы данных и SQL #

  • Wren AI 🟢 🏠 — open-source SQL-агент: вопросы к базе данных на естественном языке.
  • TEXT2SQL.AI — строит, объясняет и исправляет SQL-запросы по описанию.
  • SQLAI.ai — генерация, исправление и оптимизация SQL с учётом твоей схемы.

✂️ Сниппеты и утилиты #

  • CodePal — быстрая генерация и рефакторинг кода в браузере.
  • AI Code Convert — перевод кода между языками программирования.
  • AutoRegex — регулярные выражения из описания на естественном языке.
  • unpkg.ai 🟢 — генерация ESM-модулей JavaScript по URL для быстрого прототипирования.
  • EnigmaEasel — доступные цветовые палитры, OKLCH-градиенты и пары шрифтов с экспортом в Tailwind и SCSS.
  • JSONFix — чинит невалидный JSON.
  • CronAI — cron-выражения из описания расписания.
  • RegexAI — регулярки с объяснением для разных диалектов.

💻 Десктопные и мобильные приложения #

Нативные приложения для ИИ-разработки, терминалы и управление агентами.

  • Warp — ИИ-терминал с подсказками команд, агентами и общей базой знаний команды.
  • Pieces — менеджер сниппетов и «движок контекста» с десктоп-приложением и расширением браузера.
