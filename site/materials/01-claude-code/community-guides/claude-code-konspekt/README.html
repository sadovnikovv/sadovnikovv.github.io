Claude Code: конспект курсов Anthropic Academy на русском #

Программа четырёх бесплатных курсов Anthropic Academy по Claude Code плюс официальная документация - разобраны по-русски и собраны в один файл. От первого запуска до автономных прогонов без присмотра.

Открыть: https://bashkirtsevprofi.github.io/claude-code-konspekt/

10 частей, 47 разделов, 77 правил в формате «правило → почему так → как применить», 34 готовых промпта, шпаргалки по командам, клавишам и файлам настроек.

Об источниках #

Неофициальный материал. Не связан с Anthropic, не одобрен ею и не является её продуктом. Claude, Claude Code и Anthropic - товарные знаки Anthropic PBC, использованы для обозначения предмета конспекта.

Программа и факты взяты из официальных курсов и документации Anthropic, формулировки и промпты - авторские. Цитаты приведены в кавычках со ссылкой на источник и принадлежат правообладателю.

Первоисточники бесплатны и открыты:

  • курсы - https://anthropic.skilljar.com/
  • документация - https://docs.claude.com/en/docs/claude-code/

Материал собран в августе 2026 года по документации на эту дату.
