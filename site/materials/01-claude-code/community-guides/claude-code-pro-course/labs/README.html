Лабораторные работы #

Практика к курсу. Каждая лаба — 20–40 минут, конкретная цель и критерии «готово». Делайте их в своём реальном проекте или в учебном (см. ниже).

#ЛабаМодулиВремя
1Онбординг в проект и CLAUDE.md00–0230 мин
2Разрешения без лишних вопросов0320 мин
3Фича по циклу Explore → Plan → Code → Commit + TDD0440 мин
4Свой skill0530 мин
5Субагент-ревьюер и параллельное исследование0630 мин
6Hooks: формат, защита, уведомления0730 мин
7MCP: браузер и GitHub0830 мин
8Автоматизация: headless и GitHub Actions1040 мин

Учебный проект #

Если своего проекта под рукой нет, создайте мини-проект за минуту — прямо с помощью Claude:

mkdir todo-api && cd todo-api && git init
claude "Создай минимальный REST API списка задач на Node.js + TypeScript (Express),
с Vitest-тестами, eslint и prettier. Добавь 2 намеренных бага в валидацию,
не рассказывай, где они. Сделай первый коммит."

Намеренные баги пригодятся в лабах 3, 5 и 8.

Как проверять себя #

У каждой лабы есть раздел ✅ Готово, если — пройдитесь по нему перед переходом к следующей. Отмечайте прогресс в чек-листе в README.
