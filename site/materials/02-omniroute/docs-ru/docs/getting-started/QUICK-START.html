Кратко: Установите → Подключите подходящего провайдера → Настройте IDE для работы с OmniRoute. Готово.

Шаг 1: Установите OmniRoute #

Выберите предпочтительный способ:

Вариант A: npm (рекомендуется) #

npm install -g omniroute

Вариант B: Docker #

docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest

:latest — это самая новая опубликованная стабильная версия SemVer. Этот тег не отслеживает ветку git main. Для GitOps закрепите версию с помощью diegosouzapw/omniroute:X.Y.Z. См. Теги образов / каналы выпусков.

Вариант C: из исходного кода #

git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev

Шаг 2: Запустите OmniRoute #

omniroute

OmniRoute запускается по адресу http://localhost:20128. Панель управления откроется автоматически.

Шаг 3: Подключите подходящего провайдера #

Выберите провайдера, условия и квота которого соответствуют вашим потребностям. В разделе Dashboard → Providers подключите собственную учетную запись или API-ключ, затем проверьте соединение. Бесплатный доступ и возможность работы без ключа не гарантируются.

По умолчанию auto исключает провайдеров с пометкой tos: avoid, включая Kiro. Подключение учетной записи не изменяет эту политику. Согласие, заданное в разделе Dashboard → Combos, применяется ко всем автоматическим комбинациям. Перед выбором провайдера ознакомьтесь с руководством по бесплатным тарифам.

Шаг 4: Проверьте работу #

На странице API-ключи создайте новый ключ. Сохраните его, поскольку он больше не будет отображаться. Обратите внимание: этот ключ предназначен для доступа инструментов к OmniRoute, а не для доступа к вышестоящим провайдерам.

curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"

Вы должны увидеть список подключённых моделей.

Шаг 5: Укажите OmniRoute в своей IDE или CLI #

В своей IDE или CLI задайте:

Базовый URL: http://localhost:20128/v1
API-ключ:    [скопируйте из панели управления → Конечные точки]
Модель:      auto

Вот и всё! Теперь ваша IDE использует OmniRoute с автоматическим выбором провайдера.

Пример для IDE: VSCode/Continue.dev #

  1. Установите в VSCode расширение Continue.dev.
  2. Добавьте следующие строки в файл ~/.continue/config.yaml:
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
  1. На панели чата Continue.dev выберите OmniRoute - Auto, после чего запросы будут отправляться в OmniRoute.
  2. (Необязательно) Упражнение для читателя: попросите свою IDE добавить в config.yaml все остальные готовые конфигурации 😊

Пример для CLI: Codex CLI #

  1. Создайте постоянную переменную среды в своей операционной системе. Для macOS/Linux (добавьте в ~/.bashrc или ~/.zshrc):
export OMNIROUTE_API_KEY="<YOUR_KEY>"

Для Windows (командная строка):

setx OMNIROUTE_API_KEY <YOUR_KEY>
  1. Теперь запустим Codex, настроенный для OmniRoute. Выполните:
omniroute launch-codex --model auto

Это можно сделать вручную с помощью codex и параметров командной строки, указав конечную точку и API-ключ, однако при использовании приведённой выше команды OmniRoute настроит всё за вас.

Такой же запуск одной командой доступен и для других CLI через универсальное средство запуска: omniroute run <target> поддерживает claude, codex, aider, goose, opencode, qwen и gemini (см. Интеграции с CLI).

  1. Теперь CLI должен отправлять запросы в OmniRoute.

Убедитесь, что ваш инструмент направляет запросы в OmniRoute #

Подробности запроса можно просмотреть, выбрав пункт Мониторинг/Журналы на левой боковой панели. Переход к записи покажет более подробную информацию. Кроме того, вы сможете увидеть, какие данные отправляет ваш любимый инструмент. Это полезно как для обучения, так и для отладки.

Что дальше? #

  • Руководство по Auto-Combo — Позвольте OmniRoute выбрать для вас лучший ИИ
  • Руководство по провайдерам — Подключите больше провайдеров (бесплатных и платных)
  • Руководство по бесплатным тарифам — Ознакомьтесь с условиями провайдеров и ограничениями бесплатных тарифов
  • Устранение неполадок — Устраните распространённые проблемы

Часто задаваемые вопросы #

«Нужен ли мне ключ API?» #

Ключ API OmniRoute используется для аутентификации ваших инструментов. Учетные данные вышестоящих сервисов зависят от провайдера: некоторым требуется ключ API или вход в учетную запись. Бесплатный доступ не гарантируется.

«Что такое auto?» #

auto указывает OmniRoute автоматически выбирать лучшего провайдера для каждого запроса. При выборе учитываются скорость, стоимость, качество и доступность. Подробности см. в руководстве по Auto-Combo.

«Сколько это стоит?» #

Сам OmniRoute — бесплатный проект с открытым исходным кодом. Вы платите только за используемых провайдеров. Многие провайдеры предлагают бесплатные тарифы — см. руководство по бесплатным тарифам.

«Можно ли использовать его с Claude Code / Cursor / Copilot?» #

Да! OmniRoute работает с любым инструментом, поддерживающим формат OpenAI. Просто укажите в качестве базового URL-адреса http://localhost:20128/v1. Конкретные инструкции по настройке см. в руководстве по инструментам CLI.

«Что произойдет, если провайдер перестанет работать?» #

OmniRoute автоматически пропускает недоступных провайдеров и пробует следующего. Вам не нужно ничего делать. Подробности см. в руководстве по Auto-Combo.
