Кратко: провайдер — это подключение к сервису ИИ (например, OpenAI, Anthropic или Google). Для использования OmniRoute необходим как минимум один провайдер.

Что такое провайдер? #

Представьте провайдера как оператора мобильной связи. Подобно тому как для совершения звонков вам нужен оператор мобильной связи, для использования моделей ИИ вам нужен провайдер ИИ. OmniRoute похож на телефон, который работает со всеми операторами — между ними можно переключаться автоматически.

Быстрый старт: подключите первого провайдера #

Необязательная настройка бесплатных провайдеров при первом запуске #

Мастер первого запуска предлагает отдельную карточку Настроить бесплатных провайдеров. Он формирует текущий список доступных вариантов на основе реестра провайдеров OmniRoute, не требующих аутентификации, а затем позволяет просмотреть список и отменить выбор отдельных провайдеров перед подтверждением. OmniRoute отображает предупреждение провайдера и ссылку на его сайт, чтобы вы могли заранее ознакомиться с условиями стороннего сервиса, политикой конфиденциальности, доступностью и ограничениями частоты запросов.

Это действие необязательно: завершение работы мастера никогда не создаёт подключения к бесплатным провайдерам без вашего ведома. Он создаёт только подключения к отсутствующим провайдерам, не изменяет существующие настроенные подключения и отдельно сообщает о созданных, уже настроенных и не подключившихся провайдерах. В случае частичного успеха можно безопасно повторить попытку только для подключений, завершившихся ошибкой.

Вариант A: бесплатный провайдер (без банковской карты) #

  1. Откройте панель управления по адресу http://localhost:20128
  2. Перейдите в раздел Провайдеры → Добавить провайдера
  3. Выберите одного из следующих бесплатных провайдеров:
  4. Kiro AI — бесплатные модели Claude (аутентификация не требуется)
  5. Pollinations — бесплатные GPT-5, Claude и Gemini (ключ не требуется)
  6. LongCat — 10 млн бесплатных токенов (единоразовое начисление, требуется учётная запись и прохождение KYC)
  7. Cloudflare AI — более 50 моделей, 10 тыс. нейронов в день
  8. MLX Gemma 26B — локальная модель для Apple Silicon (~38,5 токена/с, ~15,9 ГБ ОЗУ)
  9. MLX Qwen 3.8 27B — локальная модель для Apple Silicon (~9,1 токена/с, ~13,1 ГБ ОЗУ)
  10. Нажмите Подключить
  11. Готово! Теперь у вас есть бесплатный доступ к ИИ.

Вариант D: локальные модели MLX (Apple Silicon) #

На компьютерах Mac с Apple Silicon и объединённой памятью OmniRoute поддерживает подключение локальных моделей MLX, запущенных через mlx-lm.server, в качестве обычных локальных провайдеров, совместимых с OpenAI.

Предварительные требования #
  • Компьютер Mac с Apple Silicon (M1/M2/M3/M4); рекомендуется не менее 24 ГБ объединённой памяти
  • Менеджер пакетов uv: curl -LsSf https://astral.sh/uv/install.sh | sh
  • mlx-lm: uv pip install mlx-lm
Быстрый старт #
  1. Установите зависимости:
   # Установите uv, если он ещё не установлен
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Установите mlx-lm
   uv pip install mlx-lm
  1. Запустите серверы MLX вручную (в отдельных терминалах):
   # Терминал 1: Gemma 4 26B A4B IT-QAT (порт 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Терминал 2: Qwen 3.8 27B MLX Mixed (порт 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
  1. Подключите модель в панели управления OmniRoute:
  2. Перейдите в раздел Провайдеры → Добавить провайдера
  3. Выберите MLX Gemma 26B или MLX Qwen 3.8 27B
  4. Нажмите Подключить (API-ключ не требуется)
  1. Используйте с OpenCode:
   # Настройте OpenCode для использования OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Используйте модели MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
Управление памятью #

Важно: при наличии 24 ГБ объединённой памяти одновременно может работать только одна большая модель MLX.

  • Gemma 26B: пиковое потребление памяти ~15,9 ГБ
  • Qwen 3.8 27B: пиковое потребление памяти ~13,1 ГБ

Этим необходимо управлять вручную:

  • Запускайте одновременно только один сервер MLX, или
  • Запускайте их на разных компьютерах, или
  • Останавливайте один сервер перед запуском другого

OmniRoute не управляет процессами серверов MLX автоматически — он лишь направляет запросы к настроенным вами конечным точкам, совместимым с OpenAI.

Поддержка вызова инструментов #

Обе модели поддерживают вызов инструментов, совместимый с OpenAI. Проверьте с помощью:

curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'

Как подключить провайдера (пошагово) #

Шаг 1: откройте панель управления #

Перейдите по адресу http://localhost:20128 в браузере.

Шаг 2: перейдите в раздел Providers #

Нажмите Providers на боковой панели.

Шаг 3: нажмите Add Provider #

Нажмите кнопку + Add Provider.

Шаг 4: выберите провайдера #

Просмотрите список или найдите своего провайдера с помощью поиска. Нажмите на него.

Шаг 5: введите учётные данные #

  • Бесплатные провайдеры: учётные данные не требуются — просто нажмите Connect
  • Провайдеры с API-ключом: вставьте свой API-ключ
  • Провайдеры с OAuth: нажмите Connect with OAuth и войдите в систему

Шаг 6: проверьте подключение #

Нажмите Test Connection, чтобы убедиться, что подключение работает.

Шаг 7: готово! #

Теперь ваш провайдер подключён. Вы можете использовать его с model: "auto" или указать провайдера напрямую.

Использование нескольких провайдеров #

OmniRoute лучше всего работает с несколькими провайдерами. Это обеспечивает:

  • Автоматическое переключение — если один провайдер недоступен, OmniRoute пробует следующий
  • Оптимизацию стоимости — OmniRoute выбирает самого дешёвого провайдера для каждого запроса
  • Оптимизацию скорости — OmniRoute выбирает самого быстрого провайдера для каждого запроса
  • Оптимизацию качества — OmniRoute выбирает лучшего провайдера для каждой задачи

Рекомендуемая конфигурация #

Для наилучшей работы подключите как минимум 3 провайдера:

  1. Один бесплатный провайдер (Kiro или Pollinations) — всегда доступен
  2. Один быстрый провайдер (Groq, Cerebras) — для быстрых ответов
  3. Один провайдер с высоким качеством (OpenAI, Anthropic, Google) — для сложных задач

Затем используйте model: "auto", и OmniRoute будет автоматически выбирать лучший вариант для каждого запроса.

Qoder: выбор способа передачи учётных данных #

Для Qoder требуются учётные данные. Два способа их передачи имеют разные возможности; одного имени модели недостаточно, чтобы определить возможности конкретного подключения.

Учётные данныеСпособ передачи OmniRouteВызов инструментов вызывающей сторонойПотоковая передача
PAT, начинающийся с pt-Локальный процесс qodercli на хосте OmniRouteНе поддерживаетсяБуферизованная: SSE отправляется только после возврата полного ответа CLI
Токен доступа не типа PAT или ключ APIHTTP-эндпоинт DashScope, совместимый с OpenAIПередаётся без изменений с учётом модели/ключа источникаВосходящий путь HTTP/SSE

Для PAT установите Qoder CLI на том же хосте или в том же контейнере, где работает OmniRoute. Исполняемый файл должен быть доступен как qodercli; в противном случае задайте в CLI_QODER_BIN путь к нему. CLI, установленный только на Docker-хосте, не появляется в контейнере автоматически. При отсутствии исполняемого файла возвращается явная ошибка с указанием установить его или задать путь.

Для обработки чата через PAT установлен 45-секундный тайм-аут процесса. Диалог преобразуется в единый промпт, после чего CLI вызывается в непотоковом режиме вывода. Указание stream: true изменяет формат ответа на SSE, но не обеспечивает постепенную передачу токенов от восходящего сервиса. Для проверки CLI и получения списка моделей используется отдельный 20-секундный тайм-аут. Это текущие значения по умолчанию в коде, а не настраиваемые параметры панели управления.

Используйте подключения PAT для обычного чата. При выборе учётных данных для агентских запросов, содержащих tools или устаревший параметр functions, учётные записи PAT исключаются, в том числе для закреплённых комбинированных целей. В смешанном пуле Qoder по-прежнему может быть выбрана его HTTP-учётная запись. Прямые вызовы исполнителя PAT также завершаются явной ошибкой до запуска CLI, а не молча отбрасывают определения инструментов. Это ограничение относится к инструментам, переданным вызывающей API стороной, а не к внутренним инструментам, которые может использовать сам Qoder CLI. Наличие HTTP-ключа не гарантирует поддержку инструментов каждой моделью; стандартные проверки возможностей модели всё равно выполняются.

Браузерная OAuth-аутентификация доступна только в том случае, если администратор настроит все пять параметров: QODER_OAUTH_AUTHORIZE_URL, QODER_OAUTH_TOKEN_URL, QODER_OAUTH_USERINFO_URL, QODER_OAUTH_CLIENT_ID и QODER_OAUTH_CLIENT_SECRET. По умолчанию они пусты; в ненастроенной установке следует импортировать поддерживаемые учётные данные, а не рассчитывать на готовность браузерного процесса входа.

Ссылки на реализацию: исполнитель Qoder, среда выполнения CLI и конфигурация OAuth. Постепенная потоковая передача через PAT и настраиваемый тайм-аут являются отдельными улучшениями; описанное поведение не гарантирует их наличия.

Часто задаваемые вопросы #

«Нужно ли платить за использование OmniRoute?» #

Нет! OmniRoute — бесплатное программное обеспечение с открытым исходным кодом. Вы можете бесплатно пользоваться такими провайдерами, как Kiro и Pollinations. Платить нужно только в том случае, если вы решите использовать платных провайдеров.

«С какого провайдера лучше начать?» #

Начните с Kiro AI — он бесплатный, не требует ключа API и предоставляет доступ к моделям Claude. Затем при необходимости добавьте других провайдеров.

«Можно ли использовать несколько провайдеров одновременно?» #

Да! В этом и заключается основная идея OmniRoute. Подключите несколько провайдеров и используйте model: "auto", чтобы OmniRoute выбирал оптимальный вариант для каждого запроса.

«Что произойдет, если провайдер перестанет работать?» #

OmniRoute автоматически пропустит недоступного провайдера и попробует использовать следующего. Вам не нужно ничего делать.

«Как отключить провайдера?» #

Перейдите в раздел Providers → нажмите на нужного провайдера → нажмите Disconnect.

«Можно ли использовать имеющиеся у меня ключи API?» #

Да! Если у вас уже есть ключи API для OpenAI, Anthropic, Google и других сервисов, вы можете использовать их в OmniRoute. Просто вставьте их при подключении провайдера.
